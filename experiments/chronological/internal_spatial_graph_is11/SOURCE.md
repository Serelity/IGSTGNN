# IS1.1 固定候选道路图

从 `contra_network_m41_final` 的既有产物逐字节复制 `graph.json`、`stations.csv` 与 `summary.json`（本目录命名为 `source_summary.json`）。没有重新按预测收益选路，也没有复制旧 M4 的交通、报告集合或 checkpoint。

训练器核对原产物记录的 SHA256、496 站顺序、边界来源、重复边和节点资格掩码。原图 SHA256 为 `10a69e096f0157d97391929077fe5b1fd3857609334bb4cf1720e9fe68796ac4`。

候选覆盖 476/496 站，456 条内部边、266 条显式开放边，14 个道路/方向评价组。图内仍保留候选连接、匝道来源与边界依据供审核。当前联合物理认证节点为 0；这些是元数据支持的探索性关系，不是认证的车流守恒网络。20 个图外节点不补造边。

`source_summary.json` 描述更早的 M4 输入准备，其中多报告、多通道等信息不是本轮模型输入。IS1.1 只消费本目录的静态候选边和站点分组；使用原 flow、时钟及原触发报告。图只供 B2/B3 使用。B3/B0 同时涉及结构信息变化，B3/B2 才是同信息算子比较。
