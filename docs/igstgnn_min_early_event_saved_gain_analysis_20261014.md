## 🎯 为什么再分析已有预测

[五轮结果](igstgnn_min_early_event_5epoch_results_20261014.md)显示：EVENT相对STATE最佳MAE小幅改善，但RMSE与困难窗口恶化；当前事故模块ON/OFF净MAE收益极小且高度抵消。仅凭全网平均不能判断下一步应改事故位置处理、条件强度、语义还是注入位置。

## 📐 三个收益在同一预测点分解

固定样本、站点、时距、真实目标y与同一个有效掩码。令S为STATE_ON、O为EVENT_ON、F为EVENT_OFF：

\[
T=|S-y|-|O-y|,\qquad
P=|F-y|-|O-y|,\qquad
R=|S-y|-|F-y|.
\]

逐点严格满足\(T=P+R\)。正数表示比较中的候选绝对误差较低。

| 名称 | 含义 | 边界 |
|---|---|---|
| T：整体方案收益 | EVENT_ON相对独立训练STATE_ON | 包含训练后的权重及支持策略等全部差异 |
| P：当前事故路径收益 | 同一EVENT检查点OFF相对ON | 当前权重对新增事故路径的效用，不是真实事故因果效应 |
| R：关闭后剩余差异 | EVENT_OFF相对STATE_ON | 只叫剩余误差差异，不能自动称为训练收益、正则收益或主干识别出的事故效应 |
| Q：语义依赖 | EVENT_SEMANTIC_UNK相对EVENT_ON | 固定M/D；UNK可能有分布外影响 |
| L：位置依赖 | EVENT_LOCATION_SHUFFLE相对EVENT_ON | 移动完整D与支持；单次重排可能有分布外影响 |

同一掩码和权重下MAE的T/P/R聚合仍满足相加关系。RMSE本身不作这种可加分解；分别报告各状态RMSE及比较变化。预测变化统一为候选−对照，正值为预测上调，与“误差收益正值表示改善”不是一回事。

## 🗺️ 固定分组与交叉分析

所有比较使用相同分组，不因P的对照是EVENT_OFF就重新按OFF划分高低估。

- 流量：固定真实目标桶[0,5)、[5,20)、[20,50)、[50,100)、[100,200)、[200,∞)。
- 偏差：只由STATE_ON−y确定高估、低估、恰等。
- 事故三分区：已有direct_report_nodes、potential_only、remaining_nodes，互斥完备。
- 道路：复用归档内road掩码，不重新匹配道路、站点或原始事故数据。
- 时距：未来第1～12步分别统计，保留每步分母。
- 困难窗口：复用源analysis中由STATE选出的固定样本编号，不为任何比较重选。
- 交叉：流量×STATE偏差×事故三分区，并保留逐时距结果。

报告pooled与horizon macro MAE/RMSE/MAPE、有效点数、全网贡献、正负收益、抵消、改善/变差点占比、预测上调/下调和响应幅度。组内宏平均与全网贡献使用不同分母，可能异号，不能混加；互斥完备分组的全网贡献需核对守恒。

真实目标和误差符号均为事后诊断，不作为未来门控或训练输入。事故三分区不是经过认证的真实传播区域/自然无事故区域。

## 🔀 判断整体收益与事故路径收益是否重合

同点检查T与P的正负及恰等，包含边界的分区必须穷尽所有有效点。

| 位置类型 | 解释 | 后续重点 |
|---|---|---|
| T>0且P>0 | 整体更好，事故路径也改善同点误差 | 检查是否集中在直接报告关联或特定时距 |
| T>0但P≤0 | 整体更好，当前事故路径未帮助该点 | 检查R与状态对照/支持策略差异，不能把全部收益归事故 |
| T≤0但P>0 | 事故路径有帮助，整体仍未超过STATE | 检查剩余差异及训练稳定性，不直接丢弃事故路径 |
| T≤0且P≤0 | 整体及当前路径均无改善 | 定位流量、区域、偏差与时距条件 |

这些是描述性重合关系，不是可直接部署的开关标签。误差收益按0判符号；预测响应另用固定阈值统计，不混淆两种阈值。重叠预测窗口与点数不充当独立事故重复，不计算伪精确显著性。

## 🧩 怎样据此选择模块改进

| 分析发现 | 可支持的下一项 | 仍不能断言的事 |
|---|---|---|
| 低流量T改善，但P不改善、R承担改善 | 检查纯状态调制及支持范围对训练/校准的影响 | 不能称事故推理路径修复了低流量 |
| P在直接关联/长时距改善，其他处损害 | 从可观测历史寻找条件路由或尺度依据 | 不能用未来真实流量或本次收益作门控 |
| P导致预测几乎单向移动，高低估点作用相反 | 检查是否学成输出校准效应、调制尺度是否合适 | 不能仅凭隐藏gamma正负判流量方向 |
| L有作用而Q弱 | 优先审查位置/关系表示，再考虑语义简化验证 | 一次UNK/重排不能证明语义可永久删或位置建模正确 |
| P预测响应大而净收益抵消 | 定位正负作用条件，设计更有针对性的模块 | 不等于模块没有运行 |
| P预测响应始终弱 | 下一项再对条件前后隐藏状态及下游层做插桩 | 当前最终预测不能指出到底哪一层抹掉了信号 |

本分析不自动输出删模块或增加模块的指令。结果先用于提出可被反证的局部改进假设，再设计最少新实验；原MIN模块可删除性仍需单独确认。
