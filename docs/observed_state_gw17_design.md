# GW17：用历史观测校正区域／局部状态，再连续推进未来

日期：2026-10-20。开发状态：源码与服务器测试已编写，开发机没有执行Python、模型、语法编译或数值测试。
新包为 `experiments/observed_state_gw17`；已有GW16、原版及冻结测试文件保持原样。

## 已有证据及新增问题

GW16完整100轮已经获得同样本配对保留测试收益，当前结果已冻结。
这支持整套方法的预测效用，尚不识别位置、训练配方、状态交换各自的独立贡献。
GW17不以这次测试时距或分组结果挑模块、阈值、训练预算或损失权重，不读取此前测试缓存。

现有 `HistoryEncoder` 先对每节点12点做GRU并保留末状态，再做空间混合；
区域共同状态 `C0=PH0` 与局部差异 `L0=QH0` 在预测头开始时才形成。
新科学问题是：**让同一种区域／局部动力学在观测期逐步预测并接受观测校正，
是否比直接注入观测变化，更适合初始化和持续预测事故场景交通？**
源码显示的是历史状态构建与未来推进的结构差异；尚未证明它是精度瓶颈。
原GRU已能依赖有序历史，不能将新问题写成“原模型没有顺序信息”。
GW7-15的记忆、联合槽核、分支读出和冻结来源差分适配失败结论保留，不重新执行这些诊断。

## 两组、一个明确差异

| 组 | 历史校正器读到的标量 |
|---|---|
| OBSERVATION_CONTROL | 当前观测变化 `x_t-x_(t-1)` |
| INNOVATION_STATE | 观测变化减去模型更新前预期变化 |

两组拥有逐张量完全相同的初始模型、全部活跃参数、位置与事件输入、数据次序、优化器和损失。
没有按臂添加占位参数或另配隐藏宽度。唯一功能差异是历史校正残差的定义。
GW16只读取已有STATE_EXCHANGE BEST验证缓存作历史参照，不加载其权重、不重训、不新增模型推理。
新两臂同容量与同更新预算；GW16参照不构成新的等计算训练控制。

## 数据流和变量

复用作者认证六文件、3909训练／837验证样本、496节点、12历史预测12未来、原始mean/std，
以及既有道路／方向／里程区域划分、位置元数据和固定图支持。
`S`将区域状态提升到节点，`P`取区域均值，`Q=I-SP`去除区域均值。
这些是统计坐标，不是车辆库存、道路物理守恒或已识别的事故效应。

1. 仅第一历史观测、该时钟和静态节点信息初始化隐藏状态，再分解为C/L。
   后续历史流量通过观测更新进入，不能在初态预读完整历史。
2. 对每个后续历史时刻，先由共享5分钟核心 `F_theta` 从上一步C/L预测下一状态。
   时钟是已知日历；预测当前流量前不能读取当前流量。
3. 同一组线性读出将隐藏状态增量映射为预期流量变化：
   `pred_delta = S Wc(C_minus-C_prev) + Q Wl(L_minus-L_prev)`。
   更新前原单位预测为 `mean + std*(x_prev+pred_delta)`。
4. 当前观测到达后，按两臂规则构造残差r。相邻两槽原单位流量均finite且大于0.001时才有效，
   其余残差置零。有效性按float64阈值比较，与目标指标完全一致。
5. 校正器分别读取 `P r` 与 `Q r`；位置与当前C/L决定0至1门控，
   经无偏标量到隐藏维投影和初始0.1的可学习步长校正；局部状态再次Q投影。
   无效槽不提供残差，但可经区域投影接收其它有效节点的共同信息。
6. 11次历史转移结束后，状态直接作为未来12步的起点；未来不接受观测校正。
   两阶段使用同一个核心对象和读出参数，且每次C/L更新同步读取旧状态。

核心保留GW16位置×当前状态低秩交互及区域／局部双向交换，
条件改为共享静态信息与当前日历，不使用仅未来才有的独立时距embedding。
未来日历由最后观测时钟按5分钟推进，正确处理跨日与星期回绕。
事故类别、描述及关系只在历史循环结束后编码并调制未来状态和源项；不把起点报告倒填过去。
报告首次可用时刻仍未认证，因此保留离线档案条件的解释边界。

未来读出继续采用末值锚点：
`prediction = reference + std*(S alpha + beta)`，`P beta=0`。
读出权重初始为零，两组阶段零精确为末值持续预测；先学习读出，随后梯度能进入全部状态分支。
此架构替换不是与GW16嵌套的零残差插件，不宣称零参数可恢复GW16权重或预测。

## 共同训练目标与固定预算

两组同样使用：

`L = MAE_future_node + 0.2 MAE_future_region`

`    + 0.1*(MAE_history_preupdate_node + 0.2 MAE_history_preupdate_region)`。

历史监督来自输入X中的后11个已观测槽，评分对象是读取该槽流量之前的预测，
不是校正后的重建，也不读取未来Y作为历史校正输入。
区域误差在同一有效节点子集上求平均，覆盖率至少0.8；MAPE目标至少1。
历史辅助监督与结构共同区别于GW16；两臂同样获得此监督，避免将它解释为候选独享的创新收益。

每组固定从头100轮，seed2025、batch48、每轮82批，共8200优化器更新。
Adam lr0.002、weight_decay1e-5、eps1e-8，40/70/90轮后lr乘0.5，clip5、dropout0.1。
全程joint，无早停、无阶段优化器重置，BEST按未来验证pooled MAE选择且包括第0轮。
一次完整前向含11历史＋12未来共23次共享状态转移；参数相等不代表与GW16计算量相等，实测完整训练耗时和峰值显存另报。

## 一次开发筛查

唯一候选INNOVATION_STATE必须完整正式100轮，且同时满足：

- BEST未来MAE比OBSERVATION_CONTROL和历史GW16验证参照各改善至少0.5%。
- BEST RMSE、MAPE、窗口P95均不劣于这两个参照。
- LAST MAE相对自身BEST退化不超过1%。
- 两新臂参数量完全相等、初始张量完全相等、数据轴与训练预算认证一致。

0.5%为既有开发线使用的实用筛查尺度，不是显著性水平或承诺收益。
历史一步预测误差是额外诊断，不代替未来主指标，也不单独用于选BEST。
失败不自动追加轮数、换seed或修改标准。通过只是单seed开发资格，不开启已公开的GW16测试。
新的独立确认需要另行冻结评估方案，窗口重叠不能当独立事故样本。

## 相关工作与差异范围

[MMSTNet，TR-C 2023](https://www.zhangjunbo.org/pdf/2023_TRC_MMSTNet.pdf)已有宏微历史双流、位置／结构表示与跨尺度融合。
[KalmanNet，IEEE TSP 2022](https://arxiv.org/abs/2107.10043)已有神经网络辅助状态预测与观测更新的思想。
本轮潜在差异限定在：区域共同项／零均值局部项的观测偏差校正、位置×当前状态门控，
以及贯穿历史和未来的同构交换核心。没有协方差后验、滤波最优性、首创保证或预测精度结论。
