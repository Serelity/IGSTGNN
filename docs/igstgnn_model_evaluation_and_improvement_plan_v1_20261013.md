# IGSTGNN B3-R-G1.1 完整模型评估与改进决策方案 V1.0

日期：2026-10-13

适用对象：原始 IGSTGNN 对照 B0、IS1.1 的 B1/B2/B3、B3-R，以及 G1.1 的 B3R/HALF/GATE/NO_D。

文档性质：后续评估的设计与开发依据。本文没有启动训练，也不表示下文规划的评估工具、消融版本或测试集评估已经实现。

输入建议：[模型评估体系与模块改进依据](<G:/paper/研究方案/IGSTGNN_B3-R-G1.1_模型评估体系与模块改进依据.md>)。

## 1. 研究目标与评估闭环

核心研究问题是：在现有历史流量、事故报告及候选道路结构有限的条件下，怎样改进 IGSTGNN 内部的事故信息处理与受限传播，使预测获得可靠收益？

评估需要分别回答四类问题：

1. **预测价值**：相对原 IGSTGNN，整体误差、严重失败和计算成本怎样变化？
2. **作用条件**：收益与伤害分别出现在哪些道路、报告关联位置、历史状态和预测时距？
3. **设计价值**：改进模块经过独立训练，是否优于必要的原模块与简单对照？
4. **路径解释**：同一模型中，报告条件修正怎样经过潜容量、交换、读出影响预测？作用在哪里被削弱或发生有害偏移？

执行闭环为：

```text
可比性与数据证据核对
        ↓
全网、局部、时距、困难窗口评价
        ↓
同 checkpoint 路径干预与正负收益分解
        ↓
定位一个具体问题，提出一个可证伪的模块假设
        ↓
控制变量重训练与配对种子复核
        ↓
保留、简化、修改或停止该设计
        ↓
架构与评价规则冻结后，进行最终测试
```

全网 MAE 保持既定选模地位。次级指标用于解释收益、发现风险和检验假设；不能在看到结果后更换主指标以宣布胜出。采用“整体质量—局部价值—内部响应”三类证据，不把它们合并成一个任意加权总分。

## 2. 对原建议的采纳与必要修正

采纳建议中的分层模块、整体性能、消融、空间/时间/状态响应，以及“问题发现→设计→验证”的组织方式。以下术语和归因必须按当前实现修正。

| 原建议中的方向 | 本方案采用的准确解释 |
| --- | --- |
| NO_D 验证事故信息是否必要 | NO_D 保留原 TIID，D 又同时读取历史，因此检验的是 **D 联合处理路径的增量价值**，不等于检验全部事故信息。 |
| G 是状态条件门控 | 当前 G 与 D 都读取历史摘要、报告编码、距离和年龄；应称为 **历史与报告条件的强度门控**。纯历史 G 尚待单独设计。 |
| B2/B3 验证容量和预算 | B2/B3 检验受限交换组合，相比普通交换同时涉及边上限、发送/接收预算及越界裁剪差异，不能分别归因。 |
| 容量变化与收支误差证明物理正确 | 当前容量、状态、交换均为无量纲潜变量。可验证算子内部约束与收支一致性，不能声称辨识真实道路容量或验证车辆守恒。 |
| 不同预测步的容量响应 | 当前每个 forward 生成一次容量并复用；可以比较各输出时距收益，不能画成模型已学习未来容量演化。 |
| Remove distance | 距离还决定报告关联掩码，并进入原 TIID。直接清零会同时关闭/改变其他路径，必须显式保留原支持掩码并注明干预位置。 |
| Remove report age | 年龄既有 D/G 显式输入，也进入共享报告编码。只删一个副本不等于删除全部年龄信息。 |

“事故信息应改变传播条件”是待检验的建模假设，不是已经证实的事实。最终证据允许出现模块不必要、只有部分状态受益或简单缩放足够等结果。

## 3. 当前数据与结论边界

### 3.1 本轮可使用的信息

当前冻结协议为 `internal_spatial_b3_r_strength_g11.json`：训练 3604 个窗口、验证 917 个窗口、496 站、12 个监督时距。原历史流量、时钟、报告年龄和三通道空间关系仍为输入；没有新增速度、密度、封道比例、事故处置过程或容量真值。

候选算子覆盖 476/496 站，图中包含内部边和开放入口/出口。候选方向与道路资料提供结构先验，其物理认证尚不完整。图外站继续参与全网预测，必须保留在评价中。

数据加载器当前约束报告年龄为 `0 < age ≤ 5 min`。这支持早期报告条件分析，不支持长时间事故生命周期、解除封道或恢复阶段的验证。不得为补齐评价项目虚构不可得字段。

### 3.2 必须区分的范围

- 917 个窗口不等于 917 起独立事故；`t0` 不自动等于事故 ID。
- 报告关联掩码不等于实际事故影响标签；无向连通分量包络不等于真实传播范围。
- 原统计图、主干与 TIID 仍可传播信息；图外预测变化不能直接视为新算子越界。
- 当前时间审计保留缺失证据，评价范围继续为 **conditional offline**。若未取得首报快照及可靠可见时间，不能扩展成已验证在线部署结论。
- 当前验证集已经多次用于架构设计；其区间和分组结论均属开发性证据。最终泛化结论需要冻结设计后的独立测试。

缺少真实容量标签不会阻止预测与路径评价，但会限制“真实容量变化”的解释。缺少可靠事故 ID 时，先做窗口/时间块评价，事件级评价标记为不可用。

## 4. 六层评价体系

| 层级 | 内容 | 主要输出 | 服务于什么决策 |
| --- | --- | --- | --- |
| L0 可比性 | 数据、时间、掩码、种子、预算、checkpoint、来源版本 | 比较资格与缺失证据表 | 判断差异是否可归于模型设计 |
| L1 总体质量 | 全网 MAE/RMSE、辅助 MAPE、计算成本 | 主结果表、成本表 | 是否值得继续研究 |
| L2 异质性与风险 | 时距、道路、区域、历史状态、窗口尾部 | 全量分组表、配对分布图 | 找到收益和伤害的条件 |
| L3 路径敏感性 | 同 checkpoint 的 ON/干预/恢复 ON | 预测与内部变量的配对变化 | 定位模型依赖的路径及阻塞位置 |
| L4 重训练增量 | 原模块、改进模块、必要简单对照 | 同预算、多种子差值 | 判断模块是否改善学习结果 |
| L5 稳定与外推 | 时间块、配对种子、信息缺失、最终独立测试 | 稳定性与适用范围 | 确定可支持的研究主张 |

实现正确、路径有响应、局部误差改善、整体可靠改善是四种不同结论，分别记录。

## 5. L0：先建立可比性登记

### 5.1 每次比较必须登记的字段

建立独立的 `evaluation_manifest.json`，只读原 run，至少保存：

| 字段类别 | 内容 |
| --- | --- |
| 数据身份 | 数据/上下文摘要哈希、split、站点顺序、sample_index、t0、目标时刻、valid mask |
| 信息范围 | 历史输入槽、目标槽、报告可见性假设、可用字段、缺失字段 |
| 模型身份 | arm、架构版本、模型源码哈希、图哈希、TIID/D/G 开关、参数数量 |
| 训练身份 | seed、初始化证书、batch、优化器、学习率计划、epoch、global_updates、早停规则 |
| checkpoint | 选模指标、best_epoch、checkpoint 哈希、best_model_state 哈希、实际训练轮数 |
| 运行环境 | Torch/CUDA、精度、确定性设置、GPU 型号、CPU 线程 |
| 评价身份 | 评价工具版本、分组规则、阈值来源、干预定义、是否读取 test |

比较状态分为：`comparable`、`conditional_comparable`、`incompatible`、`missing_evidence`。缺失什么、影响哪种结论都要列明；不以静默忽略的方式强行比较。

### 5.2 训练预算与 checkpoint

1. 当前四组继续使用原 batch48 和冻结协议。同数据、同 batch 时，共同 epoch 对应共同训练样本遍历与更新预算。
2. 分开给出 **共同预算前缀内最佳值**、**共同固定 epoch** 与 **各组实际完成后的最佳值**。后者若预算不同，只作旁表。
3. 同 checkpoint 机制分析使用按固定全网 MAE 规则选择的最佳状态；不能为某条机制挑另一个最有利 checkpoint。
4. 最近 5/10 轮均值用于描述轨迹，不是 5/10 次独立实验。连续 epoch 的标准差也不是训练种子不确定性。
5. 旧 B0/B2/B3 结果可复用，但先核对数据、初始化策略、训练/选择规则和共同预算。仅有不同预算的控制台最佳值不够形成正式对照。
6. 后续 batch64 先在新 run 做资源基准，再让同轮比较的全部组使用同一新协议。batch48 与64的同 epoch不代表同更新数；主表写明采用样本遍历预算还是更新预算，另报耗时，不混用。
7. 各组采用相同最大轮数、patience、min_delta、并列选较早轮的规则；提前停止时列出实际更新数。

history可恢复共同前缀内最佳**数值**，不保证相应早期**权重**仍可取得。当前last checkpoint保留当前最佳状态，不能由它反演任意旧epoch模型。机制探针只使用确实保存的权重；早期权重缺失标记不可用。后续预登记开发节点应显式归档当时best/last快照及哈希。

不修改现有训练协议或来源文件来迁就评价。新分析工具独立保存版本，保护现有恢复身份。

### 5.3 时间与重复样本审计

统计唯一 `t0`、日期跨度、可核实报告标识、重复窗口、目标时间重叠，以及 train/validation/test 的目标时间和可识别事件重叠。原基准重复出现的 station×target_time×forecast_origin 按原协议保留，但记录重复程度。

若跨 split 发现不合法的目标重叠或未来字段，不能作为确认性结果；原结果留档，另建修正后的协议。验证目标使用训练时期的历史上下文可以是合法的时序预测，不将正常历史连续性自动判为泄漏。

原输入 `X=槽0:12`、目标 `Y=槽14:26` 存在排除槽，图中优先标 `h1…h12`。只有核对目标时间与预测截止点后，才换算真实分钟数，不能直接默认成5—60分钟。

## 6. L1/L2：指标与分组规范

### 6.1 固定主指标和辅助指标

记误差 `e = prediction - target`，`v` 为有效目标掩码，`N_h` 为时距 h 的有效位置数。

```text
MAE_h = sum(v * |e|) / N_h
主 MAE = mean_h(MAE_h)，h=1…12

RMSE_h = sqrt(sum(v * e²) / N_h)
RMSE_macro = mean_h(RMSE_h)
RMSE_pooled = sqrt(sum_h sum(v * e²) / sum_h N_h)

gain = metric_control - metric_candidate
relative_gain = gain / metric_control  （control>0 时）
```

主指标保持 `all_nodes.mae_macro`。主表附 `mae_pooled`、`rmse_macro`、`rmse_pooled`，明确不同聚合方式，不能把“先开根再平均”和“先汇总再开根”写成同一个 RMSE。

MAPE仅作辅助，沿用当前 `valid & target>0` 的分母；保存比例值，显示百分数时乘100并标注。不能为改善 MAPE 事后删除小流量样本。接近零的目标会放大百分比误差，因此它不能代替 MAE/RMSE。[预测误差与百分比指标的适用性](https://otexts.com/fpp3/accuracy.html)提供这一方法依据。

主表还报告注册参数、实际执行/更新的参数范围、单轮时间、推理吞吐和峰值显存。NO_D保留未执行D的注册参数，单看参数总数会低估其计算差异。耗时尽量同GPU与相同线程复核，SXM2/PCIe差异另列环境。

### 6.2 时距

保存12个时距的 MAE/RMSE/样本数和配对收益。为便于汇报，预定义短段 h1—h3、中段 h4—h6、长段 h7—h12，并保留完整曲线。

不同时间段收益不能自动归因为“容量随时间演化”或“传播速度正确”。它首先说明输出时距的性能差异。

### 6.3 空间与覆盖

现有 `report_associated`、`candidate_potential`、`outside_operator` 可以并排展示，但存在重叠，不相加成全网贡献。`candidate_potential` 当前基于候选图无向连通分量。

需要可加贡献时，根据每个窗口的**原始输入**新建互斥分区：

| 分区 | 定义 | 可解释的含义 |
| --- | --- | --- |
| R0 直接关联 | 原距离编码非零的位置 | 输入定义的报告关联节点 |
| R1 候选包络内其他位置 | 候选包络减去R0 | 结构上可能关联的位置，非真实影响标签 |
| R2 其余位置 | 全部节点减去R0与R1 | 剩余节点，不能自动称无事故或未受影响 |

R0/R1/R2应互斥且覆盖全部sample-node。再以算子覆盖/图外作为交叉维度，并报告14个固定道路/方向组及各自有效数。

每组同时给出：组内误差、组内收益、占全网有效权重、对全网净收益贡献。少量节点较大的局部收益不等于全网更优；大组很小的平均收益也可能贡献显著。

如果没有无报告窗口或某个分组为空，标记 `unavailable`，不填0。删除报告的合成输入不冒充自然无事故样本。

### 6.4 历史状态分层

只使用预测截止点之前的可用历史：末值、均值、首尾差/斜率、波动、已有空间差异。采用训练集确定并冻结的三分位阈值，形成低/中/高流量、下降/平稳/上升、高/低波动等少量分组。

优先按站点训练期参考尺度分层，避免道路流量规模差异主导状态标签；参考尺度和缺失处理写入评价协议。训练样本存在重叠时，参考统计尽可能基于去重后的可用历史观测，并登记方法。

当前只有流量时，低流量不能直接称为拥堵，高流量也不能直接称为畅通。没有速度、密度或可信拥堵标签，就使用流量状态的名称。分组阈值、标准化参数、缺失值填补均不能使用验证/测试未来值拟合。

### 6.5 窗口分布与困难情形

现有NPZ保存窗口i、时距h的绝对误差和 `A_ih` 及有效数 `n_ih`。窗口评分定义：

```text
W_i = mean_h(A_ih / n_ih)  （只纳入有有效目标的h，同时报告覆盖数）
```

输出窗口评分的中位数、P90、P95、最差尾部平均值，以及候选相对控制的改善/持平/恶化比例和幅度。尾部平均值采用固定排序取最高 `ceil(0.05*M)` 个窗口，并登记并列处理。

区分两个问题：

- **各模型自身尾部**：比较其各自误差分布和风险水平，样本集合可能不同。
- **相同困难窗口**：固定控制模型最差10%的窗口集合，所有候选在同一集合比较。至少固定B0作为最终基准；当前四组开发分析固定B3R。控制模型、checkpoint及并列排序规则均入档。

困难集合使用目标误差进行事后诊断，不作为模型输入、在线识别规则或训练筛选条件。不能每组各挑有利样本。

窗口等权均值通常不等于原全网主 MAE。原主指标必须从各h的绝对误差总和/有效数重新计算，不能用窗口平均代替。窗口P95也不是逐点误差P95，更不是预测区间覆盖率。

### 6.6 站点、道路与规模差异

补充逐站误差/收益分布、站点胜负比例和道路等权汇总，观察少数站点及道路组的差异。各站有效数相同时，原全网MAE已对站点等权；换一种站点聚合不能自动消除高流量站误差较大的规模效应。道路等权改变道路组权重，训练尺度归一化处理规模差异，两者属于不同的次级分析，均不替换原主指标。

逐站指标需要点级预测。若后续使用MASE等训练尺度归一化指标，必须具备合法连续训练序列与明确季节周期；当前窗口资料不足时不强行计算，也不从验证集估计尺度。[Hyndman与Koehler的准确率指标研究](https://robjhyndman.com/publications/another-look-at-measures-of-forecast-accuracy/)可作为选用尺度指标的依据。

## 7. L3：同 checkpoint 的配对推理

### 7.1 需要回答的问题

推理干预回答“已训练模型对该路径怎样响应”；独立训练消融回答“这种设计是否改善学习结果”。两种结果可能不一致，必须同时保留，不能用OFF误差代替重训练NO_D。

G1.1最小推理干预登记如下：

| 干预 | 保持的内容 | 问题与限制 |
| --- | --- | --- |
| 原始ON | 全部已训练路径 | 重放保存的最佳验证指标 |
| 整个D路径OFF | P、边界、原TIID、其余已训练权重 | D条件路径敏感性；不是关闭全部事故信息 |
| GATE强制alpha=1 | 同一GATE模型的D/P和其他权重 | 已学习门值的幅度调节作用；不等于独立训练B3R |
| GATE强制alpha=0.5 | 同一GATE模型的D/P和其他权重 | 同权重尺度响应；不等于独立训练HALF |
| 恢复ON | 恢复所有干预 | 检查没有残留hooks、开关或状态污染 |

不要把alpha=0、D OFF和NO_D重训练当作三个独立的信息来源。前两者在该乘法路径上可能等价，主要用于实现核验。

### 7.2 执行契约

1. 只加载固定主指标选出且确实保存的 `best_model_state`，不默认 `last.pt` 最新权重就是最佳权重，也不从history数值推造已丢失的早期权重。
2. 原batch48、原顺序、原站点/时距轴、相同精度、相同valid mask完整重放ON，匹配保存的最佳指标后才允许干预。
3. 每批按ON/单项干预/恢复ON执行，不训练、不创建优化更新；比较参数、buffers及原checkpoint哈希不变。
4. 记录数值差异诊断；容差基于精度与受控重复评估制定，不为了通过某次失败而盲目放宽。不得随意缩小batch后将差异解释为模型效应。
5. 异常时清除全部hooks和临时开关，保留部分诊断，状态写为未完成，不能输出科学成功结论。
6. G1.1须使用适配后的独立探针。原B3-R探针目前不是新模型的现成入口。

### 7.3 最小点级产物

保存 `[window, horizon, node]` 的ON/干预预测、target、valid；另存sample_index、t0、站点顺序、目标时间、原始分组掩码、输入状态摘要和checkpoint身份。

采用流式batch导出。四组不同时驻留GPU；内部变量以流式统计为主，完整中间张量仅对预登记代表窗口保存，避免把全部层/调用/边张量长期堆在内存。

## 8. 收益与伤害的统一分解

点级收益定义为：

```text
g_ihn = |error_control_ihn| - |error_candidate_ihn|
G+ = (1/12) * sum_h [sum(v * max(g,0)) / N_h]
G- = (1/12) * sum_h [sum(v * max(-g,0)) / N_h]
net_gain = G+ - G-
gross_change = G+ + G-
cancellation = 1 - |net_gain| / gross_change  （gross_change>0时）
```

所有模型使用相同目标与有效掩码。`gross_change=0` 时抵消率为不可用，不填0或1。

净收益、正收益、负收益、预测改变量一起报告。高抵消说明收益与伤害接近，不能只展示正收益，也不能通过直接放大D解决方向问题。

互斥区域对全网贡献计算时，**分母仍是全网各h的N_h**，从而满足：

```text
sum_region(global_gain_contribution) = 全网主MAE收益
```

组内均值的分母是该组有效数，两种量都保存但不混称。对区域×时距×历史状态×控制模型误差方向做联合分解，避免分别看边际分组得出不一致归因；若细胞样本太少，仅保留较粗层级。

“高估/低估”由指定控制预测与目标定义。路径探针可用OFF作控制；跨模型对照用固定B0或B3R。参考控制不同的分组不能直接相加或比较。该标签只用于离线分析，不进入G、D、训练筛选或推理选择规则。

## 9. L4：分层对照与消融矩阵

### 9.1 先复用当前已有组

| 比较 | 回答的问题 | 归因边界 |
| --- | --- | --- |
| B1 vs B0 | 原事故注入强度调节是否改善预测 | 仍是原ICSF路线，不能代替新算子评价 |
| B2 vs B1 | 替换事故信息路径并加入内部交换是否有价值 | 删除原ICSF部分投影并加入新路径，不是只新增一个交换因素 |
| B2 vs B3 | 同信息、同参数骨架下受限交换组合是否有效 | 不能分别证明容量上限/发送预算/接收预算 |
| B3-R vs B3 | 容量参数化与报告残差更新是否改善学习 | 参数化、参数规模和报告更新共同变化，不归为单个公式因素 |
| GATE vs B3R | 条件强度参数化是否优于原D尺度 | 增加参数及优化条件，尚不能独立证明动态信息利用 |
| GATE vs HALF | 是否优于固定0.5尺度 | 仍须与原强度1及NO_D共同判断 |
| B3R/HALF/GATE vs NO_D | 各D处理方式相对跳过D的增量 | TIID仍ON，D还处理历史 |
| 最终候选 vs B0 | 改IGSTGNN是否兑现整体价值 | 数据与预算核验后才进入主结果表 |

原B0在本研究合法输入与时序协议下重现，不把论文不同数据/划分下的数值直接作严格基准。B1属于设计脉络对照；最终核心复核至少保留B0、必要中间控制、候选和与该假设对应的消融，不要求所有早期组永久多种子重跑。

### 9.2 只有出现对应证据，才新增以下实验

| 候选消融 | 控制方法 | 何时值得做 |
| --- | --- | --- |
| 学习一个全局标量alpha | 初始1、相同范围；D输入及训练协议保持 | GATE可能只是学会更合适的整体尺度时 |
| G仅保留历史输入 | 明确移除G的全部报告编码/距离/年龄来源，D不变 | 需要区分历史状态调节与报告特征调节时 |
| D仅保留历史、保留原支持掩码 | 匹配D宽度/参数条件并清楚命名“报告支持内的历史D” | 分辨联合D收益是否主要来自额外历史处理；仍不叫完全无报告 |
| D/G距离特征消融 | 使用原始距离计算并冻结mask；只屏蔽指定路径的特征；TIID保留 | 空间关系定位有害修正的证据出现时 |
| D/G年龄消融 | 同时处理该路径显式年龄与embedding中的年龄信息；保留预测时钟 | 年龄相关差异可辨且样本充足时 |
| TIID与D的2×2路径对照 | TIID on/off × D on/off；P/图/算子保持 | 确定两条事故处理路线互补还是重复；D关闭仍有历史处理混杂 |
| 容量上限/发送/接收预算单因素 | 提议网络、边界、其他限制和读出控制一致 | 约束组合有价值后，才定位哪项约束必要 |

以上都要登记“推理干预”还是“独立重训练”。移除年龄不能把预测截止点时钟一起删掉；若必须采用独立报告编码器，列明参数/信息改变并设置匹配控制。当前年龄范围仅5分钟，不能为这个消融承诺恢复过程验证。

移除预算可能造成潜状态越界或改变裁剪行为。先做合成固定proposal的正确性试验；若真实模型需要新增稳定化机制，所有对应组采用共同稳定化方案并另立版本，不能把不稳定组误差差直接解释成某预算的预测价值。

一个版本优先验证一个主要假设。每次新增训练前写下：观察、假设、对照、允许变化、预期中间响应、主指标、风险指标、预算和失败条件。

## 10. 机制证据链与定位方法

当前机制链应准确写成：

```text
历史/报告条件
  → raw D、alpha、mask×alpha×D
  → 潜节点容量
  → 潜边容量与提议
  → 实际执行的受限潜交换
  → 位移/入流/出流读出
  → 最终流量预测
```

| 环节 | 记录与检查 | 典型问题 |
| --- | --- | --- |
| D/G | signed rawD、alpha分布、实际alphaD、D幅度加权alpha、梯度 | D与alpha尺度补偿；门值变化但有效修正不变 |
| 节点容量 | P/更新logit、sigmoid斜率、饱和比例、容量变化 | logit变化被sigmoid饱和压缩 |
| 节点→边 | min瓶颈端点、ties、内边/边界区分 | 改变的节点不是实际限制端点 |
| 提议/限制 | q、边上限限制、发送/接收限制及其分母 | 容量限制很少激活；后续预算遮蔽变化 |
| 实际交换 | internal/inlet/exit flux及ON/OFF差 | 边界响应主导，内部传播弱 |
| 读出 | 位移、实际入/出流、读出贡献、各层/调用差 | 读出权重弱或后续层抵消 |
| 输出 | 预测改变量、signed bias、G+/G-/net | 广泛同方向偏移，收益与伤害高度抵消 |

现有机制诊断按五层、每层四次调用、每次两子步记录；容量按forward统计一次。汇总时保留这些分母，不把容量复制次数当独立证据。

注意三点：

1. 限制激活计数仅说明算子条件出现，不能替代最终flux/预测的配对敏感性。
2. 容量也进入proposal网络，因此D OFF可能同时改变提议与硬边上限。需要隔离这两条路线时，另做显式路由控制，并核验每次前向状态；不据观察相关性声称完成了严格因果中介分析。
3. 内部潜交换收支满足实现恒等式，只证明潜算子一致性。原统计图不受该预算限制，不能将该恒等式推广为整个模型的车辆守恒。

alpha与历史状态/误差收益的关系首先是描述性分析。当前alpha并非校准置信度；未来目标误差不能用来构造“正确门值”直接反馈当前推理。

## 11. L5：稳定性、信息缺失与统计单位

### 11.1 配对种子

开发阶段优先采用3个配对种子 `2025/2026/2027`；候选定型后，核心比较扩为5个 `2025—2029`。这些数量是资源折中，不是保证显著性的门槛。已有2025结果明确标记探索性，不因其有利而只保留该seed。

每个seed的各组共享预定公共初始化和batch随机策略，独立优化器。列出所有seed结果、配对差值、均值/标准差和方向一致性，禁止挑最好seed作为主结论。训练seed反映算法波动，不替代不同时期数据的验证。

可借鉴[Agarwal等的NeurIPS评价研究](https://proceedings.neurips.cc/paper/2021/hash/f514cec81cb148559cf475e7426eed5e-Abstract.html)对有限训练重复中不确定性的重视，但不照搬强化学习任务的独立采样假设。

### 11.2 时间块与区间

先审计t0和预测区间重叠，再定义整块配对重采样。所有模型、站点和时距使用相同抽样窗口块，保留同一时刻的跨站依赖。

- 可评估按日期或连续时间块分组，但“每日独立”不是默认事实。
- 块长根据可用时间覆盖和相关结构制定，同时考虑目标区间重叠、共享历史、重复报告及更长交通相关；额外检查更长块，不能只挑最有利区间。
- 不规则、报告触发采样不能简单把连续行号视为等间隔时间；若无法建立合理时间块，报告描述性差异与覆盖限制。
- 若块间依赖仍强、有效块太少或非平稳明显，标记区间不可靠，不能用海量逐点重采样制造狭窄置信区间。
- 重采样每次从绝对误差和有效数重建原主指标，不对窗口均值简单平均后冒充全网MAE。
- 可先使用2000次重采样与固定分析seed，并核查重复次数的数值稳定性；增加次数不能增加独立数据量。

依赖序列的块重采样方法见[Künsch（1989）](https://doi.org/10.1214/aos/1176347265)。本项目是否满足其依赖/近似平稳条件仍需数据审计；方法来源不等于本数据的适用性已经确认。

训练seed区间与时间块区间分开列；不把seed×窗口×站点展平当IID样本。大量道路、时距和消融均属探索性比较，完整展示并标明；若开展确认性显著性检验，再预先登记少量假设、检验方法和多重比较校正。

### 11.3 信息缺失压力测试

在模块有初步价值后，按固定随机seed共享生成10%/30%/50%报告缺失模式，区分“仅跳过新D整路径，TIID仍ON”和“TIID与D报告路线同时关闭”。若只移除D的一类输入，另行登记，不能与整路径关闭混称。报告dropout是合成输入偏移条件，不代表自然无事故数据，也不直接证明训练信息增量。

缺失比例的抽样单位必须写明。优先按可靠报告ID整体删除，同一报告的重叠窗口使用同一缺失状态；没有可靠ID时，可做明确命名的窗口级压力测试，但不冒称真实报告丢失过程。不得在节点间独立删除后仍称“整份报告缺失”。

采用有效字段范围内的输入处理，不引入未来事故时刻、severity或封道标签。若测试定位偏差，扰动须通过数据格式与mask审计，明确其是否改变支持范围；不对原编码任意加噪并称现实定位误差。

关注性能下降曲线、局部伤害、门控/修正响应及稳定性；相同缺失模式应用于全部候选。不要把信息缺失下的性能改善解释为原报告全部无用。

### 11.4 最终测试

当前只使用train/validation。冻结模型设计、超参数、阈值、checkpoint选择与报告表格后，才按独立测试协议评估B0、最终候选及关键对照的全部预登记seed。

test只执行一次冻结批次的完整评价，不用test挑架构、seed、分组阈值或checkpoint。若test时间证据不足，报告条件性范围；若test被用于修改模型，后续就不再将其称为未使用独立测试。

## 12. 从观察到模块改进的决策表

| 观察 | 首先排查 | 下一项最小实验 |
| --- | --- | --- |
| rawD变化但容量不变 | alphaD尺度、sigmoid饱和、输入支持 | 固定同checkpoint检查logit→容量，暂不扩大D |
| 节点容量变、边容量不变 | min瓶颈、非瓶颈端点 | 分端点/边类型配对统计 |
| 边容量变、最终flux不变 | proposal小于上限、后续共享预算 | 固定proposal合成验证，再分路线干预 |
| flux变、读出/预测弱响应 | 读出权重、层间抵消、统计主干吸收 | 小范围读出/层级路径检查 |
| 预测广泛下降，高估受益而低估受损 | signed修正、状态/空间异质性 | 先验证有害修正的条件，再设计方向/强度调节 |
| GATE≈HALF，且都优于B3R | 固定尺度与优化条件 | 增加学习全局标量对照，考虑简化门控 |
| GATE优于B3R/HALF但rawD与alpha补偿 | 参数化/正则化而非简单抑制 | 对比有效alphaD及容量/flux变化，不解读alpha均值 |
| GATE跨seed有益且G-减少 | 是否同预算、是否局部伤害转移 | 保留门控，进行B0与关键控制复核 |
| NO_D持续更好 | 联合历史处理、定位、支持、报告编码 | 明确范围的D输入控制；不直接宣布事故无价值 |
| 关联区域改善、其余退化 | 支持范围、主干全局响应、读出传播 | 定位伤害来源后才做局部化，避免先截断传播 |
| 长时距收益、短时距受损 | 输出时距的方向偏移与读出 | 单独提出时距适配假设，不宣称已有动态容量 |
| 只改善少数困难窗口 | 是否固定同一困难集合、是否有普通窗口代价 | 复核尾部收益和总体成本，明确局部主张 |

模块继续研究的依据应包括：符合目标的预测证据、可解释的作用位置、重复性和成本。单个机制数值非零、某轮排名领先或一张相关性图都不足以单独决定。

不预设“顶会需要提高1%/5%”等统一门槛。下一次确认性比较前登记最小实际收益 `delta_primary` 与允许的RMSE/尾部/图外伤害 `tau_*`；阈值结合基准重复波动与研究用途确定，公开依据。尚未设定时报告连续差值与不确定性，不自动给科学PASS。

结论使用：`支持继续研究`、`有局部收益及明确代价`、`暂不支持增加该复杂度`、`证据不足`。工程检查通过与模型有效性分开。

## 13. 当前产物可做什么、还缺什么

| 分析 | 当前能否直接完成 | 依据/缺口 |
| --- | --- | --- |
| 全网/已有区域/道路/12h的MAE、RMSE、MAPE | 可以，无新推理 | 每组 `history.json` 的 `validation.metrics` |

## 15. 实验推进与资源优先级

### P0：先从现有结果找问题

输入当前G1.1四组及可比的历史B0/B2/B3/B3-R。完成E0/E1，输出主表、区域/道路×时距表、窗口收益分布和固定困难集结果。对仅有控制台摘要的run，标记等待服务器真实产物，不推造缺失表格。

这一阶段不增加模型训练，不据10轮排名淘汰必要控制。若四组正在继续训练，评价使用同一冻结epoch快照，避免一边读取一边提交checkpoint。

### P1：回读G1.1已学机制

E2首先支持B3R/GATE及NO_D的合法ON重放，优先完成B3R/GATE的D路径干预和GATE固定强度干预，再由E3生成正负收益和机制链报告。NO_D没有D响应，作为独立训练比较的结果保留。

不要求每个epoch都跑全套探针。先在预登记开发节点与固定规则最佳checkpoint做，所有选择范围入档。

### P2：只针对一个主要问题改模块

例如定位到“同方向修正造成抵消”，下一版先验证条件调节是否减少G-并保留G+；若定位到“容量变但flux不变”，优先研究瓶颈/提议/预算路径。不要把这些不同问题同时塞进一个新模块。

先做受控工程验收，再开展同预算必要组训练。若结果主要是固定尺度效应，优先保留简单设计；若仅局部改善，明确局部目标与全网代价。

### P3：核心复核与冻结

对仍值得研究的候选开展3个配对seed开发复核；候选定型后以5个seed复核B0、候选及关键控制。保留完整失败/无收益结果，公布实际训练预算和成本。

冻结最终方案再进入test。当前协议 `main_training_ready=false` 的条件性范围不会因新增评价表自动改变。

## 16. 固定报告模板与完成条件

每轮模型研究交付以下内容：

1. **比较资格**：数据、信息、预算、checkpoint是否可比，哪些证据缺失。
2. **整体价值**：相对B0及必要中间控制的主误差与成本。
3. **收益与风险**：完整时距、道路、互斥区域、历史状态和困难窗口结果；不只展示最优组。
4. **路径解释**：ON/干预/ON是否通过，D→容量→flux→读出→预测在哪里变化。
5. **重复性**：逐seed差值、时间覆盖、有效块数和不确定性局限。
6. **下一项决策**：一个主要观察、一个待检验假设、最小控制组与停止/修改条件。

典型最终表述应是：“在相同数据与预算下，候选在整体/某些预定义区域获得多少收益，同时哪些指标恶化；干预显示哪条内部路径响应；多seed/时间范围支持到什么程度。”

完成条件是获得一份可追溯、可重复的**模型证据矩阵与下一项实验依据**，并非必须把每个模块都证明有效。
