## 为什么重构

同一数据、初始化、训练预算和选择指标下，A/B/C在917个验证事件上的全节点MAE分别为
22.6867、22.8141和22.7802。配对自然日bootstrap显示B-A和C-A的退化区间均高于0；
关联节点没有可靠改善，H7-H12退化更明显。

旧C把每个节点的三个历史统计量直接映射为12个可正可负的系数：

```text
g(h) + tanh(b[h] + MLP(z_node)[h])
```

训练后的系数可逐节点、逐预测步任意振荡，并与历史流量水平高度相关。该结构无法区分
“事件的共同时间形状”和“节点交通水平修正”，所以即使参数可学习，也不足以支持潜在
事件阶段的解释。继续调学习率或隐藏宽度不会修复这一结构混淆。

## C'的模型约束

每个节点仍计算只使用预测前输入的
`z=[历史均值, 最后值, 后3步均值-前3步均值]`。只在空间关系非零的节点上求平均，得到
一个事件级状态`q`。首报后分钟数`a`在当前包中仅为1至5分钟，因此只作为弱输入，不能
宣称恢复了事故真实开始时间：

```text
u = MLP([q, a/5])
pi = softmax(u[0:3])
alpha = sigmoid(-8 + u[3])
k(h) = sum_j pi[j] * basis_j(h)
w(h) = (1-alpha) * g(h) + alpha * k(h)
```

三条固定基曲线分别表示即时衰减、持续衰减和延迟峰值；都平滑、非负，最大尺度与原始
`g(1)=exp(-1/2)`一致。`w(h)`是它们与原始高斯的凸组合，因此始终非负。一个事件只产生
一条12步时间曲线，所有关联节点共享；节点差异继续由现有TIID上下文和三通道空间关系
承担。

阶段编码器为`4 -> 16 -> 4`，增加144个参数，少于旧C的268个。末层零初始化，
`alpha`初始约0.000335，使初始系数接近A；当前12步上的最大系数差约`9.74e-5`。
与原高斯不同，持续和延迟基在H12仍为非零，因而远期存在直接梯度。

## 预期效果与反驳条件

预期而非保证的效果：

- 减少节点级、逐步正负振荡造成的过拟合；
- 保留H7-H12的有效梯度，同时用平滑基限制自由度；
- 把可视化对象压缩为事件门控、三类阶段权重和一条共享时间曲线；
- 将时间形状和空间异质性分开，便于做明确消融。

首轮仍只使用seed 2025和开发验证集。C'必须至少满足：全节点MAE低于冻结A的22.6867，
H7-H12不退化，关联节点不出现实质退化；随后再做事件配对与自然日聚类bootstrap。
若不能同时满足，不运行测试集，不用额外种子或更大模型挽救该假设。

## 工程与运行边界

旧`fixed/shared/conditioned`语义保留，C'使用新名称`phase`。v1协议和历史结果不覆盖；
新运行必须显式使用`screening_phase_v2.json`和新输出目录。先在服务器已有Conda环境中做
两轮工程检查：

```bash

python -u experiments/chronological/train.py \
  --data-dir ../data/chronological/Contra_Costa_v8_dev \
  --output-dir experiments/chronological_runs/contra_phase_cuda_check_01 \
  --protocol experiments/chronological/screening_phase_v2.json \
  --variant phase \
  --device cuda:0 \
  --seed 2025 \
  --check
```

工程检查只验证接口、有限值、梯度、保存和恢复，不用于模型排名。通过后再用新目录去掉
`--check`运行完整100轮。输出仍标记`CONDITIONAL_OFFLINE_SCREENING_ONLY`。
