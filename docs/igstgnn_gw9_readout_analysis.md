## 本次实现范围

新增纯 NumPy 与 Python 标准库的离线分析组件。输入为认证 probe 的既有 BEST/LAST 预测归档，可选加载原作者数据以核对历史输入关联。程序不导入模型、Torch、优化器或训练器，不做新预测，不读取 checkpoint 权重张量，不申请 GPU。

分析保持原有训练执行文件、来源 manifest、运行目录与筛查文件的字节不变。单独的 `GW9_ANALYSIS_SOURCE_MANIFEST.json` 与 `verify_gw9_analysis_bundle.py` 负责校验新增分析来源；这样更新分析代码不会改变原 probe 的执行身份。每次输出到所有来源运行目录外的全新目录，已有输出拒绝覆盖。

## 配对比较与修正分解

固定三组比较：SUM 对 R、BRANCH 对 R、BRANCH 对 SUM。对每组定义旧预测 p、新预测 q、原残差 e=p−y、修正 d=q−p。沿用归档的有效值 mask 和原始 sample/horizon/node 轴。

- MAE 配对收益取 `abs(p−y)−abs(q−y)`，正值表示新预测误差较小；同时报告受益、受损和不变点，避免均值掩盖相互抵消。
- `partition_cancellation.csv` 单独汇总互斥时距、节点、流量等组的净收益贡献与组间抵消；它不同于逐点改善与恶化的抵消比例，二者不混用。
- 记录修正 d 的均值、标准差与幅度，区分近似恒定平移、非恒定修正和几乎无修正。该描述不自动判定结构机制。
- MSE 的差异可分解为 `2*mean(e*d)+mean(d*d)`，并以均值项和中心化方差/协方差项检查总量是否一致。
- 均值、相关性与均方分解只描述既有预测；不把观察到的均值、alpha 或分组偏差应用回预测，不拟合校准或融合模型。

所有指标只描述已反复用于研究设计的开发验证集。没有独立重复种子或独立 test 结果，分组结果不作统计确认。

## 固定分组

对全部三组预测与比较输出长表，而不是只保留收益最大的组：

1. 全部 12 个时距与全部节点，节点 ID、道路标签、事故直接支持标识来自原归档。
2. 流量边界固定为 `-inf/0/5/20/50/100/200/314/inf`，左闭右开。`by_flow.csv` 按未来真实值分组，`by_predicted_flow.csv` 按 SUM 预测值分组；负值单列以使有限值分组完备。
3. 原作者样本轴顺序中的连续 128 样本块，最后一块保留剩余样本。绝对日历顺序未独立认证，不能将这些块称为真实时间切分或独立重复实验。

真实流量区间依赖未来标签，只是事后解释工具，不能把“某真实值区间 BRANCH 更好”转为可部署门控。SUM 预测值分组不使用未来真实值定义组，但本次结果仍属于开发诊断，不能直接当作路由器训练或独立评估。

报告直接展示时距、真实流量、道路标签和事故支持分组，以及 BRANCH 相对 SUM 的各分区组间抵消。节点极值展示按全局 MAE 贡献选出的五个受益节点与五个受损节点，仅供定位；全部节点仍保存在 `by_node.csv`，不据此选节点部署或重定义总体指标。

## 可选的历史输入关联

仅在传入认证原始 `--data-dir` 时分析历史变化幅度与邻域变化分歧。程序核对数据字节、划分与节点身份，只用预测起点可获得的历史输入构造特征；训练历史确定分组四分位，验证历史用于分组关联。输入的统计范围与邻域定义在分析产物中记录，不能事后按收益挑选阈值。

| 特征 | 定义 |
|---|---|
| `last_flow` | 反归一化后历史窗口最后流量 |
| `mean_abs_change` | 窗口相邻步流量差的绝对值均值 |
| `window_std` | 窗口流量总体标准差 |
| `last_change` | 最后一步流量减倒数第二步流量 |
| `history_trend` | 窗口末值减首值，保留正负方向 |
| `neighbor_change_disagreement` | 节点最后变化与邻域加权平均最后变化之差的绝对值 |
| `neighbor_change_dispersion` | 邻域最后变化的加权总体标准差 |

邻域来自原始邻接矩阵 `A_ij` 的行：去掉对角元素后，以非负边权按行归一化。此处不把行方向解释为物理上游或传播时延；没有邻居的节点将两项邻域描述量记为不可用。特征先用 float64 计算再存为 float32，train/validation 采用同一路径；四分位切点的重复值保留，不加抖动或根据误差重选。

作者数据文件为包含多个划分的 object 数组。读取文件会反序列化 test 对象；程序不将 test 历史或标签用于特征构造、分组、指标、拟合或评估。缺少原数据时，这一步显式跳过，不能从预测归档推断历史可预测性。

`history_features.csv` 分总体和各时距报告这些描述量与 SUM 绝对残差、带符号残差、SUM 相对 R 逐点收益的 Pearson 相关。`by_history.csv` 用训练历史四分位分组，单列不可用值。`matched_history.csv` 只对 `mean_abs_change` 与 `neighbor_change_disagreement`，在相同预测时距和起点 `last_flow` 固定流量区间内比较四分位组。

`matched_contrasts.csv` 每行记录同一特征、时距、起点流量区间中的 Q1/Q4 有效点数、Q4−Q1 的 SUM MAE 与带符号偏差差，以及 SUM 对 R 和 BRANCH 对 SUM 的 MAE 收益差。任一端为空时差值留空。报告仅给两端非空分层中 Q4 MAE 更高、更低、相等的符号计数；不同特征及预测时距可共享样本，这些计数不构成独立重复或显著性检验。

这种分层可检查关联是否完全由时距或起点流量区间构成差异解释；没有控制节点身份，不能排除节点等其他混杂因素。即使分层后仍有差异，也不能证明可预测残差、方向性修正或因果关系。本次不拟合任何新模型，不输出自动机制裁决。

## 认证与验证

程序认证 probe 身份、既有筛查结果、归档与 metadata 字节、注册案例、轴、有效值 mask 和预测数组；分析允许读取失败的 probe，不能将原先要求筛查通过的 joint 门禁当作分析前置条件。BEST/LAST 相同必须如实记录，不作为独立证据。来源无效则停止，不能通过放宽容差或重写 source 继续。

新增测试覆盖配对收益符号、分解恒等式、空组/零修正、固定边界、来源篡改与路径约束、历史输入身份及隔离、CLI 输出与不授予训练资格等关键行为。只读分析不会调用训练入口。测试尚需服务器执行；本地仅完成静态审阅与字节核对，不能据此宣称测试通过。

## 输出与后续决策

入口为 `experiments/branch_readout_gw9/run_analysis.sh`，完整服务器命令见 `GW9_ANALYSIS_SERVER_README.md`。报告回答三件事：SUM 的收益落在哪里，BRANCH 与 SUM 是否预测相同或局部抵消，SUM 剩余误差是否与输入历史存在可复核的描述性关联。

若增量极小且没有可区分的新输入证据，就保留本轮负结果并停止当前分支方向。若发现稳定的局部残差模式，后续仍需先提出能区分替代解释的新假设与最小公平比较；本报告不自动生成新模型，不授权 joint，也不把任何分组优势当作新结构已有效。
