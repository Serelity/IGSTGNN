## 要回答的问题

在相同交通骨干、归一化和计算结构下，报告位置是否有预测增量？在位置之外，报告年龄/上下文是否还有增量？
若简单输入已经有效，再检验 TIID 或更复杂交互是否必要。当前可用的“报告内容”只有年龄与位置，
不能将实验命名为事故严重度/语义理解。

旧 traffic_only 同时绕过了 ICSF LayerNorm，旧 state_vector 则仍使用距离、年龄和 RMS(V)。
两者都不能直接担任本轮纯信息消融的全部对照。旧 A/scaler 的时间依赖也不允许直接继承为新过去信息基线。

## 三臂信息对照

三臂使用共同的流量历史、节点身份/路网与日历信息；预测时钟由时间戳独立构造，不能要求 M0 接收事故字典。
采用同一简洁上下文投影与同一处 LayerNorm，不在原 A 之上叠加旧事故分支。初始比较共同关闭 TIID。

| 臂 | 允许的输入 | 必须排除的旁路 |
|---|---|---|
| M0：交通与时钟 | 历史流量、共同节点/图信息、历史与预测日历 | 真实 D、报告年龄、候选掩码、报告 V/RMS(V)、事件 ID |
| M1：增加位置 | M0 输入 + 当时可得的报告位置关系 D | 报告年龄、事故文本/类型/最终时长 |
| M2：增加报告年龄 | M1 输入 + 报告年龄 | 后验严重度、封道结局、未来 Y 或回填文本 |

一种可实现的共同结构是向同一个投影传入 `[共同交通/时钟特征, D, age]`；M0 将 D/age 构造成常量零，
M1 仅将 age 构造成常量零，M2 使用真实值。常量在模型输入边界构造，M0 的前向接口不接收报告数据。
所有臂使用同一适用范围的投影、归一化与解码，不能只对某臂用真实候选 mask 做输出截断。
相同名义参数形状并不保证有效容量完全相同：零输入列对应权重不参与拟合，应同时报告活跃参数差异。

预测时钟原本就能从历史名义时间推出，必须作为三臂共同输入；不能把重复时钟编码的结构收益算成事故新信息。
无报告臂的候选区域仅由评估器计算，且不传给 forward 或构造输入。样本清单和训练权重三臂相同。

M2 与 M1 检验的实际上是 1–5 分钟报告年龄的增量，预期幅度不应被夸大。此项可能得出没有增量，
应按原规则保留该结果，不因输入取值少就事后更换目标或添加未认证字段。

## 时间和训练公平性

新模型从共同初始化重新训练，或使用可证明早于外层评价起点的共同预训练源。
scaler/填补统计只用 fit X 的唯一传感器-名义时槽，选择只用指定 selection 期，audit 不参与选择。
每个配对训练样本还要检查事故与两类对照的完整支持是否在许可时间内，不能仅按正事故 t0 切分。

训练对象、损失、批顺序、种子、优化预算、选择规则和回退规则保持一致。需要重新测 V100 单轮成本，
不能套用 4288 参数冻结骨干适配器的耗时。比较目标包含 M1−M0、M2−M1，而不是只比较复杂模型与旧 A。

后续 TIID 对照应保持输入资格相同；如果开启 TIID 同时引入之前未使用的距离数值，
必须把它报告为模块与信息路径的联合变化，不能称作纯时间衰减贡献。

## 协议需要覆盖的字段

- 明确开发与确认数据资格；已经反复查看的 2023 audit 不能作为独立确认。旧 test 不在本草案中开放。
- 固定完整支持时间边界、每臂结构/输入、数据预处理、重复种子和训练/选模预算。
- 根据最终任务固定唯一主要误差端点和实用收益门槛，同时保留全节点、候选早期、候选晚期、非候选及常规对照。
- 固定配对时间块不确定性、最小样本要求和停止规则。不能只挑最有利区域/种子，或把所有未显著差异称为等价。
- 用输入扰动测试确认 M0 预测对任意报告内容变化完全不敏感；三个臂的训练与评估接口都不能接收未来 Y 作为特征。

以上字段已落实到下述协议。这项开发不修改历史失败结论，也不把推理等价通过视为重训练模型有效。

## 2026-10-05 冻结实施决策

协议文件：`experiments/chronological/minimal_information_v13b.json`。
SHA-256：`ac832ff07a049a5bb0705fb2f2a0dcff8ffd97988ac017d4fabb5acd0e58db84`。
协议在新模型训练输出之前写入；下面的预算和门槛是本轮固定开发标准，不声称是最优参数或普遍行业阈值。

| 项目 | 本轮决策 |
|---|---|
| 数据地位 | 已反复使用的 2023 条件开发集；不打开 val/test，不作独立确认 |
| fit / selection / audit | 沿用 01-02–04-24 / 05-01–06-26 / 07-03–09-04 的完整支持边界与间隔 |
| 窗口数 | fit 1520；selection 全事故 856、共同三元组 206；audit 全事故 1010、共同三元组 378 |
| scaler | 从 fit X 的唯一站点—名义时槽重新拟合；重复时槽值不一致或某站全缺失则失败 |
| 初始化 | 不加载 A；同种子三臂全部模型张量初始化哈希相同，所有骨干重新训练 |
| 结构 | 保留原交通骨干；删除旧 ICSF/TIID，改用共同两层上下文投影＋全节点 LayerNorm |
| 共同特征 | 最后一步交通嵌入、独立构造的预测日历嵌入；历史日历仍供骨干使用 |
| 可变特征 | D 三列与 age/5；按臂在边界内部置零；年龄广播到全节点，不额外乘真实候选 mask |
| 损失 | 只用 fit 全事故的全节点、12 时域有效单元标准化 MAE；真实零保留，非法 Y 显式掩码 |
| 种子 / 预算 | 2025/2026/2027；三臂共 9 次训练，每次 60 epoch，batch=8，共 102600 次 Adam 更新 |
| 优化器 | Adam，lr=0.002，weight decay=1e-5，eps=1e-8，梯度裁剪 5；第 20/40 轮后 lr×0.5 |
| 选模 | 每轮 selection 全事故全节点 pooled 原单位 MAE 最低者；严格改善才替换，同值留较早轮次；不以随机 epoch0 作候选 |
| 评价时点 | 九个选中 checkpoint 身份全部固定后，才开放 audit 数值前向与 Y 评价 |
| 主要端点 | audit 全事故、候选 H1–H6 pooled MAE；分别检验 M1−M0 与 M2−M1，正 gain 表示新增信息降低误差 |
| 最低支持 | 每个用于决策的队列/区域至少 30 个有效窗口、8 个非空事故起始周；参考误差须为正 |
| 开发收益门槛 | 每个预定种子主端点相对改善均≥1%，且周与四周块两种配对区间下界均>0 |
| 保护条件 | 每种子全事故 all/noncandidate 及两类伪事故对照四区域点估计相对受损均≤1%；共同事故主端点点收益>0 |
| 不确定性 | 同一连续 9 周网格共享 2000 次重采样；四周循环块敏感性；匹配三元组按正事故起始周聚类 |
| 失败处理 | 支持不足保留 INSUFFICIENT_SUPPORT；其余未过门槛保留 NOT_SUPPORTED，不等于证明无信息或等价 |

这里的“相同初始化”不要求三臂在真实输入上的初始预测相同；位置/年龄的真实值本来就可以改变前向。
把所有可变信息列置零时，三臂在 eval 下输出完全一致，是结构公平性的工程检查。
同样地，9 次训练的种子不是 9 份独立数据，不把所有区间合称为联合 95% 置信结论。

当前三臂均有 426876 个名义可训练参数。已知恒零输入列对应的权重分别为 M0 128、M1 64、M2 32；
D0 在当前包恒零。原骨干另有前向未参与梯度的参数，逐轮首批记录其名称；
上述差值不能当作精确“有效容量”或声称三臂有效容量完全相同。

两类匹配常规窗口只用于固定端点评价，不进入本轮优化器或选模；其完整支持与配对事故都必须落在相应区间。
它们输入的 D/age 来自对应事故，日历与流量来自常规窗口，是伪事故扰动对照，不是自然发生的真实报告。
训练样本仍是事故中心窗口，因此 M0 是该条件样本集上的无报告输入基线，不是对全年常规交通的无条件性能认证。
位置首报可用性、静态地图元数据来源仍沿用当前条件假设；没有新增事故语义信息。

开发先运行 `check`，再运行三个臂各一轮完整 fit/selection 的 `pilot` 来测成本。pilot 不访问 audit，
也不用于调模型/门槛。正式预算提前固定；若资源不足，保留试跑结果并另立版本缩减预算，不在同一协议下暗改。
本轮训练不足或优化困难不能被解释为位置/年龄永远无用，结论只覆盖所声明模型、预算和数据。

恢复使用 epoch 边界保存的当前/最优模型、Adam、调度器、历史与 Torch RNG，校验来源、版本、设备与历史选模。
