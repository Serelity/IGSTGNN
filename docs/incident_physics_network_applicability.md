# 全路网条件不完整时，物理模块怎样成立

2026-10-09。用户进一步指出：即使最终在全 496 站预测，部分道路不满足物理模型条件怎么办？这是架构适用性问题。此前“未覆盖处保留主干预测”的办法可以维持输出完整，却不能证明新增事故—物理机制适用于全路网。

当前决定：**将全网适用性审查 M1.0 前置为下一任务，在完成前不把逐区段 CTM 确定为全网唯一的新增计算路径。** 已完成的 40 站包保留用于原型与对照；正式全网研究目标不变。以下是候选架构修订，尚未实现或证明收益。

## 先区分缺少什么

| 不满足的条件 | 可以考虑的处理 | 不能据此承诺 |
|---|---|---|
| 缺事故封道/清除标签、真实容量曲线 | 以报告和交通历史估计有界低维有效扰动 | 推断值就是实际封道过程 |
| 缺部分交通观测、初始密度或队列 | 带掩码的状态估计，明确观测映射及不确定性 | 网络可以唯一恢复所有隐状态 |
| 缺可靠连接、路长、流量聚合/单位或匝道交换 | 对该具体守恒/传播方程不施加约束；补证或重新定义适用区段 | 把不成立的方程权重调小就变成正确物理 |
| 道路包含模型未表达的汇分流或其他机制 | 扩展模型并定义边界，或只在可解释部分使用该算子 | 单一路段 CTM 可以直接解释任意学习图边 |

全网已有准备结果显示：482 对里程候选中 261 对有已知非主线点，217 对仅通过元数据预筛，没有已认证瓶颈。存在匝道本身不使 CTM 不适用，但说明无匝道内核不能直接复制到全部候选。这些计数来自[已有证据](incident_physics_evidence_20261009.json)，不把元数据预筛当作最终物理资格。

## 两种架构需要在全网条件下比较

**A：明确物理走廊上的直接递推分支。** 这是原方案。物理轨迹语义清楚，便于检查守恒和回溢；代价是依赖连接、量纲、初态与边界。若只能在少量精选区段落地，它可以作为局部机制实验或参照，不能单凭全网输出把它包装成普适的物理传播模块。

**B：全网共享事故状态模块，加适用位置的物理指导。** 这是针对用户担忧需要优先评估的候选：

1. 在全网用一致的数据接口与共享参数，由事故报告、历史三通道和掩码估计扰动/交通状态，并参与预测；前向计算不要求每个节点都具备完整 CTM 条件。
2. 在连接、量纲和观测映射成立的区段，用供需、守恒及容量演化算子约束该共享模型。物理损失必须实际回传到承担预测的共享模块，不能仅训练一个旁路物理网络就声称改进主预测。
3. 证据不足处仍使用同一个已训练的事故状态模块；缺失的具体物理损失不计算，也不声称该处满足严格守恒。有效容量的物理解释仍以参数尺度和观测条件为前提；仅有无量纲潜变量时，应称扰动强度，不能自动称为车辆/小时容量。

候选 B 的启发可追溯到 [Tang、Jin、Ozbay 的作者稿 §3 式(7)–(10)](https://arxiv.org/pdf/2307.06267)：神经编码器/解码器与独立 CTM 算子共同形成参数和重建约束。该文原研究是参数校准；这里的全网预测、部分道路物理指导以及跨道路共享是待设计、待验证的迁移，不能宣称论文已经验证了我们的情形。

B 没有凭空解决缺数据。物理参数的可辨识性、适用区段是否足够丰富、物理指导是否能迁移到其他道路，都需实验回答。没有任何区段满足必要条件时，不能仅把损失项权重设置为零仍声称完成物理融合。

## 如何避免“加一个门控就掩盖问题”

- 适用掩码按道路证据和数据可用性确定并记录，不让网络通过将所有物理权重置零来绕开约束。
- “全网可以输出预测”“预测受物理学习影响”“该处符合严格物理方程”分别验收。
- 同输入、同结构、有无物理指导进行对照；再比较新增事故条件开/关，并保留直接 CTM 候选作局部参照。
- 同时评价有物理指导和无物理指导的道路。无指导区域没有增益时，不能从总体平均数宣称机制有效迁移。
- 全网联合交通监督后按道路分组的结果，不是未见道路泛化。若研究物理指导的跨道路迁移，必须另行预先确定哪些道路不参与物理指导，并准确说明仍使用了哪些交通训练数据。

## 下一任务的有限交付

M1.0 首先复用现有全网元数据、482 对候选和三通道溯源结果，产出一张“模型需求—全网可用性”表：全节点共同可用输入、需估计状态、可支持具体物理算子的区段、缺失/冲突及所属道路类型。统计应按站点、候选连接、训练报告支持分别给出，不能把它们混成一个覆盖百分比。

这一步先判断架构依赖能否成立，不要求把所有路段的数据补齐。根据结果确定 A 的合理范围，以及 B 是否具有可训练且有实际物理约束的实现基础，再继续 M1.2/M2/M3。若 A 只适于少量局部，调整全网主模型设计；不将“先做好三条路，其他以后回退”作为最终研究答案。
