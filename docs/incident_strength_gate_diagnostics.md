## 本轮回答的问题

读取既有每轮历史及选择期 A 的误差充分统计量，核对：

- 每组训练是否更新、梯度是否全为零、是否发生过梯度裁剪。
- 训练中的在线拟合损失走势，以及选择期误差、门控均值和离散程度的走势。
- 每轮区域误差对全局变化的加权贡献，分别保留事故和两类对照。
- 按冻结规则重放选择过程，区分没有全局改善与改善被保护约束拒绝。

脚本只依赖 NumPy，使用 CPU，不加载模型或优化器，不重新训练或选择新模型。
输入是源 summary、六组 history.json 和四个 selection_A_*.npz；核验冻结协议、
源文件哈希、12 轮预算、更新步数、区域加和、保护决定与最终选择的一致性。
源目录只读，拒绝覆盖输出，也拒绝将诊断写进源目录。

原 summary 包含先前审计的元数据，但本脚本不读取审计数组、旧 val 或 test 数组。

## 解释边界与后续决策

在线拟合损失是在每批权重变化时累计的标准化 MAE，选择期是固定 epoch 权重的 raw MAE；
不能直接相减估计泛化差距。每轮仅保存总目标梯度范数的最大值，未保存逐项/逐区域梯度、
正则项损失或每批梯度方向；门控接近 1 不能证明正则主导，区域收支也不能证明梯度稀释。

先根据这次诊断确定缺少的证据，再设计有针对性的下一项实验。例如拟合在线损失下降但
选择期无改善，只能提示需要固定 checkpoint 的拟合/选择对比；局部改善被其他区域抵消，
只能提示需要检查目标权重或梯度冲突。不能据此自动调学习率、放宽保护、扩大容量或打开测试集。

本地验证：8 项诊断测试通过，包括真实训练器输出格式的合成端到端测试、
篡改输入拒绝、选择重放、区域加和、源文件不变和不依赖审计数组/检查点。
合成测试不构成真实数据的科学结论。
