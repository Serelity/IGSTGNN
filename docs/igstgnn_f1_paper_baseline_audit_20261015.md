# F1论文主基线与证据审计

日期：2026-10-15。目的：围绕改进原IGSTGNN、形成可发表的可信证据组织现有结果。原IGSTGNN是主baseline；MIN是结构中间对照；STATE是F1同结构的事故内容对照；同检查点ON/OFF是机制敏感性。不能因为某个OFF状态的MAE最低，就把研究目标替换为选择最低数字；也不能为了保留模块而隐藏负消融。

本次只读检查本地论文、源码、既有日志ZIP、历史验证预测及说明文档。没有训练、加载模型权重推理、访问服务器或评价新测试结果。F1正式837窗口结果依据用户回传；尚未在本地独立读取其服务器正式identity和预测NPZ。本地四窗口工程制品不充当正式精度证据。

## 1. 主比较必须分清四个层次

| 对象 | 论文中的责任 | 当前可以回答 | 不能替代的比较 |
|---|---|---|---|
| 原IGSTGNN，作者发布实现 | 首要主baseline | 完整改进方法是否优于前人系统 | 不能用MIN或STATE取代它 |
| IGSTGNN论文公式对齐版 `paper_aligned_v1` | 透明标注的实现敏感性/补充基线 | 某些论文公式与发布代码差异修正后，结论是否仍成立 | 不能改名为未经修改的作者发布实现 |
| MIN | 结构中间对照、已有成熟初始化 | 精简与潜交换路径组成的系统效果，新增候选相对当前基座的变化 | MIN已经包含历史P和受限潜交换，不是论文中纯粹删除ICSF/TIID的同一个模型 |
| F1 STATE / EVENT | 同注册架构的事故输入对照 | 相同新增适应预算下，事故条件版本是否优于状态版本 | 参数注册相同不等于语义参数梯度与有效自由度完全相同；不能单独证明每一条事故内容路径有效 |
| F1同检查点报告OFF、融合OFF、UNIFORM | 已训练模型的路径依赖与失败定位 | 当前推理使用哪些条件与分量、净收益如何抵消 | 不是删除模块后重新训练的结构消融，也不是真实无事故反事实 |

最终论文应以“原IGSTGNN → 明确的结构改造 → 完整候选”的逻辑组织，MIN/STATE与敏感性分析负责解释增量，而非另立一个更容易超过的主目标。

| 课程 | 历史复现保留warm30/cl3 | 新阶段每次完整12步损失 | 显式协议差异；不能假称源优化器精确续接 |
| 指标 | MAE/RMSE/MAPE；测试逐时距及12步平均 | 验证选模为全有效点pooled masked MAE，同时输出pooled与horizon macro | 需要同集合、同掩码、同聚合方式，不能只看指标名称 |

F1协议文件：[min_forecast_fusion_v1.json](../experiments/chronological/min_forecast_fusion_v1.json)。发布加载器：[igstgnn_published.py](../src/utils/igstgnn_published.py)，训练/验证边界为`[0,3909)`、`[3909,4746)`，测试为`[4746,5585)`。保持原标准化统计量与数组，不重新拟合scaler。

F1虽然存储在`experiments/chronological_runs/`，实际使用的是上述作者发布协议；不能仅按目录名把它认成旧chronological/v8数据实验。

原论文Table 4/5的Contra Costa完整IGSTGNN：测试12步平均MAE **13.43**、RMSE **22.50**、MAPE **15.84%**；H3/H6/H12分别为`12.50/21.37/14.14%`、`13.44/22.83/16.01%`、`14.81/24.13/17.95%`。这些是论文测试结果，不是F1当前验证baseline。

因此F1验证MAE13.696既不能直接证明优于，也不能直接证明劣于论文测试MAE13.43。历史chronological/v8协议中的22.xx也不能与本发布协议13.xx横向计算提升。

## 4. 当前F1可以写到什么程度

下表仅整理用户回传的正式837窗口验证结果，属于同一个F1评价的不同模型/状态，**不是与论文测试表直接排名**。正式服务器评价目录为`experiments/chronological_runs/contra_min_forecast_fusion_f1_bs64_seed2025/forecast_fusion_evaluation_20261015_120750_e7476e`。本次尚未本地核验该目录的正式数组，不能把报告回传升级为独立制品验收。

| STATE | 13.771632498 | 23.217150927 | 21.731100443% |

| EVENT_UNIFORM | 13.788427569 | 本表未转录 | 本表未转录 |

可以报告：同新增预算的EVENT在当前验证上优于STATE；回传显示13/14道路、12个时距的MAE比较方向一致。仍须披露MAPE相对源MIN退化、多种指标权衡、单种子和反复研发验证集。

必须保留的负发现：

1. 当前EVENT检查点开启融合比关闭融合的MAE更差，净作用约−0.05951；融合开启的RMSE稍好，存在取舍。不能把“整个候选优于旧MIN”改写成“融合模块已被证明必要”。
2. 报告上下文ON/OFF的horizon macro净MAE约+0.000487778，支持事故内容存在很小的检查点敏感性，尚不足证明强事故建模优势。
3. ON优于UNIFORM约0.092169107，但两者均逊于FUSION_OFF的MAE。异质权重优于统一缩放不能自动证明优于原固定求和。
4. EVENT相对STATE的净宏收益约0.075377182，其中remaining区域贡献约0.066842460；不能把剩余区域当自然无事故，也不能凭总体收益宣称事故传播得到改进。
5. 固定源偏差分组中低估与高估贡献约+0.593884407、−0.518507301，表明显著抵消与误差重分配。该分组用真值事后定义，不能直接作为推理门控输入。

FUSION_OFF可作为诚实的诊断、潜在精简配置与今后的机制研究线索。当前研究主线仍是改进原IGSTGNN并解释有效机制；不因最低MAE自动把这个敏感性状态升为已经验证的最终论文方法。反过来，也不能为了发论文强保一个已有负消融的模块。

## 5. 拟写论文claim所需对照

| 拟写claim | 必须对应的证据 | 当前已有 | 尚缺/当前不可写 |
|---|---|---|---|
| 完整新方法优于原IGSTGNN | 同发布数据、同目标/掩码/聚合、验证选模后固定测试；实现版本、训练预算披露 | 原发布实现真实权重/日志；对齐版权重、完整验证预测；F1正式验证回传 | F1固定方案测试结果与原版同口径对照未完成；不能拿F1验证对论文测试算提升 |
| 改进优于MIN中间结构 | 同任务评价，完整方案和旧MIN明确区分，额外适应预算披露 | SOURCE_MIN缓存及F1配对制品回传 | 相对旧MIN的差异包含结构与新增联合适应，不可全归于结构 |
| 事故信息提高同结构系统效果 | STATE/EVENT同初始化、样本顺序、完成预算和选模规则 | 当前配对训练/评价设计与回传正差异 | 多种子、独立外部检验仍缺；同注册量的活动参数差异需披露 |
| 正确事故内容在推理时有价值 | 同EVENT权重报告OFF、语义UNK、位置内容对照；真实信息优于负对照且局部证据一致 | 报告OFF很小净收益；UNK/位置重排已存 | 不足证明强内容作用；重排可能分布外，不能宣称事故因果 |
| 动态分量融合是改进必要机制 | 同权重敏感性 + 对应结构重新训练/匹配适应对照，不能只比较删输出分量 | 当前融合OFF/UNIFORM配对结果 | 当前MAE负消融直接不支持必要性；删除后重新训练可删除性仍未知 |
| 融合在训练中改善主干，推理可以删除 | 同起点、同新增预算的无融合适应对照或其他可识别设计 | 关融合后当前主干较好 | 目前不能把收益归因于融合训练；不因这一claim自动重训MIN |
| 物理先验/容量—传播机制改善预测 | 与自由神经交换/无约束结构的匹配对照、链条诊断及物理观测标定 | MIN潜交换工程约束与历史记录 | F1未新增容量或事故传播机制；无量纲预算不能称真实车流容量/守恒 |
| 道路与长时距普遍稳健 | 预先固定道路/时距、困难窗口、流量层、重复种子及独立集合 | 当前道路/时距分层的正差异 | 不能把重叠窗口、站点预测点当独立事故重复；不能由单种子认定显著性 |
| 更高效/更轻量 | 相同硬件、原batch/精度、完整端到端测量，计算实际调用与参数量 | 单次主干、440950注册参数，旧baseline约455220或454581 | 当前结构理论计算不是服务器耗时优势；不同batch/版本不能直接算提速 |

## 6. 当前授权下的下一步：先补证据，不自动重训

1. 继续分析F1已经保存的八状态预测，检查事故关联节点、预测时距、流量与源偏差交叉，明确哪里有净正作用、哪里产生负融合作用。
2. 优先复用已有对齐版837窗口验证预测，建立单独标注的baseline桥接表；核对目标、mask和原样本/站点轴后再配对。原发布实现只有日志时维持历史参考级别，不伪造逐点对照。
3. 若需要原发布实现逐点对照，先核查原服务器的已有权重、原版本环境与是否已经存过预测；本任务不自动启动新训练或推理。确需补一遍旧权重回放时，也应明确它是恢复基线证据而非重训。
4. 分析确定可辩护的机制后再设计一个小结构候选及最小对照。不把事故内容、融合结构、物理头和训练协议同时更换，也不为预期论文结论删除负结果。
5. 固定最终方法、主baseline版本及评价口径后，统一安排最终测试与必要的稳健性确认。当前验证集已多次用于研发，测试不用于继续挑结构。

出版价值需要任务改善、机制证据和诚实边界共同支撑；“比中间结构更低一个平均误差”与“为解释保留所有新模块”都不能单独成立。

## 7. 已有数据独立性边界

本地既有审计确认发布数组跨集合有重复交通观测：测试目标帧10,068次出现中6,816次与训练X/Y完整帧匹配。该67.70%是帧出现次数比例，不是事故或样本比例。本次没有重新访问测试目标或重跑这一审计；引用的是已有[数据核对记录](../../复现结果/核对与源码学习_20260909/01_Contra数据与评估核对.md)。

这不妨碍透明地在同一发布协议下对照前人方法，但不能将其描述为已认证的严格时间/事件独立泛化。若另建chronological或事件隔离协议，必须让所有模型使用同一新协议，另表报告，不能与旧13.xx混排。
