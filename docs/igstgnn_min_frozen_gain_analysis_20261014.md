# 冻结 MIN 位置预算适配器：已有配对预测收益分析

日期：2026-10-14。

## 问题与范围

服务器十轮小试中，源 MIN 最佳轮次为 28，适配器最佳轮次为 10。验证 pooled MAE 从 13.944357853 降到 13.907437003，改善约 0.2648%；pooled RMSE 从 23.502925867 降到 23.466435830，改善约 0.1553%。MAPE 从 18.315216% 升到 18.458309%，恶化约 0.143093 个百分点。全部十二步 MAE 改善、全部十二步 MAPE 恶化。

固定基线的 84 个困难窗口中，65 个改善、19 个变差，均值 MAE 从 18.849744923 降到 18.803839121。这是原 MIN 高误差窗口集合，不是独立标注的事故困难集合。

开启分支后预测平均上移约 0.466883，平均绝对变化约 0.483638。这提示需检查低估补偿和低流量代价，但尚不能断言收益来源。本项只分析保存的预测，不训练、不调用模型、不加载检查点内容、不评价测试集。事故内容置乱对照不在本项范围内。

## 输入与对齐

源为 `contra_min_i_frozen_loc_v1_bs64_seed2025` 的 `baseline_predictions.npz`、`best_predictions.npz`、身份、基线、历史、总结和原保护证书。NPZ 只允许无 pickle 的数值数组，要求 ON/OFF/目标/有效掩码均为相同 `[N,12,V]` 轴；目标、掩码、样本 ID、固定困难窗口与基线归档一致，OFF 逐点等于固定 MIN。

按历史重新核对包含第 0 轮的最小 pooled MAE，平局保留最早轮次。重算已有配对指标，并与最佳历史行、源 summary、基线证书相互核对。这个核对是 **saved artifact consistency**，不是新增模型或检查点回放认证。`last.pt` 只读取字节计算哈希，不反序列化。

旧归档没有保存事故区域，因此只为补齐对应窗口的区域元数据，重读哈希匹配的作者发布包和候选图。按原作者样本 ID、站点顺序、float32 反标准化运算逐点核对原 `y_data` 与保存目标，防止读错数据、站点或窗口。正式样本必须完整覆盖原 837 个验证窗口；旧工程运行只允许其原四窗口前缀，并始终标为工程范围。

原 `incident_all.npy` 是约 866 MB 的对象数组，需要反序列化整包，无法声称没有读取测试载荷；只检查选中的验证目标和事故关系，不遍历或评价测试记录。程序使用 CPU、NumPy 和标准库，不需要 GPU，但读取和解压发布包仍占用主机内存。

## 固定分层

1. **真实流量区间**：默认 `[0,5)`、`[5,20)`、`[20,50)`、`[50,100)`、`[100,200)`、`[200,+∞)`，均为作者原流量尺度，物理单位不重新认证。不按验证收益或分位数调边界。可选 `--flow-edges` 仅支持显式递增、从零开始的固定左边界，并记录在来源文件中。
2. **原 MIN 的偏差**：以 `OFF−目标` 的符号固定分为 `over`、`under`、`exact`。ON 即使跨过真实值，也仍留在原 OFF 分组。
3. **事故关联三分区**：`direct_report_nodes` 使用原 float32 关系非零支持及报告存在/关系可用标志；`potential_only` 是这些支持节点所在内部候选图弱连通分量的其余节点；`remaining_nodes` 是分量包络之外。三组互斥完备，后两组不能解释为已证实传播区和无事故区。
4. **交叉分层**：六流量桶 × 三偏差组 × 三事故区域，共 54 个交叉组，空组保留不可用状态。

流量区间和高低估分组使用真实目标，仅用于事后诊断，不能直接作为预测时可用特征或新增门控。事故区域没有使用未来目标定义。

## 指标与读法

每组输出 pooled MAE/RMSE/MAPE、ON/OFF 平均有符号误差、十二步误差收益、正负收益及抵消、预测上升/下降/不变点数比例、误差改善/变差/不变点数比例。

正收益统一为 `OFF误差−ON误差`；有符号预测变化统一为 `ON−OFF`。MAPE 在 JSON/CSV 中是比例，在报告中是百分数，贡献和收益列明确使用百分点。共享原有效掩码，MAPE 另外排除零分母，不把原掩码已排除的点加回。

同时报告组内收益、组的有效点数占比，以及使用全网共同分母的 MAE/MAPE 贡献。每一个互斥分层族及完整交叉族都必须满足点数和贡献加总守恒，包括逐预测步守恒。MAPE 使用全网正目标点数，可能不同于 MAE 分母；RMSE 不声明线性贡献可相加。

空组的局部指标为 `null`，有全网分母时其零质量贡献为 0。抵消比例是误差变化量的指标，不能解释为相应比例的样本无作用。预测上升点比例单独按点计数，不能用有符号均值和绝对均值的比值代替。

读结果时先看：MAPE 代价是否集中在低流量桶；上调是否主要帮助原 MIN 的 under 组而伤害 over 组；直接关联和候选区域的组内收益是否超过仅由样本质量解释的全网贡献。交叉表再定位这些现象在何种区域重合。不能用目标可见的诊断分组直接制造新预测规则。

本项是已选验证检查点上的探索性归因描述，窗口和预测点可能重叠，不当作独立事故重复做显著性检验。它不能识别真实容量、事故因果或正确事故内容的独特贡献。
