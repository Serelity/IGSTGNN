## 三通道提供了什么依据

预先固定的诊断假设是 `q ≈ α·o·v`，q/o/v沿用源三通道名称。对每站的唯一时间，只用三个值均为正的样本，在1—4月以 `median(q/(o·v))` 得到α，再在5—8月检查；两段都属于训练期。这是观测关系诊断，不是交通预测测试或物理定律验证。

496站均有足够正值样本完成该诊断。按站点汇总：

| 描述统计 | 站点中位数 | 站点P10—P90 |
|---|---:|---:|
| 后期/前期的比例中位数之比 | 1.014 | 0.996—1.052 |
| 后期对称相对误差 `2·abs(q̂−q)/(q̂+q)` 的中位数 | 5.29% | 2.94%—13.82% |
| 占有率与速度的秩相关 | −0.706 | −0.840—−0.446 |
| 前期比例 `q/(o·v)` 的P90/P10 | 1.264 | 1.140—1.598 |

这些数值支持将共同三通道用于相对状态建模，显示总体关系并非完全漂移。**它们不证明源速度、占有率是独立观测，更不证明事故引起容量变化。** 源估计/插补过程可能产生通道依赖，目前未取得足够溯源证据排除这种解释。不能将5.29%写成模型预测误差或提升率。

各站p95参考量只用于相对数值尺度，均能取得正值，已随逐站表保存；不是最大通行能力。α带源单位，跨站差异不能直接解释为车道数或有效车长。正乘法单位变化不改变相对关系诊断，但仍不能修复车道聚合、时间口径或通道语义错误。

## 限制对模型设计的影响

按预先定义的代理：速度低于本地p95速度的60%，且占有率不低于本站p75，作为“低速高占有率”状态。它不是拥堵标签或容量饱和标签。去重时间上，**169站的此类状态少于100个时间槽，其中26站为零**。100只是本轮报告的描述性计数界限，没有用于选站或认证参数；连续时间槽也不独立。

因此应优先开发共享、低维的相对状态/容量扰动原型，避免为每站自由拟合容量、需求、密度和源汇。数据没有充分覆盖饱和状态时，低流量不能识别低容量；共享参数也只能提供建模假设，不能补成独立机制真值。

另外发现以下4对站点三通道完全重复：

| 站点 | 道路 | 源8个月缓存核对 |
|---|---|---|
| 402542 / 402543 | I680-S / I680-S | 每月完整payload相同 |
| 402071 / 402070 | SR160-N / SR160-S | 每月完整payload相同 |
| 424096 / 424104 | SR4-E / SR4-W | 每月完整payload相同 |
| 414838 / 414829 | SR4-W / SR4-E | 每月完整payload相同 |

因此496个站号实际有492组不同三通道历史流。原始源中已存在，原因未查明，不能称为新流程的站点错位，也不能自动称源数据造假或某种插补。保持原站点轴以便公平比较；物理证据和独立性分析须标记这些组，不用跨方向重复序列来证明传播。源数值可用不等于496份独立、真实、无插补的观测。

候选站序覆盖12个多站方向组；SR160每向一站不构成空间链。SR242-N、I680-N、I680-S各有一组同PM站，按组保存，不连接成零长度cell。里程顺序和方向仍只是传播候选，不能直接作守恒界面或车辆行驶长度。
