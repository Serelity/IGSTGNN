# M2.2：有界的非强制单调容量轨迹

2026-10-09。以下方案在实现和新的运行结果之前固定。**M2.2工程实现现已完成，26项测试、GPU完整Bash及全候选X检查通过。** 沿用M2.1共同X、掩码、训练参考尺度、报告条件、共享编码器及输出轴；本轮只改时间展开，不增加真实数据需求或空间连接。

## 形状与来源

原型希望表达报告后影响仍可能加重，再逐渐恢复。采用一个平滑单峰扰动核 `h(t,tp)=(t/tp)*exp(1-t/tp)`：t、tp均为分钟，h无量纲；t=0为0，t=tp为1，随后趋近0。它来自形状参数2的Gamma核，按峰值归一化；[NIST Gamma分布公式及众数](https://www.itl.nist.gov/div898/handbook/eda/section3/eda366b.htm)提供数学依据。这里借用时间形状，不假设事故服从Gamma分布，不把h当概率或实际处置过程；有限维参数化是本研究的待检验选择。

M2.1单调损失为 `b(t)=a*exp(-t/tau)`。新脉冲轨迹：

`loss(t)=b(t)+(0.95-b(t))*p*h(t,tp)`，`retention(t)=1-loss(t)`。

由于a≤0.95、p∈[0,1]、h∈[0,1]，loss是b与0.95的凸组合，容量保留比例始终在[0.05,1]。t=0严格保持1-a；p=0精确返回原指数版本，t趋于无穷时恢复到1。a=0但p>0允许报告时尚未下降、之后恶化；完全零扰动需a=p=0。单一平滑脉冲能表达一轮加重与恢复，不是任意多次波动，也不表示可以识别真实变化轨迹。

四个输出参数：a/tau沿用M2.1的映射；`p=clamp(0.10+0.20*u2,0,1)`、`tp=15+75*sigmoid(u3)`分钟。15—90分钟是工程假设范围，未从事故真值标定；tp是**核的峰值时间**，总容量损失的峰值通常不恰好在tp。初始p约0.1，不宣称新增曲线初始与旧版所有时距相同。clamp允许精确零但饱和时梯度为零，记录饱和计数。

核在非负时间连续可微，`|dh/dt|≤e/tp`；因此 `|d loss/dt|≤a/tau+0.95*p*e/tp`。这是实现的平滑性上界，不是测得的道路变化速率或传播波速。时间刻度为显式截止后分钟，仍不改变原流量目标时间协议。

## 四种参照与兼容

1. M2.1原指数恢复（两个头输出）保留，默认构造和checkpoint不变。
2. 新脉冲容量曲线（四输出）。
3. 同四输出的单调混合：`loss=(1-p)*a*exp(-t/tau)+p*a*exp(-t/tp)`。同样的a/tau/p/tp、共享权重和输入，只改变展开算子；它始终恢复，p=0也退回原指数。不是给旧两参数模型增加无用参数来凑数。
4. 同四输出的普通状态：`state=1+support*(u0+u1*tanh(t/60)+u2*h(t,tp))`，tp由u3给出，不加容量界。它用于后续控制额外输入和参数；不是当前已完成的空间传播参照。

后三种使用完全相同的可学习张量初始化。共同GRU、首层条件头以及最后头前两行可与M2.1严格复制；脉冲与混合的截止容量相同，但未来轨迹无需相同。配置显式记录trajectory，保存恢复不能只依赖形状一致的state_dict猜模式。事故条件关闭只影响新增路径，不改变原IGSTGNN或历史编码。

实测参数量：原指数1506；脉冲、单调混合、普通状态各1540，比原版多34个。新增两个输出分别承担扰动强度和时间尺度，所有输出头行在人工目标检查中均有非零有限梯度。四参数的单调混合用于检验“参数增加”解释；普通状态用于检验“额外信息/普通函数”解释。真正的预测比较仍须等同输入融合与训练完成。
