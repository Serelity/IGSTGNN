## 1. 新假设与已有证据

v12n 的六个端点都呈现 S_fit>S_selection>S_audit，且 audit 的越界损失 O 比前两阶段低。
因此，“后段只因修正幅度过大而失败”不能独立解释现象。S 同时包含修正幅度与残差符号构成，
这个观察也不能证明某种特定漂移或过拟合原因。

本轮假设：在完全相同的输入、架构和输出支持下，训练时增加对相对 A 受损较多的拟合期时间块的权重，
可能学到对开发后段更稳定的修正。预先接受无改善甚至进一步退化的结果。
这是一次有界的优化目标比较，没有增加模型容量或新外部信息，也不搜索最终输出缩放 λ。
不重启已失败的 v9b 残差/v11b 多通道方案，不把未认证为首报可用的事故描述纳入模型。

## 2. 固定的配对设计

| 因素 | 预先固定的取值 |
|---|---|
| 架构 | state_vector、interaction_vector |
| 训练目标 | 原始 ERM、temporal_excess |
| 随机种子 | 2025、2026、2027 |
| 每条轨迹 | 12 epochs，训练 batch 8，评估 batch 16 |
| 优化器 | Adam，lr=0.001，eps=1e-8，weight_decay=0，梯度裁剪 5 |
| 正则项 | 原候选节点向量能量，系数 0.001 |
| 训练预算 | 12 条轨迹 × 12 epochs = 144 epochs；每 epoch 190 步，共 27360 次 Adam 更新 |
| 被训练参数 | ICSF 向量适配器；A 的全部骨干参数冻结 |
| 输出 | 候选 H1–H6 使用修正 P，其余位置/时刻严格使用原始 A |

每个架构/种子的两个目标具有相同的新初始化、样本顺序、批次、训练轮数、评估次数和选择规则。
保留原始“种子→探针 DataLoader→创建适配器”的 RNG 消耗顺序。
ERM 直接调用原版 early_train_epoch；temporal_excess 在首轮 q=pi 时也调用该函数。
程序必须核对初始适配器、第一轮适配器及第一轮 Adam 状态的精确哈希一致，之后才允许冻结端点。
这不是重新挑选旧 v12m 权重；12 条轨迹都会重新学习。

## 3. 分期、分组与权重

沿用原 fit `[2023-01-02,2023-04-24)`、selection `[2023-05-01,2023-06-26)`、
audit `[2023-07-03,2023-09-04)`，保留完整支持区间与 embargo。
完整事故窗口分别为 1520、856、1010；selection/audit 匹配三元组分别为 206、378。

只按事故报告 t0 把 fit 划为四个连续 28 天块：

| 块 | 左闭右开日期 | 窗口数 |
|---|---|---:|
| 0 | 01-02 至 01-30 | 353 |
| 1 | 01-30 至 02-27 | 364 |
| 2 | 02-27 至 03-27 | 414 |
| 3 | 03-27 至 04-24 | 389 |

窗口允许跨块边界，分组只使用 t0；因此这些块是可能相关的训练环境，不能当作独立验证折。
pi_g 是各块在 fit 候选 H1–H6 中的有效**单元**占比，不是窗口占比。四块都必须有正支持。
固定公共尺度 L0=MAE_fit(A)，要求大于 1e-8。

初始 q=pi。每轮内 q 固定，对每个原始 minibatch：

```text
loss = sum_valid_early[(q_g/pi_g) * abs(P_standardized-Y_standardized)]
       / 原始有效 early 单元数
       + 0.001 * 原始候选向量能量
```

分母不按权重再归一化；不改样本顺序。缺失标签在误差运算前排除，避免 NaN 梯度。
每轮结束，完整推理 fit/incident_full，再更新下一轮权重：

```text
u_g = (MAE_g(P_epoch) - MAE_g(A)) / L0
v = softmax(log(q) + 20 * u)
q_next = 0.05*pi + 0.95*v
```

使用统一 L0，不能替换成每组自己的 A 误差分母。覆盖混合使每个单元倍率至少为 0.05。
更新率 20、混合率 0.05 不搜索；ERM 的 q 始终等于 pi。
权重更新只接收完整 fit 记录，selection/audit/control 的 Y 不进入优化器或权重更新。
这是一种超额损失乘法重加权，不宣称已获得总体分布稳健优化保证。

## 4. 选择、报告与判断

每个端点独立使用原 v12k candidate_early 选择器与全部 16 个 v12c 保护条件。
必须满足完整事故 global/early MAE 严格优于 A，再按 selection early MAE 选最低值，平局保留较早轮次。
没有合格轮次时保留 epoch 0=A。不按最差时间块选择，不让 audit 参与选择。
**全部 12 个已选检查点身份冻结后，才允许 audit 目标评估。**

主比较为 audit/incident_full/candidate_h1_h6 的 pooled `MAE_ERM−MAE_temporal_excess`。
对全部架构与种子同时报告两目标相对 A 的收益。即使优于 ERM，若仍差于 A，也不能说修正成功。
不以种子为独立样本求显著性，不选择最好种子作为主结论。

保留三个阶段、原四群体和四个主要区域。保存全部 21 个原始区域的逐窗口误差/支持，以及选定端点的
G/S/O、类别贡献和元数据。分析包括 pooled 与等窗口口径；按原连续周网格（保留空周）共享
2000 次普通周与循环四周块抽样。比较差值在每次抽样内直接计算，不能减两个边际区间的上下界。
匹配 D 使用同一组周抽样，报告 pooled/等完整三元组及任一成员支持区间删周敏感性。
区间是逐项、条件于已选权重的描述，不是所有机制结论同时成立的联合 95% 保证。

若有改善，仍只是反复使用的开发区间上的机制证据；若无改善，保留负结果，不追加 rate、mixture、
epoch、seed 或 λ 搜索。完成一次比较后人工审查，不自动进入主模型训练或 test。

## 5. 工程验收与恢复

小包使用 seed 2025、每条轨迹两轮；每个 fit 块取最前最多两个窗口，总计 8 个真实 fit 窗口。
其他阶段/群体各两个窗口。保留四个组，四条轨迹实际反向传播；小包不做科研 bootstrap，
科学状态固定为 `NOT_EVALUATED_ENGINEERING_ONLY`。

恢复快照在每轮结束原子保存当前适配器、Adam、下一轮 q、连续历史、历史最优、RNG 与输入/代码/设备身份。
恢复时独立复算 q 与选择结果，并检查当前/最优/优化器哈希、更新步数和设置。
可恢复 epoch 0；已完成轨迹只重建评估，不再优化。源目录只读，恢复必须使用新名称；
既有 output、partial、job 和符号链接不能覆盖。当前正式恢复要求相同设备类型、GPU 型号、Torch/CUDA/NumPy/Python 版本及输入路径哈希。

服务器日志记录训练进度、真实参数/输入/预测设备、梯度前向、优化器步数和 CUDA 显存。
本地 CPU 只能证明工程路径；V100 正式运行及速度/显存需由服务器日志验证。

## 6. 独立确认的后续边界

本轮程序不读取 val/test，不获取 2024 数据。旧 A 曾在更完整的 train 上预训练、在 validation 上选过检查点，
scaler 也利用了整个 train X，所以三段划分不能被包装为一个完全独立的泛化试验。

候选后续是单独的 2024 年份队列。先在不查看预测结果的前提下认证源版本、事故身份、首报可用性、
传感器覆盖及完整时序支持，再冻结队列与评价规则；目前连续窗口尚未完成物化。
A/scaler/adapter 的拟合、模型与方法选择必须全部早于确认期。如果既有来源记录不能证明，
需重建经过认证的仅用过去信息的训练包。不能把反复使用的 2023 audit/val 或已暴露 test 改名为新确认集。
确认系统与队列冻结后再看目标，保留全部规定种子、配对基线和常规交通保护，不根据确认结果调参。
