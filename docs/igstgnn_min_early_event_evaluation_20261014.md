# MIN-E1：模型评估、模块作用与后续改进方案

_2026-10-14。与单次事故条件模块配套；首轮为开发性评价，不将重叠预测点视为独立事故。_

---

## 🎯 三个分开回答的问题

| 问题 | 证据 | 不允许的替代解释 |
|---|---|---|
| 新方案是否改善预测？ | 同预算STATE与EVENT完整验证、共同轮次/前缀最佳、曲线及条件指标 | 不能只比较EVENT5轮和旧MIN28轮，再归因事故 |
| 模型是否使用事故内容？ | 同EVENT最佳检查点REAL、OFF、语义UNK、完整位置重排 | OFF主干已随EVENT训练，不等于原MIN；扰动结果不是真实事故因果效应 |
| MIN各路径贡献何在？ | 捕获5扩散＋5固有forecast，移除指定分量后复用原头逐点评价 | 不能将forecast直接读出贡献冒充整个编码/backcast分支的可删除性 |

本轮先保证这三个问题清楚，再决定下一处改进。原MIN模块减法研究见[模块必要性主线](igstgnn_min_dataflow_effectiveness_plan_20261014.md)；本轮预测分量筛查是其低成本部分，不表示已完成全部模块的必要性验证。

## 🛡️ 回放与保护先于解释

评价只读每组`last.pt`的`best_model_state`，不用最后一轮权重冒充最佳。复用训练时原837验证顺序、batch64及尾批、站点轴和原尺度。先完整回放各组ON并核对保存最佳轮的作者pooled MAE/MAPE/RMSE；任一失败就不许可事故OFF或forecast移除。

完整回放通过后，同批执行EVENT ON→干预→ON。恢复ON逐元素一致；参数、缓冲、输入、图、梯度、训练标记、RNG及源文件保持不变。插桩按上下文清理，异常也移除hook。推理中不调用优化器、不修改checkpoint、不评价测试集。

同执行环境要求重组原预测与恢复预测精确一致。保存指标回放保留既定数值容差，不能放宽到掩盖行为差异；数值抖动与训练随机性是两回事。

## 🧪 默认推理状态与比较

| 状态 | 操作 | 回答什么 |
|---|---|---|
| STATE_ON | 状态控制组最佳权重正常预测 | 同预算、同架构控制 |
| EVENT_ON | 事故组最佳权重正常预测 | 完整候选 |
| EVENT_OFF | 仅禁止新增early调制，剩余训练后主干保持 | 新增条件路径的检查点依赖 |
| EVENT_SEMANTIC_UNK | 保留真实M/D，类型/描述改为UNK并将有效标记关闭 | 对语义内容的敏感性，可能有分布外影响 |
| EVENT_LOCATION_SHUFFLE | 对每个样本将完整D向量在全站作确定性重排，包含零行；语义不变 | 对支持位置及关系配置的敏感性，可能有分布外影响 |
| LOCATION_ON，可选 | 若该组已独立训练，则正常评价 | 语义增量的训练对照 |

位置重排以固定seed及原全局sample_id决定，不读目标、不消耗训练全局RNG；记录支持/向量实际移动覆盖。它与旧“支持内D重排”不同，但依然不保证随机事故位置在道路语义上合理。REAL胜过重排只是对当前信息配置的依赖证据，不等于已排除全部混杂。

可选LOCATION须在训练前写入组集合；不允许在已有identity里悄悄改组。默认两组从头配对训练，保持STATE完全不读事故。若某些组没有完成相同轮次，共同前缀比较与各自最佳评价分别报告，不能假装预算相同。

## 🧭 各层预测分量审计

EVENT正常前向捕获五层扩散forecast和五层固有forecast。按原`sum(dif)+sum(inh)`顺序重组，经过相同repeat、ReLU、原预测头和gap通道选择，先验证完全等于EVENT_ON。

随后得到12个直接输出干预：10个单分量移除、全扩散forecast移除、全固有forecast移除。保持原backcast和后续层输入，避免把多种作用混在一起。每批捕获并释放隐藏张量，不保存837窗口的全部10份高维特征。

对原预测\(\hat y\)与干预预测\(\hat y_{-m}\)，逐样本、站点、时距保存并分析：

\[
\Delta\hat y_m=\hat y_{-m}-\hat y,\qquad
g_m=|\hat y_{-m}-y|-|\hat y-y|.
\]

正g表示保留该路径有益；预测改变大不表示误差改善。原头非线性，多个路径的边际作用不能简单相加。若某分量弱或有害，只列为后续删除候选，不直接删上游编码、残差或整层。

完整逐层潜交换、图消息、门控、归一化和整分支删除留待相应候选证据出现后再开发；默认评估不扩大成指数级组合。可通过`--skip-forecast-audit`先跳过这12种诊断，其他内容评价照常。

## 📊 指标与固定参照

同时报告作者pooled MAE/RMSE/MAPE与12步宏平均、每步MAE/RMSE/MAPE。MAPE在JSON为比例、Markdown标百分数；作者流量尺度未重新认证物理单位。所有状态共享源有效掩码，不按候选重新筛数据。

开发分析至少覆盖：

- 道路/站点区域与12步时距；直接报告关联、候选图包络、其余节点。
- 真实流量固定桶[0,5)、[5,20)、[20,50)、[50,100)、[100,200)、[200,∞)。
- 按STATE_ON与真实目标固定划分高估、低估、恰等，不随候选改标签。
- STATE_ON选出的最差10%完整窗口固定集；各状态自身窗口P95/最差5%另行报告。
- 逐点正收益、负收益、净收益、抵消比例、预测变化方向和胜负点占比。

流量桶与误差符号是事后诊断，不能作为线上门控输入。报告关联范围来自作者关系编码；候选范围来自图结构，不是真实事故传播认证。其余区域不是已证明无事故区域。区域互斥分解要核对全网贡献守恒；额外重叠道路/条件分组不可相加。RMSE不作线性贡献分摊。

## 🔬 机制记录怎样用于改进

`mechanisms.json`记录调制的支持规模、通道gamma/隐藏增量的绝对量与方向、各批的调用覆盖，以及原潜交换约束摘要。与实际预测收益一起解释，不仅凭gamma大或attention高来断言有效。

| 观察到的结果 | 优先检查/下一项 |
|---|---|
| 调制输出不为0但预测几乎不动 | downstream是否消除/忽略该通道，再选择接入位置；不先加更多分支 |
| EVENT与STATE相同，真实/内容干预也相同 | 事故内容独特贡献弱，检查字段、支持与语义，不把额外参数收益算事故收益 |
| 只改善原低估点，几乎全网上调 | 检查是否形成条件校准偏置，并查看低流量/MAPE代价 |
| 局部事故区有效，全网均值弱 | 检查分层流量、固定困难窗口与道路一致性，避免平均数淹没局部作用 |
| 某层forecast移除后更好 | 核查交互与直接读出，再另做实际精简验证 |
| 语义UNK无影响，位置重排影响明显 | 优先研究位置/关系处理，不立即扩大语义编码器 |
| 条件强度早期饱和或梯度异常 | 核查尺度、有效标记和残差接入，不用提高调制上限掩盖接通问题 |

上述是决策规则，不是预言结果。首轮若未超过STATE且没有明确内容作用，不直接安排百轮；先依据保存预测定位问题。反复使用的验证集属于探索，后续正式主张需独立种子/留出证据；不对数百万重叠预测点作独立样本显著性检验。

## 💾 制品与复用

保存`paired_predictions.npz`及目标、valid、原样本编号/站点轴；`analysis.json`、`report.md`、`mechanisms.json`、`replay.json`、`preservation.json`和可比性记录。预测保存float32、指标逐时距用float64归约，不导出数千万行逐点CSV。后续分层或画图优先读取这些制品，不重复训练或推理。

本轮默认测试集不评价；已有MIN测试结果只作为已存历史记录。最佳checkpoint已由同一验证集选择，干预后的差异仍是该检查点上的开发性证据。
