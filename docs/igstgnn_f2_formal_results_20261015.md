## 📌 比较身份

论文主 baseline 是原 IGSTGNN。MIN 是中间结构；CONTROL 是相同成熟 MIN 最佳权重的额外纯主干微调；STATE/EVENT 是同源的 F2 联合微调。三组均完成阶段 5、310 次更新，最佳阶段均为 5；只有一个种子，尚不能判断收敛或稳定泛化。

成功评估目录：`contra_min_component_f2_bs64_seed2025/component_fusion_evaluation_20261015_164939_5bcf01`。之前的 `component_fusion_evaluation_20261015_164215_5d1652` 被 KeyboardInterrupt 中止，只含 failure.json，不用于完整效果比较。

## 🔎 选择性问题没有消失

下表由回传中相同分组的 `STATE_vs_CONTROL + EVENT_vs_STATE` 作算术相加，得到完整 EVENT 相对 CONTROL 的 pooled 差值。不是新增逐点分析。

高流量桶的正贡献与低于 200 的合计负贡献 −0.090155765 抵消后，得到全网改善约 0.081300343。真实流量只能事后分组，不能成为推理门控。

融合本身相对当前 EVENT 主干在低流量桶有正收益，并改善 MAPE 约 0.5094 个百分点；当前 EVENT 主干关闭融合后，相对 CONTROL 的 MAPE 仍恶化约 2.5550 个百分点。因此，不能把完整模型的低流量/MAPE 退化全部归咎于最终融合。当前报告未给出完整预测有符号变化统计，不能把旧版的 96% 上调结论套到 F2。

## 🧩 五问题的当前状态

| 原问题 | F2 后可以判断什么 | 仍缺什么 |
|---|---|---|
| 关系细节缺少额外价值 | 报告即时作用仍接近零；总体 EVENT 优于 STATE 不能替代报告内容证据 | 区分信息冗余、入口受限、训练路径差异；真实内容与仅支持位置的匹配控制 |
| 修正缺少选择性 | 融合有益，但完整模型仍以高流量改善抵消低流量恶化 | 只用历史可见证据决定怎样改，而非真值桶或误差标签门控 |
| 跨槽状态职责不清 | MIN 已有四块递推；F2 仅提供十二槽融合权重，没有新的事故持续状态 | 检验是否需要共享响应状态，不能先认定 GRU 必胜 |
| 局部约束与输出联系弱 | 潜 exchange 的工程约束仍满足；F2 不新增事故传播 | 约束的预测必要性、可观测读出联系；不能称已识别车辆容量 |
| 只训练小模块限制适应 | F2 已全主干与融合器联合训练，此限制已处理 | 联合训练后的主干漂移与结构收益应继续区分；解冻不再算创新 |

均值权重呈 DIF 多数大于 1、INH 多数小于 1，提供“普通分量族校准”的竞争解释；权重均值不等于重要性。零和最大残差 5.2154e−8、最大增量 0.0870、幅度收缩触发 0，不能解释为预测无偏或物理守恒。
