## 指标与产物

主指标继续使用全部原验证行、496站、12个原目标窗口的时距宏平均池化MAE。逐有效位置定义`d=abs(OFF-target)-abs(ON-target)`，正值表示开启报告改善预测；只关闭新增容量报告路径，原IGSTGNN事故路径的含义沿用源探针。

- `G_plus`与`G_minus`分别是正向改善和负向恶化的绝对量，均使用相同区域与时距分母，净收益为两者之差。字段为`gain_positive/gain_negative/off_minus_on_mae`。
- `global_gain_contribution`是区域对全网净收益的贡献K，使用全网每时距有效目标数作分母。直接关联、包络内其他节点、有支持样本的包络外节点、无支持样本四区域互斥穷尽；贡献能加回全网。各区域自身MAE收益不能这样相加。
- 空区域MAE、G与宏平均响应为null；全网分母有效时空区域K为0。部分时距为空时区域宏平均也不可用，保留其他时距结果。
- 输出响应的时距宏平均、全位置池化均值、未加权分位数、最大值及超过`1e-4/1e-3/1e-2/0.1/1`的比例。两种均值分开命名；时距有效数不同会使它们不同。
- 逐位置检查误差变化的三角界，并逐时距检查更强的`G_plus+G_minus<=平均绝对预测变化`。抵消率为`1-abs(G)/(G_plus+G_minus)`，正负总和为零时为null。

| 文件 | 内容 |
|---|---|
| `analysis.json` | 全网、四区域、旧静态区域、道路、报告年龄、时距与权重敏感性，身份及哈希记录 |
| `gain_decomposition.csv` | 各区域宏平均与12个时距的收益、正负项、K及响应均值 |
| `trigger_event_summary.csv` | 按原触发事件ID汇总，附全网贡献、支持与响应行数 |
| `cutoff_summary.csv` | 按原截止点汇总，附全网贡献、支持与响应行数 |
| `README.md` | 简短结果说明与对称的改善/恶化案例 |

道路、年龄等表交叉重叠，不能全部相加。触发事件ID不等于逐条匹配报告实体身份；并发报告不能强行归因给触发事件。触发事件/截止点逆行数加权仅为敏感性结果，有缺测差异时不等于先算每组MAE再等权。窗口重叠与共源站点不提供独立重复，本工具不输出p值或现实因果结论。

## 如何用结果推进模块改进

先同时看绝对响应量和响应比例，再看正负项与K：净收益近零可能来自两者都小，也可能来自较大的正负抵消；抵消率高而绝对响应极小不能单独称为明显机制。道路/时距表用来解释已有候选，不按验证收益更换道路、扩大匹配范围或删样本。

本步不能直接定位裁剪、梯度或可辨识性问题；已有聚合路径曲线也不能恢复逐事件梯度。M4.6仍是独立新版本的历史容量基准加报告修正候选；其单条件槽、系数空间关联混合与梯度验收已写入设计，待本次真实分解后开展。训练收益与推理ON/OFF敏感性分开解释。
