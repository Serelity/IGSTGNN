## “有用”分成三种证据

1. **计算是否实际参与。** 查看前向调用及梯度；未执行的模块没有当前直接预测作用。执行次数、参数量、梯度大小和权重均值都不是收益排名。
2. **固定检查点是否依赖。** 在相同输入/权重下关闭或替代一条路径，比较误差；这是条件敏感性，可能包含分布外输入。关闭变差不能证明重训后不可删除。
3. **结构是否值得保留。** 完整模型与删除/替代版本在同协议下重新训练，比较固定预算与一致选模结果。单种子接近或不显著不能证明无用；需要重复及预先定义的实用等价界。

每个模块输出“收益×稳定性×资源代价”的表，标为强正作用、弱/条件作用、负作用、闲置或证据不足。保留MAE/RMSE/MAPE的取舍，不因一个指标小差异自动删除模块。

## 第一轮：原检查点固定权重筛查

先恢复原代码、数据字段解析、标准化、站点顺序、原验证837窗口与原批次划分，严格加载已有权重。完整FULL对历史指标及重复回放通过后才允许干预；回放不符时先定位差异，不能直接给模块排序。首轮已复用已有原检查点；用户随后允许再训练一次完整原版，建立新来源证书，不意味着分别重训十二个状态。

已实现并运行的首轮12个唯一状态：

| 组 | 状态 | 干预定义 |
|---|---|---|
| 基准 | FULL | 原模型完整路径 |
| 总体分支 | DIF_FORECAST_READOUT_OFF / INH_FORECAST_READOUT_OFF | 仅在最终forecast汇总时置零一类读出；保留全部backcast、残差、后层 |
| 报告分工 | ICSF_ONLY | 原ICSF开启，TIID关闭 |
| 报告分工 | NORM_ONLY | 最新历史保留原LN，无报告注入与TIID |
| 报告分工 | TIID_ONLY_ON_NORM | 使用NORM历史，同时复用FULL原生事故context给TIID，不重新定义context |
| 归一化参照 | RAW_ALL_REPORT_OFF | 原生incident_data=None路径；与NORM_ONLY区分LN作用 |
| 图类型 | PRE_BANKS_ZERO / DYN_BANKS_ZERO / STA_BANKS_ZERO | 所有20次卷积的gcn_updt输入中清零对应bank切片，保宽度/bias/其他bank，不重标定 |
| 时间组件 | GRU_TRANSITION_IDENTITY | 所有历史和生成GRUCell调用以输入作恒等替代；其余流程照常 |
| 时间组件 | ATTENTION_QUERY_IDENTITY | 所有历史和生成attention调用以query作恒等替代；保留位置编码及外层dropout |

这些状态只给条件路径依赖，尤其DIF/INH读出OFF不等于删除整条分支。GRU/attention恒等替代可能严重分布偏移，退化只能作为后续重训优先级线索。先粗筛后细化，estimation gate、各层读出、backcast/LN拆分另列第二轮，不一次穷举所有交互。

ICSF/TIID组合中动态图随当前历史按原计算重建；若需分开内容注入与构图响应，再增加FULL使用NORM动态图的状态。计算路径发生变化的效应不能相加为独立贡献百分比。

所有干预使用eval/inference_mode；检查参数/buffer、输入不变和调用覆盖，结束恢复FULL并核验。原BatchNorm统计不更新，临时hooks在异常时也须移除。清零bank仍执行其原计算，不能用这类诊断耗时声称真正删除后的速度收益。

报告全网MAE/RMSE/MAPE、逐时距、道路、事后流量分层、固定FULL困难窗口和正负抵消；预测点/重叠窗口不作为独立实验重复。当前只测完整推理与被动模块内部前向，未测正式训练速度；后续结构比较需另测同硬件原batch/精度的完整前向、反向、更新和峰值显存，避免重复之前的前向外推问题。

## 第二轮：只对关键结论补结构重训练

对低/负依赖且成本高的模块检验真实删除价值；对高依赖模块检验其具体机制是否优于简单同容量替代，不机械保留所有高依赖设计。DIF/INH真正删除需同步定义backcast/残差路径，保留LN的零backcast与整个块旁路分开标记。

各组同数据、split、scaler、mask、初始化规则、样本顺序、完成优化更新预算和选模规则。共同参数可按键共享同一初始张量，但不能用完整模型成熟权重暖启动删除版并叫从头消融。没有匹配完整控制时，旧完整训练不能冒充新增微调控制。按种子配对重复，先报告探索性差值，再对候选固定方案确认；本阶段不查看测试集挑模块。

现有`audit_architecture_mechanisms.py`与`probe_b3_r_modules.py`的模型合同均不适合原558ab01，不能直接复用其启动命令。独立入口为`evaluate_original_igstgnn_modules.py`；`train_original_igstgnn_baseline.py`仅训练完整原版，不训练十二个干预状态。

本轮采用experimental-design技能的配对、对照、重复与交互边界原则；技能工作流不作为模型有效性证据。
