# 回到原始 IGSTGNN 的单模块改进边界

2026-10-15。用户最新要求：“我觉得还是在 IGSTGNN 的基础上改吧”。本记录更新后续研究起点；不是新模型效果或训练完成报告。

**执行顺序修订：**用户进一步明确第一步是识别原IGSTGNN内部哪些模块有用、冗余和收益较高。因此先完成[原模型模块价值审计](igstgnn_original_module_value_audit_20261015.md)，下文DIF子槽选择暂缓，不能当作已经选定的开发任务。只有审计结果定位具体问题后才确定结构修改。

## 起点已经核对

以本地 Git 对象 `558ab01:src/models/igstgnn.py` 保存的原发布实现作为可追溯的代码参照。当前工作区同名 `igstgnn.py` 包含论文公式对齐与后续接口，不能仅凭类名把它当未经修改的原版。历史训练 ZIP 缺完整启动/Git证书，代码参照不等于独立认证历史服务器运行版本。

原流程为：交通嵌入 → ICSF → 图构造 → 五层 DIF→残差INH → 两类 forecast 汇总 → TIID → 原 gap=3 预测头。每层 DIF/INH 已有四个预测块递推，不是无时间状态模型。

首轮候选保留原输入字段与解析、ICSF、TIID、图构造及支持、INH、残差结构、层数、四块预测递推和读出。学习率、宽度、batch及训练预算不作为模型创新。原版与候选使用同一明确的数据/训练/评价协议；原版和公式对齐版分别命名。

## 当前条件传播分支的处置

不再将 MIN 条件传播替换核作为本轮默认主线。它同时改变报告入口、跨窗值变换、图硬支持等多个环节，且服务器已观察到约77–79秒/训练batch，不能只靠前向算子提速证明训练成本可接受。

本轮尚未发布的训练性能优化保存为本地草稿，位置为 `experiments/chronological_runs/conditional_training_perf_20261015/paused_training_optimization.patch` 及相邻源码副本；相应三个工作区文件已恢复至原 HEAD，未提交/推送该草稿。已有实验、模型与已发布提交保留。

## 暂缓的结构候选：DIF 内部子槽汇聚

动机来自原核源码，而不是把 MIN 的负结果移植成原模型缺陷。原 `STLocalizedConv` 先对三槽窗口做共享 `fc_list_updt→ReLU`，得到 U[B,Q,N,3,C]。非self图在三个子槽重复同一个图，所以各bank实际对同一组三个变换子槽求和后做图传播；self分支取均值。

研究候选是在该位置引入**内容条件的 bank 子槽选择**：

```text
U = ReLU(original_window_projection(window))
w_s = 3 * softmax_over_subslots(score_s(U))
pooled_s = sum_l w_s,l * U_l
message_s = original_graph_s @ pooled_s
self_message = mean_l U_l
hidden = original_gcn_projection(concat(self_message, message_1, ..., message_10))
```

评分器采用共享小映射和bank身份的非线性交互，避免为每条边构造通道消息；仅给每bank加一个常数bias会被子槽softmax消掉，不构成有效选择。权重由来源节点、bank及内部子槽索引确定，同一来源对各接收者共享，不是逐边选择。评分输出零初始化时，w=1，数学上恢复原非self求和；保留所有原参数。归约次序改变可能产生浮点差异，不能预先声称逐位相等或旧检查点已精确回放，必须实算候选自身阶段0。

该改动只负责“不同图分支如何使用局部窗口内容”。原ICSF的事故条件可经U影响选择，但没有新增直接报告入口，不能把通用预测提升写成事故关系/语义的额外增益。旧窗口投影已经跨时间槽混合，U的子槽不能解释为未混合的原始时刻或真实传播时延。

这是待检验候选，没有开发新模型、运行预测或训练，也未完成新颖性核查。资源仍需端到端测量：额外bank选择和不同pooling会增加计算，避免E×C消息不等于免费或一定更快。

## 五个历史问题如何使用

| 原问题 | 本轮约束 |
|---|---|
| 关系细节无额外价值 | 原事故模块保留；需要独立对照才可主张内容增量 |
| 修正缺少选择性、容易上调 | 内容条件选择是候选动机；低流量/MAPE及正负抵消仍需检验 |
| 新增物理路径无跨目标槽共同持续状态 | 这是历史新增路径的职责问题；保留原DIF/INH递推，不宣称原模型无记忆 |
| 局部预算/平衡与最终预测联系弱 | 新候选直接进入原DIF/backcast/forecast，不再增加潜预算路径；不作物理守恒主张 |
| 只训练预算MLP限制共同适应 | 完整模型联合训练；F2已这样做，不能再次当成创新 |

## 开发和实验门槛

1. 独立数学/梯度对照验证均匀选择恢复原核、bank顺序、self尺度、四块递推和输出槽对应。
2. 同硬件、同batch与FP32/确定性设置，测完整模型前向+反向+优化器更新的耗时与峰值显存。不能由单chunk或推理时间外推每轮提速。
3. 原版、内容条件选择、无内容的bank子槽参数对照使用同初始化规则、完成预算、样本顺序和选模规则；检验内容条件是否超过静态权重重标定。
4. 报告MAE/RMSE/MAPE、逐时距、低流量与固定困难窗口。已有验证集属于探索集；选定结构后再固定最终确认方案。
