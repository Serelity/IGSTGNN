# IGSTGNN 事故信息与物理传播改进构想

整理日期：2026年10月10日

本文整理已有消融实验对下一版 IGSTGNN 的启发，说明每个想法的来源、改造位置与验证方式。核心建议是：**用交通历史与事故报告共同估计事故响应状态，让它改变模型内部的空间传播，再检验状态递推能否替代独立的时间衰减。**

研究目标保持为“事故发生了什么—道路有效通行能力怎样变化—交通影响如何传播”。现有报告主要提供位置和年龄，缺少可靠的封道程度、处置阶段及容量真值。因此下面的状态和交换上限首先是模型潜变量，不能直接解释为真实道路容量。本文是一份设计构想，所列新结构尚未验证有效。

## 1 已有实验给出的关键启发

| 既有证据 | 对模型设计的启发 |
|---|---|
| v13a 单报告 ICSF 等价核验：关联节点两次 softmax 权重恒为1 | 应显式研究交通状态怎样决定报告的绝对响应，不能依赖当前退化的注意力完成这件事。 |
| v12a/b：关闭事故、只保留归一化、只保留 ICSF、完整模型的训练集 MAE 依次约21.9707、21.0663、21.0299、21.0293 | 归一化及其下游响应需要独立控制。ICSF 与 TIID 的作用应拆开检验。 |
| A/B/C/C′/C″ 各训练100轮、同一种子：最佳验证 MAE 为22.6867、22.8141、22.7802、22.7586、22.7978 | 四种可学习时间响应均未超过固定响应。下一版需要解释其状态演化与旧时间曲线有何实质区别。 |
| P2 多层事故门控未超过 fixed；同权重下关第2层改善、关第3层恶化 | 事故信息的注入位置和传播职责值得设计，但不能据此认定只保留第3层最优。 |
| v13b 的位置、年龄增量在三个种子及总体均未通过预设复合门槛 | 不能预设有限报告一定有稳定收益；也不能把未过门槛解释成信息完全无用。 |
| v12n/o 输出修正未形成稳定增益；当前 M4.5 新增报告路径净收益约9.65e−6 | 单纯增加修正幅度、门控或输出残差缺少依据，应优先改状态更新机制。 |

这些实验的切分、样本与端点不同，数字仅用于各自实验内部解释，不能跨行排名。同检查点关模块反映模型依赖，重新训练的对照才更接近回答“这个模块值得保留吗”。

## 2 想法一 让事故响应取决于当前交通状态

### 思想来源

当前单报告 ICSF 可简化为“最后一帧隐藏状态加候选位置上的报告向量，再做 LayerNorm”。V、位置和后续图传播仍然有效，但这条注意力的权重不能利用节点状态与连续距离决定绝对注入强度。v13a 的等价核验为这一结构判断提供了证据。

跨领域可借鉴信号处理的状态估计思路。KalmanNet 将已知的状态空间结构与学习模块结合，用于部分已知动力学下的状态估计。这里借鉴的是“观测用于修正状态估计”的分工，不照搬其滤波器或监督条件。[KalmanNet 作者稿](https://arxiv.org/abs/2107.10043)

### 具体改法

由合法交通历史估计当前状态，结合报告位置、年龄与历史观测掩码，生成低维事故响应状态。它描述当前哪些位置可能受到扰动、扰动程度如何，而不直接输出未来流量修正值。位置关系负责定位，交通历史负责提供需求与拥堵状态的证据。

同一条报告在低需求和高需求背景下可以产生不同响应；报告关联也允许几乎不产生额外扰动。事故状态后续用于控制内部传播，避免只换一个更大的报告嵌入或 sigmoid 门控。

### 与旧尝试的区别及验证

v12f 等已经尝试过状态向量和上下文交互，单纯增加交互网络并不是新的研究贡献。这个想法的价值取决于：状态是否确实进入受限传播更新，并在相同输入下优于原 ICSF。首个对照先保留原 TIID、内生时间分支和预测头，只改变空间事故接口；共同归一化保持一致。

若新状态仅改变数值而不改善预测，或普通同容量注入同样有效，就应收窄其价值判断，不继续靠增大网络解释失败。

## 3 想法二 用事故状态改变内部交换能力

### 思想来源

输出修正系列说明，识别事故影响并不等于知道未来预测应该上调还是下调。当前外挂容量分支又保留了原 ICSF/TIID，其开关只测得新增路径的边际作用，不能比较两种事故建模方式。

CTM 提供另一种组织方法：界面流量受上游可发送量、通行能力和下游可接收空间共同限制，状态由流入、流出更新；模型允许容量随时间变化以表示事故。借鉴重点是供需限制与共享界面交换。[Daganzo CTM 前驱报告](https://escholarship.org/content/qt0b6612tk/qt0b6612tk.pdf)

### 具体改法

在 IGSTGNN 外生空间分支中引入一个有界交换接口。历史状态确定可发送与可接收程度，事故状态调制交换上限；同一条边上的交换量同时进入两端更新。合流、分岔和开放边界按统一预算处理，避免多个独立消息各自放大。

让事故改变“状态可以怎样传播”，而不是在完整原事故模型之外再叠加一个预测残差。原有学习图仍可服务相关性建模；带道路依据的候选有向关系服务受限交换，两类关系需要明确区分。

容量上限下降不意味着流量必须立刻下降：需求较小时，上限可能不约束实际交换；下游受阻时，限制可能来自接收端。这些条件性的响应比强制所有事故节点降流量更符合研究目标。

### 验证重点

必须设置相同输入、相同接入位置、可比状态维度和预算的普通神经递推参照。新模型优于原 IGSTGNN，只能先支持完整改造有效；进一步优于普通递推，才能讨论受限结构的额外价值。

潜状态交换的收支恒等式不等于车辆守恒，最终预测头也不会自动满足物理守恒。仅在单位、连接、边界与观测映射有依据的局部区段，才进一步检验真实 CTM 解释。

## 4 想法三 由状态递推产生事故时间响应

### 思想来源

原 TIID 显式叠加的固定衰减在较晚时距接近零，但 ICSF 仍可经主干影响晚期预测。A 到 C″ 的结果说明，只增加衰减曲线自由度尚未取得优势。值得检验的是“交通状态如何持续演化”，而不是再选一条更长的事故曲线。

Tang、Jin、Ozbay 的交通模型校准工作将神经编码与交通流模型知识结合，以观测约束参数估计。可借鉴“参数估计需要通过观测结果接受检验”的思路；本文的内部状态递推是另外提出的设计，不归于该文原架构。[作者稿](https://arxiv.org/abs/2307.06267)

### 具体改法

从预测截止点的状态出发，递推事故状态、交换能力和交通潜状态，在各目标时间窗读出预测。恶化、持续和恢复由状态及边界条件共同决定；事故年龄作为已有证据输入，不直接当作剩余持续时间。

递推需要覆盖原任务的预测间隔和真实目标窗口，不能把12个输出索引直接解释成12分钟。未来真实流量、事故清除时间和事后处置更新不能进入预测输入。若利用历史前缀外推训练状态估计，监督片段必须位于合法训练历史内。

### 验证重点

在空间接口固定后，比较原 TIID、同输入普通状态递推和受限状态递推。除整体误差外，检查早晚时距、状态饱和、梯度和长时递推稳定性。曲线看起来更平滑或更像恢复过程，不能代替预测收益，也不能认证真实事故清除时刻。

## 5 想法四 统一事故路径并控制可选信息

### 思想来源

P2 的逐层结果表明，事故注入可能局部有益、其他区域有损；当前 M4 则同时存在原事故路径与新增容量报告路径。这些结果提示我们应明确每条路径的职责，而不是默认更多注入点更好。它们尚未证明重复注入就是失败原因。

### 具体改法

最终候选中，报告先形成一份事故状态，并通过明确接口控制交换能力；各时空层消费这个状态或其传播结果，不各自再生成独立报告修正。第一阶段为了隔离空间改造，可保留原 TIID；是否移除或替换 TIID，应在后续单独验证。

速度、占有率、多报告集合和道路资料采用可选输入接口，显式记录可用性。只有当数据实际可用且通过时点、对齐审查时才接入。缺信息时仍保留全部496站的基本预测路径，资格不足处的回退单独统计，不能算成物理机制已经覆盖。

原邻接矩阵、学习图或里程顺序不能自动认证道路直接连接。无报告模型也不能偷偷接收真实报告候选掩码，否则报告消融失去含义。

### 验证重点

先用原模型已有的单报告与交通输入比较内部模块。新增通道、报告集合与道路信息另设信息增量实验；新旧模型使用不同信息时，应分别报告完整系统效果与模块结构效果。可插拔接口解决的是适用性问题，其预测收益仍需逐项检验。

## 6 建议的整体架构与推进顺序

建议主数据流为：

**合法交通历史与可用报告 → 当前事故响应状态 → 有效交换上限 → 内部空间状态更新 → 与内生时间分支共同预测。**

时间接口随后研究由状态递推替代原 TIID。它与空间接口共享状态定义，避免另造一份互不关联的事故表示。状态初始化、边界预测与报告调制的职责需要在开发前明确。

| 顺序 | 具体比较 | 要回答的问题 |
|---|---|---|
| 第一步 | 原 ICSF 加原 TIID，对比新空间事故接口加原 TIID | 相同信息下，内部空间改造是否更好？ |
| 第二步 | 新接口中的普通传播，对比受限交换 | 收益是否来自受限结构？ |
| 第三步 | 固定空间接口，比较原 TIID 与状态递推 | 时间演化是否提供额外收益？ |
| 第四步 | 固定结构，比较基础输入与可选新增信息 | 哪些信息真正提供增量？ |

按前一步结果决定是否进入后一步，不要求立即全量训练。每次比较需要重新训练；选定模型的 ON/OFF 可用于解释依赖，两类证据分开报告。

全部496站的冻结主指标优先，同时报告道路、关联与非关联区域及早晚时距。控制共同初始化、样本顺序、归一化、训练与选模规则，披露有效参数差异；后续通过配对种子与时间段检查稳定性。旧 audit 已被反复查看，只能继续作为开发证据。

当前最高优先级是把想法一和想法二落实成一个职责明确的内部空间接口及其普通参照。想法三是后续时间机制候选；想法四是架构和数据适用性的共同约定。旧 M4.6/M4.7 外挂残差方案保留为历史候选。

## 7 证据来源与结论边界

上述四个想法均为待验证假设。单报告注意力退化提供了明确的计算结构线索，但不证明整个 ICSF 无用；负结果限制已有方法的主张，也不证明所有事故信息或物理先验都无效。

本地核查覆盖源码、保存的服务器日志、结果记录以及五个时间响应压缩包摘要。部分远端 checkpoint 和逐样本数组未回传，本次没有独立重放全部实验。v13b 的复合门槛失败项尚不能从现有日志细分。不同实验不可横向比较绝对 MAE。
