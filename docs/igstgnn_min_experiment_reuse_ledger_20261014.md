## R1 已完成开发、尚无正式效果结论

1. 一个共享的低秩事故条件持续响应结构，具有跨十二槽状态、双轨迹和专用读出。
2. 两个候选 state/location 从已有 MIN 最佳权重复制初始化，允许候选主干与新模块联合适应；**源 MIN 不更新，无 MIN-only worker**。
3. 输入历史低流量的配对风险项、原 MIN/当前OFF的明确区分、可续跑保存和条件风险报告。
4. 可选冻结入口用于本结构接通诊断，不要求服务器重跑旧模块，也不要求额外完整冻结试验。

## 每次运行前的复用判据

先核对源checkpoint指纹、数据发布/划分、样本索引、批大小、有效掩码、选模规则和目标槽。相符时优先读取已有预测；确有新模型或新训练协议时建立独立目录。必要的检查点回放是推理，不是重新训练，但也应复用已验证制品、避免无目的重复。

候选继续联合训练时，当前OFF主干已经改变，不能伪装成旧MIN。新候选对旧MIN是整体方案比较，对同预算state/location才是关系数值的增量比较。已做的测试集评价保留为记录，本轮不重新看测试集选择模块。

## R2 当前默认开发方向

用户要求同时修正物理模型、重复路径和输出旁路。R2保留兼容的MIN统计编码权重，删除旧P/逐层潜exchange及R1双轨迹自由残差，改为唯一输出域开放存量—流量解码器。详见[重构方案](igstgnn_min_stock_flow_r2_plan_20261014.md)。

这不是重新训练旧MIN、旧service-budget或R1。只训练两个新候选state/location，源MIN不更新；新候选初始化不等于旧MIN。R2条件OFF仍运行新解码器，不能复用R1中“OFF是当前MIN主干”的解释。

476候选覆盖不等于物理认证；当前联合物理认证0站。新模型的名义时间、库存和观测映射均显式记录，不用模型内部账本代替现实车辆守恒证据。
