## 4. 对研究目标的含义

1. B1/B0提示原事故空间注入的强度调节是有价值的比较方向；由于仍保留TIID，不能解释为有/无事故信息的纯增量。
2. B3/B2为同信息算子对照，初步支持受限交换这一设计包；同时包含容量、共享发送/接收及有界更新，当前无法拆出哪一条规则贡献最大。
3. B3/B0同时改变内部空间设计和候选道路结构，不能把全部改善归为物理规则。
4. B2/B3的共同提议网络也读取容量C，因此差距和完整报告响应不能都归为硬容量上限。仅凭MAE，尚不能证明“事故报告改变容量，再沿内部道路传播”是有效路径。
5. 当前交换仍是无量纲潜状态规则；候选道路图、真实容量单位和真实交通守恒尚未认证。预测收益与现实物理解释分开记录。

下一轮重点是：在完整IGSTGNN内部继续比较B1与B3，并用已有诊断核对报告状态更新、容量变化、内部/开放边交换及梯度。先验证机制是否实际参与，再考虑增加模块。
