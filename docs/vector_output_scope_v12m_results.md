## 定义与解释方向

U为原向量模型完整输出；P仅在报告位置候选节点H1–H6使用同权重向量输出，其余输出
取同一原生A模型预测，输入历史及报告上下文保持相同。两策略共享训练更新，分别
执行原candidate_early选模规则和16项保护。epoch 0表示回退A。

除明确标出的策略/架构对比外，**收益＝A MAE－当前输出MAE**，单位为原始流量MAE，
正数表示改善。区间均为服务器报告的配对四周循环块、2000次重采样、95%逐项区间，
主估计量是合并有效单元误差。它们以当前选定权重为条件，不涵盖选模/随机种子不确定性，
也没有多重比较校正。audit已反复参与研究开发，不是独立确认集。

## 当前科研判断与后续边界

1. **工程问题得到回答。** 在既定共享轨迹上，最终输出范围可以精确保住A的晚期与
   非候选输出，确实改变了选择准入；无需为两种策略重复训练。
2. **目标收益未成立。** 解除了晚期保护障碍之后，选出的早期修正仍在后段完整事故
   上退化。因此，“只是晚期输出损害挡住了稳定有效的早期适配器”不足以解释此前失败。
3. **不唯一归因。** 拟合/选择改善、后段退化与cohort/加权口径差异，提示应检查早期
   残差规律的跨时段稳定性；仅凭此结果不能区分过拟合、状态分布变化、事件信息不足
   或其他机制，也不能否定所有其他模型或数据上的事件信息价值。
4. **保留负结果，不以本轮选择改善作为模型升级依据。** 本记录不新增自动成败门槛，
   不据此放宽保护、追加epoch、挑种子或进入test。若继续，应先为现有输出和可观测
   历史上的早期残差稳定性诊断另立方案，再评估是否值得开展新训练。

以上是本次结果解释。冻结A与scaler仍保留原广泛train及旧val的信息依赖；
本次完整运行不改变该边界。日志没有提供独立城市/年份验证。
