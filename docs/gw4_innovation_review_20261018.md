## 1. 结论与推荐次序

优先研究的问题是：**当旧图消息模型已经较强时，接收节点的状态是否能提供超出消息自身的选择依据，并带来可重复的预测增益？**

第一阶段用冻结 GW2 的零初值残差作验证底座，比较 STATIC_RESIDUAL、MESSAGE_RESIDUAL、RECEIVER_RESIDUAL。它用于隔离现象，不把冻结、零初始化、接收查询或残差连接分别包装成新发明。

第二阶段候选是**按来源决定修正幅度，允许无益修正收缩到零附近**。当前槽位 softmax 只在每个图来源内部重新分配系数，无法直接决定某个来源是否应该进行修正。先完成第一阶段，才有理由增加这一自由度。

真实历史轴上的时延不列为当前主线：已有 PDFormer、近期 Traffic-DiMAGNet，自己的 ED v2 也已实现时间读取、边界回退与零初值残差。重新加入时延层不能自动构成新的贡献。

## 2. 当前证据：支持什么，还缺什么

当前 GW 系列使用作者发布的 496 节点输入、12 步历史与 12 步未来；继承试跑为 seed=2025、每组 5 轮、410 次更新、837 个验证窗口。它与早期重新构造的 chronological Contra496 管线须区分，不混用其模块退化结论或指标。

| GW2 同检查点 UNIFORM | 15.156640950 | 动态选择的敏感性增益仅约 0.000419 |

“两组关闭选择后的差异 + 各自选择敏感性 = 最终差异”只是逐点绝对误差的代数恒等式，不能据此识别训练过程的因果贡献。5 轮间排名变化、单种子和开发验证集反复使用，也都限制了结论。

源码还有三个边界：

1. 原卷积先对完整 K×C 窗口作线性混合，再产生 K 个潜在槽位；槽位不是三个可直接解释的历史时刻。
2. GW2/GW3 在每个来源内对槽位归一化，系数和为 K；没有来源之间的竞争或独立幅度选择。图来源与空间阶数保持原模型设置。
3. 权重和固定不能保证隐藏均值、最终预测均值或车辆守恒。冻结参数也不能保证新残差启用后的预测不变，尤其第一层还参与递推。

## 4. 候选 A：接收状态是否提供额外选择依据

**研究问题。** 在保留 GW2 已有消息评分和全部旧参数的条件下，接收状态能否让同一组消息获得更合适的修正，超过静态修正和只读消息的动态修正？

**假设。** GW3 的失败可能既包含旧表示改变的代价，也包含接收查询的有效信息。冻结 GW2 能缩小前一种混杂；同容量消息自查询对照检验后一种信息来源。另一种竞争解释是接收查询只是调整总体偏差、获得额外容量或短期优化优势。

令 M[g,k] 是原图来源 g 的一阶槽位消息，U 是接收节点本地混合槽位的均值，s0[g,k] 是已训练 GW2 的完整旧 logit：

```text
STATIC_RESIDUAL:   delta[g,k] = b[g,k]
MESSAGE_RESIDUAL:  delta[g,k] = b[g,k] + q(mean_k M[g,k]) · key(M[g,k]) / sqrt(d)
RECEIVER_RESIDUAL: delta[g,k] = b[g,k] + q(U) · key(M[g,k]) / sqrt(d)

w[g,:] = K * softmax_k(s0[g,:] + delta[g,:])
```

实现沿用 GW2 原表达式 `1 + K*(p - 1/K)`，以保持其浮点计算路径。b 与 key 的权重初始为零，q 随机初始化；不能把乘法两端同时置零而使分支失去梯度。三个组共用源检查点、样本顺序、适配轮数、优化器配方。STATIC 只有显式偏置活跃；MESSAGE 与 RECEIVER 的活跃参数量和初始化相同。

**与最近工作的差异。** 验证对象是固定来源图传播后的潜在槽位修正；保留已学习评分而非整层替换。与 GATv2/PDFormer 的邻居注意力、TESTAM 的专家路由、H2STGCN 的双图传播均有操作对象上的差异。但该残差点积模块本身仍接近已有注意力适配器，当前新颖性有限。

**最小验证。** 新增三个训练组，各最多 5 个适配轮；零新增历史基线训练或基线推理。验证报告同时给出相对 GW2 的预测增益、RECEIVER 对 MESSAGE/STATIC 的增益，以及 BEST/LAST。增加 STATIC_ONLY 与 QUERY_SELF 同检查点干预，但明确它们不替代独立训练。

**成功条件。** 接收组先在共同适配预算超过两类控制与 GW2；后续在预先固定预算、配对多种子和未用于方案筛选的数据上确认，同时报告 RMSE、MAPE、预测偏移与固定困难窗口。短试跑收益只是进入下一阶段的条件。

**失败条件。** 三组都不超过 GW2；或接收组不优于同容量消息组；或主要收益由静态项解释。出现这些结果应缩减或否定“接收状态提供额外选择依据”的主张。

**静态校准竞争解释。** 若已有经过认证的训练集预测缓存，可增加仅在训练集拟合的标量仿射校准。若没有该缓存，本轮不补跑基线、不在验证集拟合校准参数，明确这一竞争解释尚未完全排除。禁止直接按验证集测得的 -2.222278 偏移补回输出。

**成本与风险。** 数据和实现可复用，优先级最高；主要风险是收益微小、短期优化依赖和方法新颖性有限。冻结旧参数只能限制参数变化，不能禁止残差造成预测退化。

## 5. 候选 B：按来源允许修正收缩

**研究问题。** 来源内部权重归一化是否迫使模型在没有可靠改进证据时仍重排槽位？能否通过接收状态与来源冲突特征，决定某一来源的修正幅度？

对候选 A 的每个来源，定义其相对 GW2 的修正：

```text
DeltaZ[g] = sum_k (w_new[g,k] - w_GW2[g,k]) * M[g,k]
Z[g] = Z_GW2[g] + a[g](U, message_summary, source_conflict) * DeltaZ[g]
```

这里的 a 只作用于新增修正，不能关掉旧模型的整个图消息后仍声称保留了旧锚点。若用 sigmoid，幅度只能趋近零，不能声称有限参数下严格选择了“全拒绝”。来源之间的冲突统计来自预测起点已知的隐藏消息，不使用真实未来流量、未来误差或事后事故严重程度。

**与最近工作的差异。** 讨论的是“是否修改某个旧图来源的槽位汇聚”，而非 TESTAM 的完整专家选择。Gated Attention、动态图融合和通用残差门已有先例；有价值的贡献必须来自来源冲突与修正效用的机制证据，不能仅靠多加一个门。

**假设与竞争解释。** 特征冲突可能帮助区分有益领先变化与无益扰动；但也可能只是幅度缩小产生的正则化收益。隐藏特征相异不等于消息不可信，相异消息也可能包含最需要的领先证据。

**最小实验。** 仅在 A 至少存在稳定可用修正后开展，先固定同一个已训练修正，比较固定幅度、仅接收状态的门、读取冲突的门；比较两种动态门时匹配活跃容量与预算。候选修正已非零后再研究门，避免门与其内部残差同时零初始化造成死分支。端到端联合训练应作为另一个明确的实验阶段。

**成功条件。** 冲突条件门超过同容量普通门，减小对旧模型已有正确预测的破坏，收益同时出现在全网与预先固定的困难窗口；来源干预与门变化也支持解释。

**失败条件。** 常数缩放或普通门获得同样收益；冲突门只把所有修正压近零；或者改善只是验证集筛选的结果。此时应退回简单修正，不保留“冲突感知”主张。

**成本与风险。** 有可检验的结构依据，研究价值中等、开发成本中等，新颖性风险仍高。当前代码事实只证明缺少该自由度，尚未证明它就是 GW3 退化原因。

## 6. 数学检查：避免看似新颖但实际相同

如果 key 是线性的，在打分前从每个消息减去同一个接收向量，并不会改变槽位 softmax：

```text
softmax_k(q(U)^T W(M_k - U))
  = softmax_k(q(U)^T W M_k - q(U)^T W U)
  = softmax_k(q(U)^T W M_k)
```

所以不能把这种减法单独称为“需求差分匹配”。要有非等价机制，必须明确引入非线性交互、不同的竞争集合或值路径变化，并单独检验。

同样，`sum_k (w_new-w_old) M_k`只是 logit 残差所产生汇聚变化的改写，不是另一个独立模块。在系数差和为零时，它对所有槽位同时加同一个向量不敏感；这不保证整网预测无偏或交通流守恒。

## 7. 实验边界与后续证据

- 每个新组从同一个已认证 GW2 BEST 开始；旧参数冻结，旧模块保持 eval，禁止 dropout 或运行统计偷偷改变锚点。仍须允许梯度穿过冻结的后续算子，不能把整个前向包在 no_grad 中。
- 新 Adam 只优化新增活跃参数；调度器与课程从适配第零步开始。明确是“既有 GW2 + 新增适配预算”，不冒充与旧 GW2 相同的从头训练预算或原优化器续训。
- BEST 在新增适配轮次中选择，旧锚点单列；不要把第零步自动纳入 BEST 后用“未退化”掩盖新模块无收益。
- 历史缓存缺失、身份/哈希不符时停止，不自动重建基线、不覆盖旧运行。BASE 对照复用源 BEST 的预测，不构造 BASE 推理任务。
- 每个适配轮保存旧张量摘要、新参数、优化器、调度器、课程、RNG 与训练顺序；中断恢复到最后完整轮。恢复不能重新初始化已完成的组。
- 机制统计至少区分调用阶段与来源，并记录局部权重极值、残差幅度和查询/键范数。平均熵高不等于不存在局部饱和。
- 真实未来流量、误差符号、原本低估等分组只作事后诊断。可部署条件只读取历史或预测起点已知字段。
- 窗口可能重叠。后续不确定性按事件或连续时间块进行配对分析，不把数百万预测点视为独立事故重复；事件 ID/时间戳不足时明确限制。
- 开发验证集已多次用于结构设计。主张泛化前应先冻结方案、预算和指标，再做独立确认；不在本轮开启测试集评价。
