# 冻结 MIN：事故位置关联细节的同检查点对照

日期：2026-10-14。

## 本项回答的问题

已有十轮冻结主干小试中，位置预算适配器改善验证 MAE 约 0.265%，但使 MAPE 恶化约 0.1431 个百分点。已有预测的分解进一步显示：96.16% 的有效预测被上调；原 MIN 高估组约 96.08% 的点变差，低估组约 95.05% 的点改善。事故直接关联区域在相同粗流量桶、相同原 MIN 偏差组内，同时放大收益和代价。

本项检验：**在原事故支持站点集合不变时，同一个最佳模型使用正确关联编码，是否优于该集合内部的错误向量分配？**它是位置关联细节的检查点敏感性对照，支持范围本身的作用不在本项识别范围内。

## 固定项与变化项

固定源 MIN 的最佳权重、最佳位置适配器、全部缓冲和图、原历史交通、类别与有效标志、报告存在和关系可用标志，以及每个样本的事故支持站点。正式输入仍为作者发布数据的 837 个验证窗口，原 batch 64，尾批 5；不重新训练或评价测试集。

默认使用一个预先固定的 seed `20261014`。每条样本以 `[seed, 原全局样本 ID]` 构造独立局部 NumPy Generator，不读取目标、不消耗全局随机状态、不随批次划分改变。

仅在原 float32 关系编码非零、报告存在且关系可用的支持站点内部，循环置换完整三维关联向量。支持数至少为二时，每个支持站点的供体均非自身；零或单支持站点保持恒等。非支持站点和关闭报告标志下保留的原关系值不变。不跨样本、不按目标选供体，也不独立打乱关系列。

随机循环不是全部错排的均匀抽样。重复关系向量可能导致供体虽然改变、数值却没有变化；不更换 seed 寻找更强或更有利的扰动。记录每条样本的支持数、供体变化数、实际向量变化数、重复向量数及全局变化幅度。

置乱保持原支持规模、支持位置和支持集合内向量多重集合；它改变向量与具体站点的对应关系。这个控制不保证保留真实道路位置的联合几何分布，错误关联可能偏离训练分布。

## 开始前的核对

同时锁定冻结运行、原 A 总运行和 A 子目录的已有锁文件；只读获取锁，不创建或写源文件。核对原发布包、图、协议、旧训练代码、源 A 和冻结运行记录的哈希，旧训练源码及其 fingerprint 不变。

从原 A 最佳 MIN 重建冻结模型，只应用冻结运行 `last.pt` 中的 `best_adapter_state`，不构建或恢复优化器、不继续训练。检查点格式会一并反序列化其记录字段，但不会应用当前 adapter、优化器或保存的训练 RNG 状态。核对初始化证书、冻结主干哈希、检查点历史、JSON 伴随记录及包含第零轮的原最佳轮次选择；不因内容对照结果重新选轮次。

读取作者发布包时复用训练已使用的 `load_samples`，兼容服务器 NumPy 1.24 的对象 pickle 模块路径。整包测试载荷不可避免被反序列化，但没有测试集迭代、指标计算或选模。

## 推理流程

1. **完整真实输入回放**：先遍历全部原验证批次，正确关联 ON 必须逐点完全匹配保存的最佳 ON，关闭适配器必须逐点完全匹配保存的 MIN。目标、样本 ID、有效掩码、固定困难窗口、原批次及机制统计保持一致。
2. **干预前保护检查**：核对模型参数、全部缓冲、图张量和普通图属性、随机状态及输入摘要。任何回放或保护失败，都不允许构造及执行置乱干预。
3. **逐批正确→置乱→正确**：每批先核对正确预测，使用仅替换事件关系字段的新批次执行置乱，再恢复正确输入；恢复预测必须完全一致。旧前向审计同时核对事故支持及适配器执行覆盖。
4. **完成保护**：再次核对原输入、权重、图、模式、梯度、hooks、随机状态和源文件哈希。通过后才保存最终成功总结。

正式 14 个批次共进行 70 次模型前向：完整回放的正确/MIN 各 14 次，加配对阶段正确 28 次、置乱 14 次。它们是同一验证集的多次计算，不是独立重复。GPU 名称只记录；软件版本、设备类型、线程、确定性与 TF32 策略沿用原身份。

## 指标与解释

保存三种预测：`REAL`、`SHUFFLED`、`MIN`。使用共享原有效掩码和第零轮 MIN 选定的固定困难窗口。

- 正确分支收益：`MIN 误差 − REAL 误差`。
- 置乱分支收益：`MIN 误差 − SHUFFLED 误差`。
- 正确内容收益：`SHUFFLED 误差 − REAL 误差`，正数表示正确关联在本次对照中更好。

输出 pooled 及逐预测步 MAE/RMSE/MAPE、固定困难窗口、真实逐点正负内容收益及预测变化。流量、高低估、事故区域和交叉分层始终沿用原 MIN：高低估由 `MIN−目标` 定义，不被置乱预测重新分组。

内容分层由两个使用相同 MIN、相同组和分母的分支对照相减，核对各互斥族的点数及全网 MAE/MAPE 贡献守恒。不能将两个分支各自的正负收益相减冒充逐点内容收益分解；后者从真实正确/置乱配对直接计算。MAPE 在 JSON/CSV 中为比例、报告中为百分数或百分点；RMSE 不声明线性贡献可加。

先查看有效扰动覆盖，再查看正确内容收益和各组代价。如果没有实际向量变化，不能根据相同预测判断模型不使用位置内容。

正确关联优于置乱，只支持该固定检查点对正确关联细节的有益依赖；正确关联与置乱接近，不能否定原支持范围、事故信息整体或其他训练方案的价值。置乱更好也不是部署错误信息的理由。一次固定置乱、一个种子、已选验证模型不足以证明事故因果、泛化显著性或真实道路容量识别。
