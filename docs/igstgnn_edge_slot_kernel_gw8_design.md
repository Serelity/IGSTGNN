# GW8：在 DIF 内检验接收者—发送者—时间槽的联合核

状态：2026-10-19 开发候选。代码与服务器检验协议单独交付，尚无本版测试通过、训练完成或精度改善的实测结论。所有 Python、模型和测试执行留在服务器。

## 研究问题与已有证据

GW7 的四臂同预算结果未支持图交互记忆，R_CONTINUE BEST 的开发验证 MAE 为 13.618473855。后续匹配分析在有限覆盖样本中保留了高历史波动对应较大误差的现象，但未发现跨节点、尺度和高波动条件一致的趋势欠响应。因此，本版不把“模型普遍跟不上趋势”作为依据，也不按历史趋势符号设计输出补偿。

本版提出独立的表示假设：**在邻域求和之前，对每个发送者和时间槽联合决定消息权重，是否比保留相同边缘分布、但去掉发送者与时间槽关联的核更有预测价值？**

源码事实：第一层 GW4 ReceiverResidualConv 先将三槽窗口展平，经原 fc_list_updt 的方阵线性变换与 ReLU，再沿每槽聚合所有发送者，最后按源选择混合槽。它已经有接收者条件选择，也能间接表达时空变化；不能说它完全没有时间建模。这里的限制是先聚合发送者后才进行槽选择，使该接口不能再逐个识别每个发送者在各槽的内容。fc 是 3C→3C，不能称为维度压缩，也不能声称所有原始时间信息都不可恢复。

## 改动位置

保留全部原 DIF/INH、ICSF/TIID、原 GW2/GW4 路由及输出头。只在第一层 DIF 的 gcn_updt 输出、原 dropout 之前加入一个低维联合核产生的隐状态更新。历史调用和该层的所有生成调用共享同一组新参数。更新继续进入原 backcast、层间残差和 forecast 递推；它不是最终预测上的第二个输出头。

新增结构用内部增量参数化以保留认证起点；增量本身不是创新主张。其可检验差异是发送者×时间槽的联合核及其与保留边缘分布的可分离对照，而非把残差换到另一个位置。

“原始槽”指这一 DIF 调用在 fc_list_updt 之前的隐藏状态槽。首次历史调用来自已嵌入、融合事故信息、乘估计门后的历史；后续调用包含已生成隐藏状态。它们不是始终直接观测到的流量，也不等价于物理传播时延或实际目标时距。

## 图先验与稀疏预算

新核仅使用原调用已经获得的图：每个图源取第一阶邻接矩阵，删除自环，各有效行归一化后，对有邻域的图源等权平均。原有第二阶消息仍在原生路径中；新核不额外将其当作直接边。

对合成先验逐接收者保留权重最大的至多 8 个发送者，再归一化保留权重。邻接的行是接收者、列是发送者，这表示预测依赖，不保证道路物理方向。无有效邻居的行更新为零，不把无邻居填充索引当作新边。保留权重参与梯度，top-k 索引选择本身离散。

稀疏化是事先固定的计算取舍，不能在返回结果后调整边数挽救本轮；记录保留先验质量、无邻居比例和峰值显存。原有完整图路径始终保留。联合核与可分离核使用相同的稀疏先验和节点分块，避免把邻域数解释为联合核收益。

## 联合核与可分离对照

对局部窗口 U[b,w,i,l,c]，接收者查询取该窗口最新隐藏状态；键和值使用发送者各个未经原 fc 混合的槽。共享投影维度 d=16，槽数 K=3：

\[
q_i=W_q U_{i,K},\quad k_{j,l}=W_k U_{j,l},\quad v_{j,l}=W_v U_{j,l}.
\]

\[
A_i(j,l)=\operatorname{softmax}_{j,l}\{q_i^\top k_{j,l}/\sqrt d+b_l+\log P_i(j)\}.
\]

联合臂的读出为 \(z_i=\sum_{j,l}A_i(j,l)v_{j,l}\)。可分离臂从完全相同的 A 得到两个边缘分布，再取乘积：

\[
A_i^{sep}(j,l)=\left(\sum_r A_i(j,r)\right)\left(\sum_m A_i(m,l)\right).
\]

这样，两者的发送者边缘分布和槽边缘分布在同参数、同输入下完全相同，唯一限制是可分离臂去掉两轴的关联。它不把图交互记忆投影到接近零的子空间，也不保证两种读出的能量或幅值相同。联合臂仍有可能更差；不同训练轨迹下，两臂的实际边缘分布也会分化。

隐状态更新为 \(\Delta h_i=W_o z_i\)，W_o 无 bias 且零初始化。W_q/W_k/W_v 正常初始化，槽 bias 初始为零。W_o=0 应在相同模式、梯度开关、精度和随机数下精确恢复认证 R。首步可只有 W_o 获得非零新增梯度，之后才向内部传播。三个新增臂的参数名、初始张量及活跃容量严格一致；不填充无用权重凑参数数。

局部对照使用同一组投影与槽 bias，仅从接收者自身的时间槽读取，检验额外局部非线性容量能否解释收益。图先验不属于局部臂的新输入。

## 四臂与固定预算

| 臂 | 功能 |
|---|---|
| R_CONTINUE | 当前强 R 同预算继续训练 |
| R_LOCAL_KERNEL | 同容量本地时间核 |
| R_SEPARABLE_KERNEL | 同容量图核，保留发送者与时间槽边缘分布，去掉联合关联 |
| R_JOINT_KERNEL | 同容量发送者×时间槽联合核 |

共同起点为已完成 GW7 中 R_CONTINUE BEST：best_epoch_004_ef6b4b17370d.pt，文件 SHA-256 为 568ff5e0dcea220cb28e2e9bec794ef1894411e8dd8acd4bf427bfb2e425ca65。其身份链、源权重、BEST/LAST 归档及数据必须重新认证，而不是只按文件名加载。

四臂共同新增 5 轮、全 12 步损失、原配置与数据顺序；所有原模型参数联合训练。开始统一重置 Adam，构造模型与引擎后统一重设训练随机数；中断续跑恢复优化器、调度器、随机数和样本顺序。BEST 包含第零轮，LAST 固定第五轮；失败不自动追加预算。旧 GW7 的 13.61847 只用于认证起点，不能代替本次 R_CONTINUE 对照。

服务器先进行合成单元测试，再做真实批次零更新前/反向预检、共同起点回放和显存/耗时记录，通过后才开始训练。预检不做优化器更新，不改写来源目录；训练模式回放会改变临时 BN 缓冲，随后重新载入认证源并丢弃临时状态，正式训练独立重建。训练和评价只读开发验证，不运行测试集。

筛查条件预先固定：JOINT 的 BEST pooled MAE 相对本次 R_CONTINUE 与 SEPARABLE 均至少改善 0.5%，同时优于 LOCAL；自身 LAST 相对 BEST 退化不超过 1%；真实值≥314 及 7—12 步组不劣于本次 R_CONTINUE。保留逐时距、RMSE、MAPE、窗口 P95、偏差及固定困难窗口，并实报 LAST 对各对照。门槛属于单种子开发筛查，不是统计显著性。未超过可分离或局部对照，就停止相应必要性主张。

## 相近研究与贡献边界

检索日 2026-10-19；定向检索，不是系统综述。

- [D²STGNN](https://arxiv.org/html/2206.09112v2)：已有扩散/固有分解和局部时空卷积。本版保留此骨架。
- [STSGCN](https://ojs.aaai.org/index.php/AAAI/article/view/5438)：已有局部时空同步建模。不能以联合空间和时间为首创。
- [TraverseNet](https://arxiv.org/abs/2109.02474)：已有跨邻居历史状态的消息与注意力；作者存档全文的 Message Traverse Layer 段（公式 5—8）也明确进行空间与历史状态消息选择。与本版存在直接概念重叠。
- [STJLA](https://arxiv.org/abs/2112.02262)：官方摘要已提出对时空联合图做线性注意力；本轮未据此声称通读所有实现。
- [PDFormer](https://arxiv.org/html/2301.07945v2)：已将历史模式引入空间注意力以处理传播延迟（DFT 段公式 7—11）。本版不宣称识别真实道路传播时间。

因此，本版是受这些相关工作启发、在认证递推骨架内实施的受控结构扩展；新增注意力、稀疏图或联合时空读出本身均不构成已确立的强创新。潜在贡献只能由“同容量、同边缘分布的联合关联确有增量价值”及可重复证据支撑。若没有收益，保留负结果。

## 预期失效与解释限制

边和槽的关联可能已被强 R 充分表达；原始隐藏槽可能比混合槽更噪；top-k 可能漏掉有用弱依赖；动态边选择也可能使训练不稳定。零初始化只保证起点相同，不保证后续无偏或稳定。注意力熵、联合与可分离核差异及先验保留质量只能说明执行特征，不能代替预测效用、因果方向或物理机制证据。

开发验证集已经反复用于研究选择。即便通过筛查，也需冻结方案后另做配对多种子及独立确认，不能将本次最佳值写成普适优越性。
