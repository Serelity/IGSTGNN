# GW15：在原生时空与事故融合之前显式编码历史变化顺序

本轮直接实现一个内部结构改动，检验明确的增量问题：在固定、已认证的 GW9 SUM BEST 上，把历史一阶差分的真实顺序编码进交通隐状态，是否优于相同容量、相同差分值集合但移除差分先后顺序的内部适配器？不重新执行 GW13/GW14 查表诊断，不延长已经失败的旧分支，也不把弱诊断收益当成结构有效性的证明。

研究主题仍是 IGSTGNN 的交通时空建模。新增表示进入已有 ICSF、动态图构建和 DIF/INH 解耦路径；没有建立另一条查表预测链，也没有增加事故记录、未来观测或外部数据。

原 IGSTGNN 已有 GRU、位置编码和注意力，天然能够依赖顺序。本轮假设是显式差分表示可能使已有原生路径更容易利用变化顺序，而不是原模型在信息论意义上不具备顺序表达能力。

## 唯一新增结构与两个等容量臂

令已经按来源固定 mean/std 归一化的交通历史为 `x[b,t,n]`，长度为 12。只读取第 0 列交通值，不读取标签、未来流量或评价分组。先计算 11 个有符号一阶差分：

```text
d[t] = x[t+1] - x[t]
u[t] = d[t] / (1 + mean_t(abs(d[t])))
```

分母是每个起点、每个节点的单个公共尺度。它没有用验证集拟合新归一化，也没有把各时刻分别缩放。两臂输入仅有以下区别：

| 臂 | 适配器输入 | 作用 |
|---|---|---|
| SORTED_DELTA | 按数值升序排列的 11 个 `u[t]` | 保留有符号差分的完整多重集合、净变化和总绝对变化，移除这条新增路径上的真实先后顺序。 |
| ORDERED_DELTA | 真实历史顺序的 11 个 `u[t]` | 唯一候选，检验新增路径显式利用差分先后顺序的价值。 |

原生来源在两臂中始终接收未经排序的真实历史。排序只用于新增适配器，不能把本比较描述为从完整模型中移除了顺序，也不能声称排序形成了纯粹、完备的因果干预。排序会改变新增网络所见的输入分布；这是同容量功能对照的限制。

两臂使用相同结构和逐张量相同的初始权重：

```text
Linear(11, 16, bias=True)
  -> Tanh
  -> Linear(16, 12*H, bias=False)
  -> reshape [B,N,12,H] -> permute [B,12,N,H]
  -> 0.1 * Tanh
```

`H` 从认证原生 embedding 的输出维度读取。每臂新增参数总数为 `11*16 + 16 + 16*12*H = 192 + 192*H`，实际数值随运行身份一并报告，不用历史文档中的维度描述代替当前来源检查。第二个 Linear 的权重初始化为零，新增输出初始严格为零；第一层含偏置，因此训练后常量历史也可能产生共享修正，两臂有同样能力。

通过一次临时 forward hook，把残差加到 `original.embedding` 的输出，保持原 `[B,12,N,H]` 轴和 dtype/device。随后继续执行未改写的 ICSF、动态图构建、五层 DIF/INH、TIID 以及完整已训练 SUM 读出。hook 在正常返回与异常路径中都移除，不缓存跨批次张量，也不重建或替代原生 forward。

嵌套退化要求：零输出时，两臂在原认证的 eval/no_grad 推理条件下逐点、dtype、shape 精确恢复固定 SUM 预测。不放宽认证缓存比较容差。训练的 autograd 路径和认证 no_grad 推理路径可有不同数值分派；不能用训练路径的比较取代认证推理回放，也不能为了通过回放改变原生注意力配置。

新增残差用当前可观测的完整 12 点历史生成全部历史隐位置。这是预测起点之前的窗口编码，并非未来观测，也不是物理道路传播时延。

## 来源固定与梯度边界

从已完成 GW11 的认证初始来源恢复原 GW9 SUM BEST，不从 GW11 的退化 LAST 或 GW12 的新读出出发。既有认证文件、缓存和失败结论保持原字节与身份。

完整来源始终处于 `eval()`，参数和缓冲区不能更新；优化器仅包含当前臂的新适配器参数。为保持原认证推理分派，来源参数的 `requires_grad=True` 标志保留，不把“保留标志”误报为来源参数参与优化。

训练新适配器时不能把来源前向包在 `no_grad()` 中，因为损失需要通过原生时空与事故路径反传到新增的 embedding 残差。使用 `torch.autograd.grad(loss, adapter_parameters)`，只将返回梯度写入新适配器；来源参数的 `.grad` 始终为 `None`。每轮、保存与恢复检查来源 state_dict 哈希、参数标志、eval 模式、梯度为空和 hook 清理状态。

因此“固定来源”指来源张量不更新，不等于无主干反向计算。每个训练批次，两臂各执行一次完整来源前向和一次穿过来源的反向；不能沿用 GW12 共享一次无梯度来源前向的成本描述。完整计算时间与显存成本由服务器实际记录，当前没有测量值。

## 固定训练与一次开发筛查

保留认证的数据划分和预处理：训练 3909 个样本、验证 837 个样本，batch=48、每轮 82 批、seed=2025。两臂使用同一轮样本顺序、同一原生 MAE 目标、相同优化器配置与初始化张量。

每臂固定 3 轮、246 次优化器更新；逐轮学习率为 `0.002, 0.001, 0.001`。BEST 包含阶段零，LAST 固定为第 3 轮。恢复时载入原优化器、调度器和进度，不重置优化器或增加轮数。固定 SUM 的 0 次更新参考不是等训练预算控制；SORTED_DELTA 才是与候选相同新增参数和更新预算的训练对照。

唯一候选 ORDERED_DELTA 必须同时满足：BEST MAE 相对固定 SUM 和 SORTED_DELTA 各改善至少 0.5%；LAST 相对自身 BEST 退化不超过 1%；三个既定评价组的 BEST MAE 不劣于固定 SUM。评价组为真值至少 314、预测步 7–12、`50 <= 真值 < 200`，必须非空且两臂支持一致。未来真值仅用于评分，不能用于适配器输入、训练分流或阈值选择。0.5% 是沿用的实用筛查幅度，不是显著性水平。

本轮直接运行这一固定结构比较。仅保留源码、嵌套恢复、梯度边界与来源认证所需的必要服务器检查，不再要求用户先跑新的查表或信息充分性诊断。失败后不延长训练、补换 seed、调整排序规则或改变残差尺度来追逐同一开发集收益。

## 能支持的结论与不能支持的结论

若候选优于固定来源但未优于 SORTED_DELTA，证据更符合额外适配容量或差分集合的作用，不能归因于先后顺序。若同时通过两个主要比较和保护组，只能支持这个固定来源、固定预算下显式顺序表示有开发效用，下一阶段才讨论冻结方法后的独立确认。

若未通过，本轮只否定当前适配器、插入位置、固定来源与三轮预算的组合，不证明所有轨迹建模无效，也不授权自动开展下一轮相似诊断。应保留负结果并据研究主线决定是否停止这一结构方向。

本比较没有与同输入、同容量的最终输出适配器进行新的同步比较，因此不能单独证明“早期注入优于晚期读出”。旧 GW12 输入和容量不同，不能补作这个因果对照。没有增加事故条件专用控制，因此也不能宣称事故机制改善、事故识别有效或事件传播规律被验证。现有 development 已多次参与设计，任何通过都不是独立确认、统计显著性或普适优越性。
