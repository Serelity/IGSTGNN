# 原生递推预测与交互图记忆增量

状态：GW7研究候选，待服务器验证。GW6已回传的单种子开发结果中，JOINT BEST MAE约14.08655，递推对照约14.00802；JOINT第18至20轮95.708%有效点下移，平均变化−6.15916，变化标准差6.37405；均值匹配只消除约16.367%净MAE退化。最高真实值组约20.06%点承载52.94%逐点恶化总幅度。数字来自用户回传的20轮评价和漂移诊断，不是本次新增运行结果。

这些观察支持研究有条件的响应变化，不能证明softmax压缩幅值、某个BN或输出头是原因。GW7的可证伪问题是：原生预测之外，图源×图阶×历史窗的交互信息是否比普通残差记忆更有增量价值？

## 结构

保留完整原生DIF递推、INH、TIID和输出头，均参与联合训练。只从第一层的历史调用读取记忆M，轴为[B,N,G,O,W,C]。通过第一层gcn_updt的前置hook读取已经算出的receiver及按图源/阶排列的消息和，不改变原生forward返回值、求和顺序或随机数行为。

P_G、P_O、P_W分别沿图源、图阶、历史窗取均值并广播。普通记忆控制的两个bank为P_W M与(I-P_W)M；完整候选将相同两路bank分别投影为：

\[
A=(I-P_G)(I-P_O)P_W M,\qquad
B=(I-P_G)(I-P_O)(I-P_W)M.
\]

三种投影相互交换，A+B=(I-P_G)(I-P_O)M。A保留窗口平均的图源×图阶交互，B保留交互的窗口变化。只有两阶时，相当于考察“某图源二阶减一阶，是否偏离所有图源共同的阶差”，再分成历史均值与变化。这里的算子阶和编码窗口不当作物理传播延迟。

查询由历史receiver、起点可得ICSF和实际目标时距构成，不用未来标签。两个bank通过同形状、同参数数目的reader读取：

\[
\widehat y_{n,h}=f_R(X,C)_{n,h}+W_{out}[z^A_{n,h};z^B_{n,h}].
\]

value和最终输出投影无bias；仅最终W_out零初始化，其他投影正常初始化。新增量在原预测的同一归一化域相加，然后共用一次逆变换。新增路径不经过原融合ReLU头，不增加末端非负截断。

W_out=0应恢复相同模式、requires_grad、RNG和精度下的原生预测；A=B=0时新增量恒为零。初始第一步内部reader梯度可为零，输出投影先获得梯度，后续更新才向内部传播。

交互投影不是物理守恒，不保证输出均值不变、无偏或训练稳定。attention能把零和记忆读成非零增量；原生主干也可漂移。应记录记忆投影前后RMS，以及固定批次上f_R、增量和总预测的变化。

## 对照与预算

四臂R_CONTINUE、R_MLP、R_MEMORY、R_INTERACTION_MEMORY统一从完成20轮GW6的同一RECURRENT_CONTROL权重开始，新增5轮、统一full12损失和训练配置。普通/交互memory唯一差异是(I-P_G)(I-P_O)投影；MLP用接近的活跃容量，实报差异，不填闲置参数。BEST包含共同第0轮；LAST固定为第5轮。

先用GW6第18/20轮固定输入执行一次无训练分支诊断，再显式启动新训练。诊断报告只认证执行与端点差异，不自动证明原因。筛查结果及阈值见根目录GW7_SERVER_README.md，后续确认不自动执行。

如果普通memory同样好，交互约束没有必要；如果MLP同样好，图记忆的必要性没有得到证据；如果交互信号很小，投影可能丢失了有效信息。当前反复使用的开发验证集不能作为独立确认。

## 相似工作边界

归一化后恢复统计量已有[RevIN](https://openreview.net/forum?id=cGDAkQo1C0p)；图阶混合和差分已有[MixHop](https://arxiv.org/abs/1905.00067)；两张softmax注意力相减已有[Differential Transformer](https://arxiv.org/abs/2410.05258)；交通历史误差检索及门控修正已有[DeCyReM](https://www.mdpi.com/2227-7390/14/17/3207)。本版不以残差、去均值、图阶差分或门控本身宣称新颖性。

候选贡献只可能落在原生预测与特定交互增量的分工，以及它超过相同预算普通残差对照的可重复证据。本版读取当前样本的历史消息，不构建跨样本未来误差记忆。有限文献核对不保证该组合首次出现；尚无GW7精度结果。
