# IGSTGNN B3-R：审核意见与深化开发方案

**修订接续（2026-10-12）：** 用户后续审核已纳入[B3-R研究方案V1.1](igstgnn_b3_r_research_plan_v11_20261012.md)。执行以新方案为准，尤其补充最终交换量敏感性、时间/事件证据、确定运行条件和日志累计单位；第10轮仅作工程与优化观察，不作精度淘汰门槛。

日期：2026-10-12。状态：设计审核与局部数学核验完成；B3-R 尚未接入仓库模型或训练器，尚无真实数据训练结果。

审核对象为用户提供的[报告条件残差更新建议](verification/igstgnn_b3_r_user_suggestion_20261012.md)，原文件 SHA256 为 `33695f559c37d11b6a6dd880bff4857a57acc5e4cc742825cfde8db5eb5d1654`。本次直接核对了当前 `incident_spatial.py`、`igstgnn.py` 和 `train_internal_spatial.py`，源码指纹见[模块核验记录](verification/igstgnn_b3_module_audit_20261012.json)。

## 1. 审核结论

建议采纳 B3-R，作为 B3 深化的第一个候选：用“历史容量基线 P＋报告条件修正 D”替代“历史状态 A＋候选 U＋采用门 G”，先保持容量之后的空间交换及主干接口不变。

这仍是在 IGSTGNN 内部改造事故信息的使用方式。残差加在容量 logit 上，修正容量再影响主干内部的空间交换；它没有回到此前在最终预测外部叠加修正量的方案。

目前回传的四组累计70轮结果中，B3 最佳验证 MAE 为22.613580，相对 B0/B2 最佳值改善约0.88%/0.37%，但仅为单种子探索性证据，尚不能证明报告更新、容量限制各自的贡献。用户已启动原四组向100轮续跑，本设计不改变该运行的源码、配置、检查点或学习率协议。结果依据见[七十轮分析](igstgnn_internal_spatial_is11_epoch70_20261012.md)。

## 2. 建议中可以直接保留的部分

| 建议 | 审核结果 |
| --- | --- |
| P 为120→16→4，D 为156→16→4 | 与当前历史条件、报告条件维度相符，不增加外部数据要求。 |
| `c = 0.001 + 0.999 * sigmoid(p + m * delta)` | 直接表达相对历史基线的容量修正；允许正负变化，容量仍有界。 |
| 将原 A 的末层权重和偏置取反映射到 P | 推导正确；这里 A 指 sigmoid 前的 logit 网络，不能对 sigmoid 后的概率直接取反。 |
| D 仅末层零初始化 | 初始化容量回到历史基线；隐藏层保持正常初值，末层学习后可向隐藏层传递任务梯度。 |
| 保留原图、边界、交换、读出和 TIID | 限制首轮变化范围，便于解释整体报告更新方案的比较。 |
| 移除旧 U/G 注册参数 | 两网络报告与边界模块合计4,848参数；按当前 B3 总量推算，新模型应为455,780参数。仍须在接入后实际计数。 |
| 不把 B3-R 称为纯 G 消融 | 正确：网络分解、容量表示和报告初始化同时改变，结果不能证明 G 单独无用。 |
| 不将隐藏容量解释为真实通行能力 | 正确：当前没有容量标签、单位标定或车道损失观测。 |

U 与 G 可以以不同组合得到相同更新结果，足以支持尝试更直接的参数化；这不是 G 必然有害的证明。P 和 D 都读取历史条件，新的功能补偿仍然可能存在。

## 3. 实施前必须补齐的五项

### 3.1 将“节点容量到边容量”做成明确接口

现有 `state_capacity(state, graph)` 的第一步是 `node_capacity = 0.001 + 0.999 * (1-state)`。它接收的是旧限制状态 a，不是容量 c。

B3-R 已直接生成 c，不能把它传给这个旧函数，否则会再次反向转换。新接口应明确接收 `[B,N,4]` 节点容量，仅完成以下映射：内部边取两端最小值，入口取目的节点容量，出口取源节点容量；外部端点 `-1` 不能当作站点索引使用。

旧 B3 保持原接口和原行为，新版本另设适配。验收应包含内部边、入口、出口、空图以及未关联报告节点，并检查所有数值有限。

### 3.2 新诊断字段必须与 P/D 的含义一致

现有 `Diagnostics.update` 固定读取 `prior`、`posterior`、`adoption`，并由 prior 重建容量。直接替换模型而不改诊断器会报错或记录错误语义。

建议新版本明确返回 `base_node_capacity`、`node_capacity`、`base_edge_capacity`、`capacity`、`base_logit`、`updated_logit`、`report_logit_delta` 和 `effective_logit_delta=m*delta`。诊断记录节点与边的容量差、有效修正幅度、sigmoid 斜率或饱和比例，保留原交换预算、边界流量和收支统计。

报告关联节点的条件统计与全图统计分别报告，并保留分母。大量零掩码节点会稀释全图均值，不能仅据此认定 D 不起作用。旧“采用率”字段在新版本中消失，不用虚假的别名维持兼容。

### 3.3 公共初始化要逐参数核对

先构造规范的、尚未训练的 B3 初始化，再向 B3-R 显式复制保留的主干、TIID、边界头及所有交换层参数；按上述符号映射生成 P，D 隐藏层可复制规范 U 的隐藏层，D 末层置零。删除 G 会改变后续随机数消费顺序，因此相同种子不等于公共参数相同。

至少记录公共参数的名称、形状与哈希，并验收：

1. P 生成的历史容量与原 A 的历史容量在浮点容差内相同。
2. B3-R 自身初始化时，空间修正 ON/OFF 的容量和预测一致。
3. 与规范 B3 的空间报告 OFF 比较，初始容量及预测在容差内一致；不要求等于原完整 B3 的 ON，也不要求等于 B0。

正式从头训练不读取已训练 B3 权重，不继承旧优化器。未来若做迁移，另设实验身份。

### 3.4 梯度验收至少覆盖两次更新

D 末层为零时，首次反向的隐藏层任务梯度为零是预期行为；末层可先获得梯度，更新后再使梯度进入隐藏层。不能要求第一步所有 D 参数都有非零任务梯度，也不能因此判定路径断开。

仓库接入验收必须使用最终预测损失，验证“损失→交换读出→交换量→容量→D”的路径，并构造容量实际限制交换的输入。至少检查末层第一步、隐藏层后续步骤，区分任务梯度与 weight decay 导致的参数变化；原 TIID 或 E 的梯度不能替代 D 路径验收。

保留首版不加 tanh、幅度系数或新正则的安排。先记录 logit 与 sigmoid 饱和情况；只有出现可复现的优化问题，再单独提出约束及对照。

### 3.5 区分检查点敏感性与从头训练对照

| 实验 | 可以回答的问题 | 不能直接得出的结论 |
| --- | --- | --- |
| 旧 B3 与 B3-R 从头训练 | 报告更新整体精简方案是否值得保留 | G 的独立贡献、纯参数量效应 |
| B3-R 同检查点空间 ON/OFF/ON | 该权重是否依赖新增修正路径；切换能否恢复 | 从头训练该路径是否有用、报告的因果效应 |
| B3-R ON 与空间修正 OFF 分别从头训练 | 在原 TIID 保留时，新修正路径是否值得保留 | 全部事故信息的贡献 |

从头训练 OFF 应在大规模种子扩展之前完成。D 读取历史 s，且 m 本身来自事故关联信息，所以整个 D 路径关闭同时减少了历史条件处理能力；这不是只删除外部报告信息的严格对照。若需要“报告信息本身”的结论，另设计有效处理能力匹配的中性报告对照，并审查 E、年龄、距离和掩码的信息残留。对照仍保留目标信息属于消融不完整；截止点之后才可获得的信息进入输入或训练属于相应时间泄漏问题，两者分别处理。

## 4. B3 各模块的合理性与待验证问题

| 模块 | 当前合理之处 | 待验证问题及本轮处理 |
| --- | --- | --- |
| 历史容量基线 | 无报告时仍有历史驱动的传播条件，覆盖报告稀疏场景 | 隐藏容量是否有用尚无单独证据；本轮用 P 继承同一基线。 |
| 报告条件更新 | 报告作用集中进入容量，再影响空间计算 | 优先检验 P/D；不新增未获得的事故类型、封道或严重度输入。 |
| 节点到边容量映射 | 将报告条件转为共享边约束，简单且可审计 | 两端最小值是建模假设，不是真实道路瓶颈定律；首轮保留。 |
| 边交换提议 | 利用两端隐藏特征、状态和容量决定候选交换 | C 同时进入提议网络与硬上限，关闭硬上限不会消除全部容量作用。 |
| 发送、接收共享预算 | 比逐边独立裁剪更直接处理多出边、多入边竞争，保持潜在状态有界 | 当前是可行比例分配，不是最大通量或真实转向分配；先保留。 |
| 开放边界头 | 给不完整观测图显式入口、出口，内部收支可以核对 | 缺少真实匝道观测，边界可能吸收误差；继续单独记录入口/出口响应。 |
| 交换读出 | 将潜在交换接回原隐藏特征，让最终预测损失监督新支路 | 固定两步、eta=0.5时存在代数冗余，单列工程精简，不与 P/D 同改。 |
| 原统计图与 TIID | 保留原 IGSTGNN 表达能力与已有时间事故路径 | 新预算只约束新增交换支路，不能声称整个模型满足物理守恒；TIID 开关继续独立。 |
| 状态编码与调用频率 | 每次空间调用从本地隐藏特征编码状态，一次完整前向共享容量 | 没有跨层持续维护的物理状态；本轮不同时改成动态容量或连续模拟器。 |

当前候选图支持476/496站，仍是候选道路结构，不等于已认证物理图。未覆盖站点继续有原主干预测，预算资格不扩展到原统计图。诊断中的候选连通区域只是结构性潜在范围，不能当作实际传播区域或因果影响范围。

## 5. 本地核验结果及范围

[B3-R 局部核验](verification/igstgnn_b3_r_review_20261012.json)已经完成独立 P/D 原型计算：

- 参数核算：报告与边界模块从7,428降至4,848，总量按现有 B3 推算455,780。
- A→P 历史容量映射：FP32 最大绝对差 `8.94e-8`，FP64 为 `1.11e-16`。
- 零末层初始化时，容量 ON/OFF 差为0；未关联节点严格回到基线，容量有限且有界。
- 独立容量目标下，D 末层首步有任务梯度、隐藏层首步为0，后续步骤隐藏层获得梯度。

这些结果验证公式、参数和零初始化的局部行为；尚未验证完整 IGSTGNN 的主预测损失梯度、运行时间或预测收益，没有读取服务器真实数据或检查点。

[B3 模块合成核验](verification/igstgnn_b3_module_audit_20261012.json)还确认：

1. 三节点分叉反例中，接收受阻的一条边会使部分发送预算未被重新分配，实际总交换0.5，而可行交换可达1。这体现当前分配策略，不自动构成程序错误；重分配需要新的路由假设。
2. 两步、eta=0.5且没有裁剪时，`最终状态−初态 = 平均流入−平均流出`，B3 的12维读出可折叠为8维；该等式不能直接用于有裁剪的 B2。
3. 提议输入中重复的源状态、目的状态与其补量可在第一仿射层折叠，84维可改为76维。已有权重的函数可等价转换，不代表从头训练轨迹不变。
4. 只去掉显式边上限，保留节点发送/接收预算，仍可保持状态范围和潜在收支关系，为后续较少受 B2 裁剪干扰的对照提供依据。该变体尚未实现。

因此，首轮只改 P/D；输入折叠、读出精简、分叉分配、动态容量都保留为后续独立问题。

## 6. 拆分后的开发与验收顺序

| 小任务 | 交付物 | 通过条件 |
| --- | --- | --- |
| B3R-A：容量模块 | 独立 P/D 类与节点容量→边容量接口 | 形状、掩码、正负修正、有限范围及开放边映射正确；旧 U/G 不残留。 |
| B3R-B：公共初始化 | 规范初始化映射、公共参数核对产物 | P 符号映射、D 零末层、公共参数一致；与旧 B3 空间 OFF 的初始对应关系通过。 |
| B3R-C：诊断适配 | 新容量/修正日志及原交换统计 | 字段语义正确、分母清楚、记录完整；主预测损失的两步梯度检查通过。 |
| B3R-D：实验入口 | 独立配置、训练器与恢复身份 | 沿用原数据与训练协议，明确 ON/OFF；恢复拒绝错误架构或参数集合。 |
| B3R-E：工程与首轮 | 局部检查及服务器完整1轮 | 不改变旧运行；共享初值、完整分组、检查点、梯度和交换约束产物可读。 |
| B3R-F：配对判断 | 第10轮观察工程与优化，再按共同预算比较并安排独立训练OFF | 不用早期排名裁定结构有效性；效果遵循既定上限、早停和选模规则，OFF在大规模种子扩展前补齐。 |

新版本使用独立源文件和入口，优先复用版本固定的源码及训练循环，保留模块仍按原协议端到端训练。当前训练器将模型与入口源码纳入身份指纹；不能为了新增实验改写被原100轮运行使用或用于其后续恢复的文件。若最终需要修改公共文件，应先保证旧协议可从固定快照继续恢复。

比较保持全496站主任务、原训练/验证样本、输入、优化器和学习率计划。训练上限100、patience20及原选模指标保持，不用 B3-R 第10轮与旧 B3 第100轮最佳值排名。旧 B3 结果只有在数据、协议及公共初始化身份可核对时才能复用；没有必要自动重跑四组。Test 继续封存。

若 P/D 方案值得保留，后续优先做“去掉显式 `min(q,C)`，保留 C 作为提议输入并保留发送/接收预算”的有界对照，以检验硬上限的独立价值。它仍有容量信息，不能称为无物理或无事故模型。若要论证 P/D 下整体受限交换优于普通交换，则另外配套同 P/D 的普通交换组；旧 B2 不足以隔离该差异。

## 7. 思想来源与借鉴边界

| 来源 | 可以借鉴的思想 | 本方案没有因此获得的性质 |
| --- | --- | --- |
| [ResNet，He等](https://arxiv.org/abs/1512.03385) | 学习相对基线的修正，减少直接学习完整映射的负担；启发 P＋D 的组织方式 | 该论文未给出本方案的容量 logit 结构，也未证明 D 零初始化在本任务最优。 |
| [KalmanNet，Revach等，IEEE TSP 2022](https://doi.org/10.1109/TSP.2022.3158588) | 在部分已知结构上学习观测更新，区分历史预测与新增观测作用 | 当前不是卡尔曼滤波，没有协方差传播、标准创新项或贝叶斯容量后验。 |
| [Daganzo，The Cell Transmission Model: Network Traffic，1994](https://escholarship.org/uc/item/9pz309w7) | 容量、可发送量、可接收空间与网络边界共同决定交换；容量可随事故等条件变化 | 当前无密度、路段储量、时间/长度标定及转向比例，不是已校准的 CTM。 |
| [Horie与Mitsume，Graph Neural PDE Solvers with Conservation and Similarity-Equivariance，ICML 2024](https://proceedings.mlr.press/v235/horie24a.html) | 将局部通量与共享边更新写进图网络结构，从构造上维护收支关系 | 潜在支路的收支一致不等于真实交通状态或最终流量预测守恒。 |

这些是设计思想的来源与类比，不是 B3-R 的直接实验依据。当前可检验的新问题是：在有限事故报告下，直接容量修正能否比三头更新更有效地驱动 IGSTGNN 内部传播，以及显式容量上限是否有独立价值。

方法工具说明：本审核使用本地 `scientific-critical-thinking` 与 `experimental-design` 技能组织证据边界、匹配对照和验收任务。工具来源为 Kassis等，2026，[Scientific Agent Skills: A Library of Procedural Knowledge for Research Agents](https://doi.org/10.48550/arXiv.2609.00065)。该引用说明审核流程来源，不替代模型或实验依据。
