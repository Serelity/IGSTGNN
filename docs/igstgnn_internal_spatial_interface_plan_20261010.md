# IGSTGNN 内部事故状态与受限空间传播：下一阶段方案

日期：2026-10-10。版本：IS1.0。状态：**设计规格，尚未实现、训练或取得新预测结果**。

本方案承接用户《IGSTGNN事故信息与物理传播改进构想_审核建议_20261010.md》及[既有消融复盘](igstgnn_internal_incident_ablation_review_20261010.md)。将“事故报告—有效交换能力—交通影响传播”落实到 IGSTGNN 内部。第一阶段比较空间机制，保留原 TIID，全部 496 站参与训练和评价。

## 1. 本阶段回答的问题与交付

**研究问题：在现有单报告、流量历史和有限道路结构下，用报告更新历史形成的运行限制判断，再调制内部空间交换，是否比原 ICSF 和同信息的普通神经交换更有预测价值？**

本阶段交付五项：

1. 明确的内部接入位置和状态职责。
2. 同输入、同参数的普通与受限交换算子。
3. B0—B3 四组可重训练参照。
4. 全 496 站主指标、机制覆盖和路径响应记录。
5. 可分步执行、可恢复、不会覆盖旧实验的服务器入口。

首版只使用现有流量、时钟、原触发报告及固定候选道路结构；速度、占有率、多报告集合、车道数、封道记录、恢复时间均不作为必要输入。现有道路资料审查可以继续进行，但不同时改变首轮模型输入。

## 2. 证据如何约束设计

| 已有证据 | 本次设计决定 | 结论限制 |
|---|---|---|
| 单报告 ICSF 两个 softmax 轴长度为 1，关联节点权重恒为 1 | 用简单强度门控 B1 作低成本参照；新模块显式更新状态 | 不等于整个原 ICSF 无效 |
| v12c 已有节点强度门控，旧实验冻结主干 | B1 复用数学形式，重新端到端训练 | 旧端点不能代替当前 B1 |
| 归一化干预的影响明显 | 四组保留原最后一帧 LayerNorm；不增加只有候选使用的归一化层 | 归一化收益不归入报告收益 |
| P2 逐层关闭结果方向不同 | 报告状态只更新一次；同一状态供内部算子读取 | 不根据关闭结果挑第 3 层，也不声称重复注入是已证实根因 |
| M4.5 关闭新增容量报告路径的净收益很小 | 直接改 ICSF 的空间职责与 DifBlock，不延续输出残差调参 | 旧探针不能比较新模块与原 ICSF |
| M3 已有共享预算、边界及潜收支测试 | 复用图聚合和预算工程经验 | 不能直接继承分钟递推、旧融合头或旧科学资格 |

本文件的公式、维度和运行预算是新的设计选择，不是已有实验结论。旧结果仅用于提出假设，不用于预先宣布某一组会获胜。

## 3. 准确的内部改动位置

### 3.1 当前源码的数据流

根据 [igstgnn.py](../src/models/igstgnn.py)：

```text
历史嵌入
  → ICSF 最后一帧融合及 LayerNorm
  → 静态/动态图构造
  → 5 个 DecoupleLayer
       EstimationGate
       → DifBlock: STLocalizedConv → forecast/backcast
       → InhBlock: 读取 dif_backcast_seq_res
  → 汇总 forecast_hidden
  → TIID
  → 原输出头
```

`DifForecast` 还会多次调用同一个 `STLocalizedConv`，生成后续预测块的隐藏特征。接入时必须覆盖这些调用，不能只改 `DifBlock.forward` 中的第一次调用。

### 3.2 IS1.0 的接入决定

| 位置 | B0/B1 | B2/B3 |
|---|---|---|
| 报告编码 | 原编码器 | 同架构原编码器，共同初始化 |
| ICSF 空间注入 | B0 原注入；B1 强度门控注入 | 取消原 V 向量直接注入，改为一次报告条件状态更新 |
| 最后一帧 LayerNorm | 原操作 | 相同位置、相同维度的操作，输入为无报告直接注入的历史 |
| 原 EstimationGate | 保留 | 保留；不启用旧 ACDG |
| STLocalizedConv | 原空间计算 | 保留统计图计算，在其内部加入同一空间交换接口 |
| backcast/forecast 分支及 InhBlock | 保留 | 保留结构和张量契约 |
| TIID 与输出头 | 原结构 | 原结构及原 K/距离输入契约 |
| `forecast_delta` | 不使用 | 不使用 |

这里保留原统计图，是因为它承担一般交通相关性建模；新道路交换只承担有证据支持的有向局部交换。学习图和原邻接矩阵不进入受限收支预算，不被解释成真实道路流量连接。

**内部改造的实质：** 新交换结果改变 `STLocalizedConv` 输出，随后同时进入扩散 backcast 与 forecast。backcast 再影响内生分支。它不是 TIID 后增加的一份未来预测修正。

“保留 InhBlock”指保留结构，并不要求它的数值输出不变；它的上游输入已经改变。

### 3.3 修改范围与实现方式

首选新增独立模块，给原模型增加显式模式开关，默认保持原行为：

```text
incident_spatial_mode = native | strength | state_ordinary | state_restricted
```

新增上下文通过显式参数传入 `DecoupleLayer`、`DifBlock`、`DifForecast` 和空间算子。每次 forward 创建局部上下文，不使用可跨 batch 残留的全局缓存或长期 hook。

B2/B3 共享完全相同的实现和可训练参数，唯一结构开关是是否执行第 5 节的预算限制。旧 ICSF 的 Q/V、单报告融合 MLP 不再作为 B2/B3 的活跃可训练模块；共同参数迁移使用明确的名称清单，不以宽松加载掩盖漏载。

## 4. 状态、索引与信息权限

### 4.1 三类状态

| 符号 | 首版形状 | 定义 | 不作的解释 |
|---|---|---|---|
| \(H\) | `[B,T,496,32]` | IGSTGNN 普通隐藏特征 | 不对其全部通道施加收支守恒 |
| \(a^-_0,a_0\) | `[B,496,4]` | 历史先验与报告更新后的运行限制潜状态，范围 `[0,1]` | 不是真实封道比例、事故阶段标签或容量损失真值 |
| \(x^{(s)}\) | `[B,W,496,4]` | 一次空间调用内的有界交换潜状态 | 不是真实车辆数、密度或队列长度 |
| \(C\) | `[B,E,4]` | 潜单位的边交换上限 | 不宣称单位为 veh/5min |

四通道是首版的低维建模选择，不对应四条车道或四种事故类型。四个通道分别进行收支更新，不在交换子步之间混合坐标。

索引严格区分：历史观测时间 \(t\)、网络层 \(\ell\)、空间子步 \(s\)、预测块 \(b\)、目标窗口 \(k\)。空间子步取 `S=2`、无量纲步长 `eta=0.5`；二者均不换算成分钟。

### 4.2 历史先验与一次报告更新

在原 ICSF 注入之前，从流量嵌入构造报告无关摘要：

\[
u_i=[H_{last,i},\ \operatorname{mean}_tH_{t,i},\ H_{last,i}-H_{first,i},\ TOD_0,\ DOW_0].
\]

采用现有 `hidden=32,time_emb=12`，摘要维度为 120。报告条件为原编码向量、三维关联距离和年龄除以 5，共 36 维；不加入描述、类型、最终持续时间或处置信息。

\[
a^-_{0,i}=\sigma(A_\theta(u_i)),
\quad \widetilde a_i=\sigma(U_\phi([u_i,e_i])),
\quad r_i=\sigma(G_\psi([u_i,e_i])),
\]

\[
a_{0,i}=a^-_{0,i}+m_i r_i(\widetilde a_i-a^-_{0,i}).
\]

`A/U/G` 均为一层宽度 16 的 MLP，再输出 4 维；隐层使用 ReLU。`m` 沿用原报告关联规则，不依据目标或预测误差选站。报告空间关闭时，`m=0`，得到严格的 `a0=a0_prior`。无报告不代表无事故，仅表示没有这条报告带来的更新。

凸组合保证状态有界。报告可以增强或减弱历史已有的限制判断；不规定“有报告就一定再降低容量”。`r` 是学习到的采用强度，不称为已校准置信度；状态更新差也不称为卡尔曼新息。

同一次模型 forward 仅计算一次 \(a_0\)。5 层及 `DifForecast` 后续调用均读取它，不在每层重新执行报告融合，不制造新报告到达时间。

### 4.3 从限制状态得到交换上限

首版不用额外自由容量尺度，避免与状态幅度重复参数化：

\[
c_i=\epsilon_C+(1-\epsilon_C)(1-a_{0,i}),\qquad \epsilon_C=10^{-3},
\]

\[
C_{ij}=\min(c_i,c_j).
\]

内部边取两端限制的最小值，开放入口/出口取所连接节点的 \(c_i\)。这是一项对称局部瓶颈先验，不等价于真实道路的完整基本图；真实发送、接收能力不足的辨识问题仍然存在。

限制状态增大必然降低该容量上限；但完整网络中的实际边交换还受提议、竞争和其他预算影响，不预设所有边的实际流量都单调变化。

### 4.4 读取权限

| 计算 | 可读 | 禁止直接读取 |
|---|---|---|
| 历史先验、空间初态、开放边界提议 | 截止点合法流量历史、时钟、原隐藏特征 | 报告及其关联掩码的直接输入、未来目标、排除的两个原始槽 |
| 报告状态更新 | 历史摘要、原触发报告字段、关联掩码 | 未来交通、事后持续时间、未保存的报告版本 |
| 空间边提议与受限算子 | 历史特征、当前 \(x\)、\(C\)、固定道路边及边界类型 | 报告向量、报告距离、报告掩码的独立旁路 |
| 新空间读出 | 原统计空间输出、\(x^S-x^0\) | \(a\)、报告向量、报告掩码直接拼接 |
| 原 TIID | 原 `incident_key/sensor_features/distances` 契约 | 新 \(a/x\) 或隐藏加入的额外键 |

首版不把 `x_valid` 当作候选新增可学习特征；四组继续使用相同的填补与目标有效掩码。以后若研究缺失信息，另设同结构输入实验。

后续层或预测块的隐藏特征可能已受到前一次合法交换的间接影响，这是模型内部传播的一部分；“没有报告直接输入”不表示这些特征与报告统计独立。历史先验与开放边界始终从最初的报告无关历史计算。

### 4.5 空间初态与读出

复用 `STLocalizedConv` 中长度为 `k_t=3` 的窗口变换和均值表示 \(h\)。每一层有自己的初态编码器、边提议网络和读出；同层所有空间子步和预测块复用参数：

\[
x^0=\sigma(P_\ell(h)),\qquad P_\ell:\mathbb R^{32}\rightarrow\mathbb R^4.
\]

同一次空间调用内，只用交换更新 \(x\)，不重新编码或归一化。换层、换历史窗口、换预测块允许重新编码，**不声称这些调用之间存在连续的潜收支或物理时间演化**。

令 \(z_{stat}\) 为原 `gconv` 输出，加入交换位移：

\[
z=z_{stat}+W_\ell(x^S-x^0),\qquad W_\ell:\mathbb R^4\rightarrow\mathbb R^{32}.
\]

`W` 不带 bias，采用正常非零 Xavier 初始化，不增设一个初始为零的自由融合门。B2/B3 的初始化逐项相同；不同空间规则的初始预测不必相同。没有可用交换的节点位移为零，其直接新空间增量为零。

当前报告调制整个预测调用中的隐藏表示，包括由历史窗口构成的特征；这是截止点条件编码，不是宣称报告在过去已可见，也不把这些条件化特征拿去重建过去真值作事故监督。

## 5. 完整的普通与受限交换

### 5.1 共同边提议

对候选内部边 \(i\rightarrow j\)，同一个 MLP 计算非负提议：

\[
q_{ij}=\sigma(F_\ell([h_i,h_j,x_i,x_j,C_{ij},D_i,R_j])).
\]

`F` 隐层宽度 16、ReLU、输出 4 维。发送与接收预算定义为：

\[
D_i=x_i,\qquad R_i=1-x_i.
\]

B2/B3 都能读取容量、发送和接收信息；B2 可以学习近似限制关系。二者共享完全相同的提议网络、状态编码器、报告更新、边界预测和读出参数。

每个节点的开放入口/出口提议分别由 ICSF 前的最后一帧历史嵌入经两个共享的 `32→4` 线性层加 sigmoid 给出，再乘固定边界存在掩码；不直接读取报告或 \(a\)。每次模型 forward 只计算一次，并在各层、空间子步及预测块中复用，作为历史预测的背景条件。多条原始匝道可在主线站聚合成一个开放入口和一个开放出口，保留来源列表。

### 5.2 B2：同信息的普通有向神经交换

采用 \(f=q\)，不强制边容量、共享发送或共享接收预算：

\[
y_i=x_i+\eta(\sum_jf_{ji}-\sum_jf_{ij}),\qquad x'_i=\operatorname{clip}(y_i,0,1).
\]

固定 clip 保持两组状态的定义域相同；必须记录 clip 比例和截断量。B2 不声称收支守恒。它是一个参数匹配、可看到同一限制信息的普通有向消息参照，不代表所有普通 GNN 的最优实现。

若 B2 频繁截断并出现学习不稳定，先检查其数值适用性；对不稳定参照的优势不足以确认受限结构的价值。必要时另立版本，给两组共同调整步长，或补充同信息的有界神经转移参照并披露参数差异，不在看到 B3 收益后只削弱 B2。

### 5.3 B3：边容量、共享发送与共享接收限制

以下操作逐潜通道执行，所有预算和提议来自同一个旧状态；不按边顺序原位更新节点。

**先限制每条边：**

\[
b_e=\min(q_e,C_e).
\]

**再共享发送预算：** 对每个真实节点，将内部出边和开放出口一起分配：

\[
s_i=\begin{cases}\min(1,D_i/\sum_{e\in Out(i)}b_e),&\sum Out(i)b_e>0\\1,&\text{otherwise},\end{cases}
\qquad b'_e=b_e s_{src(e)}.
\]

开放入口的源是外部，发送缩放设为 1。

**再共享接收预算：** 内部入边与开放入口一起竞争：

\[
r_j=\begin{cases}\min(1,R_j/\sum_{e\in In(j)}b'_e),&\sum In(j)b'_e>0\\1,&\text{otherwise},\end{cases}
\qquad f_e=b'_e r_{dst(e)}.
\]

开放出口的目的地是外部，接收缩放设为 1。零分母使用显式分支，不通过给所有分母加 epsilon 改写预算。

**同时更新：**

\[
x'_i=x_i+\eta(\sum In(i)f_e-\sum Out(i)f_e).
\]

每条内部边只保存一个实际 \(f_e\)，同一值加入下游、扣除上游。两次比例缩放给出明确的合流/分岔分配规则；接收受阻后不将剩余发送量重新分配给其他边。本规则保证预算可行，但不宣称最大吞吐、真实转向比例或 FIFO，也不是原网络 CTM 节点求解器的完整复现。

### 5.4 有界与潜收支约定

由 \(\sum Out f\le x_i\)、\(\sum In f\le1-x_i\) 和 \(0<\eta\le1\)：

\[
(1-\eta)x_i\le x'_i\le(1-\eta)x_i+\eta\le1.
\]

B3 不靠 clip 保持范围；若越界超过浮点容差，运行失败并保留诊断。B2 的 clip 是参照算子的一部分，不将其截断当作合法外部源汇。

开放图的逐通道收支为：

\[
\sum_i(x'_i-x_i)=\eta(\sum f_{external\to node}-\sum f_{node\to external}).
\]

只在一次空间调用、同一通道内检验此式，不跨隐藏层、批次或预测块累计成真实交通守恒。

由于提议网络也读取 \(C\)，容量变化可能通过提议产生响应，即使硬上限没有激活。机制分析须区分“完整报告路径响应”和“固定提议下的限制响应”，不能把所有容量响应都归为硬物理约束。

### 5.5 首版数值选择

| 项目 | IS1.0 取值 | 理由与边界 |
|---|---|---|
| 潜通道 | 4 | 控制自由度；不是物理车道数 |
| 空间子步 / eta | 2 / 0.5 | 允许相邻交换后再传播；满足有界条件，不对应分钟 |
| 参数初始化 | 新网络常规初始化，B2/B3 精确共享 | 不为了初始输出一致强行关闭新路径 |
| 预算/状态容差 | float32 验收绝对容差 `1e-5`，另报误差最大值 | 工程容差，不是预测收益阈值 |
| 收支检查 | float64 独立核验，并按累加规模记录 float32 误差 | 不把不同图规模的舍入误差混为机制错误 |

这些数值在首个真实预测实验前写入独立协议。之后修改维度、子步或算子，必须产生新候选版本，不能在同一个 run 下静默修改。

## 6. 数据范围、道路资格与缺信息行为

### 6.1 固定主任务

保持当前开发包：3604 个训练窗口、917 个验证窗口、496 站、12 个目标窗口，使用原 `report_location_v1` 单触发报告。流量历史仍取原槽 `0:12`；排除槽 `12:14`；目标取 `14:26`。不扩大监督样本，不读取 test。

历史、报告和道路信息按各自来源保存哈希。报告可见性仍依赖当前记录时间与位置的离线假设，不因换模型而认证为真实在线首报。

### 6.2 两种图的使用

已回读的 `contra_network_m41_final/summary.json` 记录：显式开放交换候选图覆盖 476/496 站，保守无匝道候选图覆盖 216/496 站；已联合认证节点数为 0。476 是元数据候选覆盖，不是物理验证覆盖。数字对应当前产物快照，新的输入打包需要重新核对。

首版选择覆盖较广的固定候选图作**探索性结构**，B2/B3 完全共用。开放边界显式容纳已映射匝道和走廊截断，不因缺少匝道观测而假定交换为零；其潜交换是历史预测量，不是真实匝道流量。

没有足够关系证据的节点不补造内部边；没有边界来源时也不随意给每站增加一个自由储库。其基础预测保留，新交换直接增量为零，单独报告不覆盖原因。保守图用于后续固定模型设计的敏感性实验，不与主图混用来归因报告收益。

不按验证收益选道路、不硬编码三条走廊。两图比较同时涉及连接、覆盖和边界变化，不能称为纯信息加入效果。

### 6.3 三类掩码与覆盖

| 掩码/指标 | 来源 | 用途 |
|---|---|---|
| 报告关联 `report_mask` | 原报告与候选位置 | 控制本次报告更新 |
| 观测有效 `observation_mask` | 原始数值有效性 | 相同预处理及评价；不伪造插补可靠性 |
| 算子可用 `operator_mask` | 固定道路与边界证据规则 | 控制交换适用范围 |
| 计算覆盖 | 固定可用图及有效调用 | 不能代替物理资格 |
| 实际响应覆盖 | 同权重干预后的非零变化范围 | 不能代替预测收益 |

同样预测 496 站不代表新机制在 496 站全部工作；整体指标和机制覆盖都要报告。

## 7. B0—B3 对照及可解释范围

| 组 | ICSF 空间职责 | 内部新交换 | TIID | 主要比较 |
|---|---|---|---|---|
| B0 | 原报告 V 注入 | 无 | 原版 | 当前原结构参照 |
| B1 | `2*sigmoid(g)` 强度乘原 V | 无 | 原版 | B1−B0：选择性强度采用 |
| B2 | 历史先验＋报告更新 \(a\) | 同信息普通神经交换 | 原版 | B2−B1：状态与传播组合 |
| B3 | 与 B2 完全相同 | 加边容量及共享预算限制 | 原版 | B3−B2：受限交换规则 |

### 7.1 B1 与旧尝试的关系

复用 v12c 节点门控的输入、宽度 16 和 `2*sigmoid` 形式，零初始化输出层使初始强度为 1。保留原 LayerNorm、K/TIID 和图构造，**本轮所有活跃参数端到端更新**；不调用会冻结主干的旧 `attach_gate`。

此门控可抑制或放大报告，范围为 `(0,2)`。它是选择性强度参照，不宣称为严格的报告/空选项概率模型，也不将其作为新创新。

### 7.2 公平条件

- 四组使用相同流量、时钟、原报告、填补、目标有效掩码、样本清单、训练顺序、主损失和选模指标。
- B2/B3 使用相同道路边、边界来源、容量信息、状态维度、子步、网络参数和读出。可训练参数名称、数量、初值逐项一致；不同算子的梯度及运行时间允许不同。
- B0/B1 不读取新候选道路图。因而 B3−B0 是“内部设计及候选结构”的完整系统比较；B3−B2 才是同道路信息下的算子比较。不能用前者单独证明物理约束有效。
- 所有匹配的主干、报告编码、TIID、原统计图和头部参数从同一初始化副本装配。B0/B1 初始预测应一致；B2/B3 只要求共同参数一致，不要求不同算子初始预测一致。
- 相同种子不足以自动保证 dropout 配对。新状态/提议模块首版不使用 dropout；原 dropout 使用独立可复现随机流，记录共同 batch 的随机种子与调用顺序。
- 报告总参数、实际参与训练参数、主干/新模块参数和优化器内参数。不能保留失活的 Q/V 参数来制造参数匹配。
- B2/B3 不使用 M4 的辅助预测损失、历史前缀任务、Bernstein 曲率正则或容量伪标签。首版只有原 pooled MAE 主损失。

如果后续额外加入速度、占有率或多报告集合，必须固定本轮结构另立信息实验；不能只给 B3 新通道再与旧 B0 排名。

### 7.3 归因与补充实验条件

B2 与 B1 同时改变状态接口及传播，不能据此独立证明“状态表示本身有用”。第一轮先比较组合；若组合确有价值且论文需要独立归因，再补“同一普通传播＋直接报告条件”与“同一普通传播＋状态更新”的对照。

B0—B3 也不能独立证明事故信息的增量价值：所有四组仍有原 TIID。若结果支持推进，应为最终候选和必要参照加入**重训练的空间报告关闭**；若声称整个报告的价值，再做**所有报告路径关闭的重训练**。不能把同权重 OFF 代替这些实验。

## 8. 首轮运行预算与判读

### 8.1 独立协议

新协议名建议 `contra_v8_internal_spatial_is1`。状态初始为 `DESIGN_ONLY`，实现、输入检查和本地工程验收后才允许标记可运行。以下为本版推荐默认值，在首轮预测结果产生前落盘；不继承旧 M4 run 身份或恢复其中优化器。

| 项目 | 默认 |
|---|---|
| 原主干 | hidden 32、5 层、`k_s=2,k_t=3,gap=3`、固定 TIID、ACDG 关闭 |
| batch | 48；显存不足时四组共同调整并新建协议 |
| 优化器 | Adam，lr 0.002，weight decay 1e-5，eps 1e-8 |
| 梯度裁剪 | 5.0 |
| 学习率 | 保持原筛选协议 `[1,38,46,54,62,70,80]`、gamma 0.5；明确包含第 1 轮衰减，不暗改成恒定 lr |
| 主损失 | 原有效目标 pooled MAE |
| 选模 | 全 496 站 12 时距的 horizon-macro MAE，严格改善；并列取较早 epoch |
| 首个配对种子 | 2025 |
| 扩展配对种子 | 2026、2027 |
| 完整预算上限 | 100 epoch，patience 20；实际更新数逐组报告 |
| test | 开发阶段不读取 |

沿用原训练超参数是为了控制比较条件，不代表这些参数已经针对新模块最优。如果候选需要调参，给普通参照相同的调参预算，并另立协议。

### 8.2 分步执行

| 步骤 | 范围 | 要得到的判断 |
|---|---|---|
| E0 本地工程 | 独立图、真实少量窗口、每组至少 2 次更新 | 输入权限、张量契约、梯度及恢复正确 |
| E1 首轮服务器 | B0—B3，seed 2025，完整 1 epoch | 真实运行时间、资源与完整指标输出 |
| E2 短跑 | 同 4 组从各自最新 checkpoint 续至绝对 epoch 10 | 学习是否稳定、路径是否参与、是否值得增加预算 |
| E3 开发筛选 | 无工程故障时同 4 组续至绝对 epoch 30 | 判断预算内信号和收敛趋势，决定扩大或调整 |
| E4 稳定性 | 对保留的比较链按共同预算上限运行 3 个配对种子 | 开发验证集上的方向稳定性；不能冒充独立最终测试 |

10 轮不以单次排名淘汰 B2 这个算子参照。若 B3 值得继续，必须保留 B0 与 B2；若要声称超过简单门控，还必须完成 B1 的同预算比较。30 轮未见信号可以停止投入，但结论只写“当前版本在该预算内未见足够支持”，不写“事故信息/物理先验无用”。

首轮不设一个事后挑选的收益阈值。扩大预算时记录 B3 相对 B0、B2 的最佳验证差、共同 epoch 差和末 5 轮趋势。结构错误或输入不公平优先修复；数值正确但无收益时，改变一个明确假设后建立新版本，避免堆叠多个自由模块。

### 8.3 指标与统计单位

定义收益 `G = control_MAE - candidate_MAE`，正值表示候选更好。报告 B1/B0、B2/B1、B3/B2、B3/B0；其中 B3/B2 是首要结构检验，B3/B0 是最终改进目标。

全部 496 站主指标外，报告：原报告关联节点、候选可传播范围、候选图外节点、14 个道路/方向组、12 个时距和有效目标数量。分组规则从输入结构定义，不按误差选组；空分组记 unavailable。

同截止点或相邻时间窗口不作为独立重复。种子是优化重复；时间块是数据重复。保存逐窗口的误差和有效数，以完整日期/周为块做配对重采样，保留重叠窗口关系。3 个种子的方向、均值和范围单独列出，不能用海量节点误差伪造独立样本量。

当前开发验证与旧 audit 已反复查看，即使三个种子均有收益，也只属于开发证据。最终确认需要在模型与规则锁定后使用未参与选择的时间段或封存 test；本阶段不打开它。

## 9. 机制记录与干预范围

每组正常评价只做必要的统计，不保存整套每边梯度或全部中间激活。最少记录：

| 环节 | 记录 |
|---|---|
| 报告更新 | 关联数、`r` 分布、`abs(a0-a_prior)` 分布 |
| 容量 | `C` 分布、报告开/关容量差 |
| 提议及限制 | 提议量；边容量、发送、接收限制比例；真实内部与外部交换量 |
| 潜状态 | `abs(xS-x0)`、范围、逐通道潜收支；B2 clip 比例与截断量 |
| 主预测 | 绝对变化分布、误差改善与恶化及抵消 |
| 使用范围 | 图覆盖、实际调用、实际响应的范围及不覆盖原因 |

选定 checkpoint 后区分三种明确干预：

1. **空间报告 OFF：** `a0=a_prior`，重算容量与交换；原 TIID 保持 ON。检验新空间报告路径依赖。
2. **限制条件探针：** 缓存 ON 的某一次旧状态、提议和边界，只替换报告导致的容量上限，比较当步实际交换。它仅检验该条件下限制是否激活，不直接当作另一种完整预测模型。
3. **全部报告 OFF：** 同时关闭空间报告和 TIID 报告；命名并保存完整关闭清单。此探针仍不能替代重训练无报告组。

所有干预先重放保存的 ON，再使用相同 batch 形状执行 ON/OFF/ON。检查原参数、缓冲、训练模式及 RNG 复原。禁止仅因缩小 probe batch 就要求与不同 batch 的旧预测逐值完全相同；数值差异先诊断，容差不得在看到收益后临时放宽。

约束不活跃或没有可交换状态时可以没有响应；有响应也可能改善与恶化抵消。潜收支通过、梯度非零、曲线平滑均不替代主预测收益。

| 任务 | 开发内容 | 验收与产物 |

| IS1-D 配对训练器 | 共同初始化、顺序、指标、逐臂 checkpoint | 每组独立优化器、epoch/step/RNG 记录；中断恢复与无中断下一步一致；不覆盖旧 run |
| IS1-E 服务器短跑 | 1→10→30 轮分段续跑 | 一条入口、逐组资源与时间、完整验证和机制摘要；全部是新实验目录 |

这几个任务按依赖实施，不要求用户先提交多轮重复工程检查才能继续开发。

### 10.1 必须覆盖的工程场景

- 无报告时 `a0=a_prior`；空间 OFF 不影响 TIID 的开关状态；先验/初态/边界不读取报告。
- 单链与独立手算一致；合流共享接收；分岔和出口共享发送；入口与内部入边竞争接收。
- 闭图逐通道收支、开放图源汇对账、无边/孤立节点、零出价、全零发送、全零接收。
- B3 不靠 clip 保持范围；B2 clip 被完整记录；节点/边重排结果一致。
- 人工激活容量约束时，报告参数经容量影响实际交换及主预测；不要求每个真实 batch 都有非零容量梯度。
- 原模式前向不变；5 层与预测块调用均覆盖；异常路径不遗留上下文。
- B2/B3 活跃参数完全匹配；共同参数与 batch 顺序校验；保存/恢复下一次更新一致。

### 10.2 资源与服务器约定

首轮沿用用户现有 Python/Torch/CUDA 环境和任一可分配 V100。记录 GPU 型号，但兼容的 SXM2/PCIE 名称变化不作为数据或模型身份错误；在恢复记录中披露环境变化，不承诺跨硬件位级复现。

各臂顺序运行，结束后释放模型/优化器与大中间数组，避免将四套图缓存和验证预测常驻内存。逐 epoch 原子保存，记录子进程退出码；外部 `-9` 不自动等同于 GPU OOM。

交付 Python 运行入口与 Bash 包装，Git 更新命令单独提供。Bash 不包含 Git、安装或下载；Slurm 不使用该集群拒绝的 `--mem`。显式仓库路径，进入目录后才创建输出，避免在 Slurm spool 等目录写 `experiments`。

本文件尚无可执行新训练命令；实现完成后再给出实际存在且验收过的入口。预计时长以 E1 实测为准，不能把旧 M4 单轮时间直接当作新模型时间。

### 10.3 本轮设计核验

已用独立 NumPy 计算核验第 5 节方程：随机种子 20261010、1000 个随机有向图、每图 1—64 节点、4 通道，包含全零状态、全一状态、全零提议和开放源汇。float64 下最大容量越界与状态越界为 0，最大发送/接收预算超量分别为 `2.22e-16/4.44e-16`，最大逐通道潜收支残差 `7.11e-15`。

这是设计公式的独立数值检查，不是 PyTorch 新模块、自动微分、原模型兼容、真实道路资格或预测效果验收。IS1-A—F 仍未完成。

## 11. 后续时间机制与信息扩展的入口

若 B3 在同信息 B2 和原 B0 比较中形成值得继续的信号，再研究：

1. 固定空间接口，将原 TIID 与普通状态递推、受限状态递推比较。必须重新定义从截止点到目标窗口的真实时间、初态、边界和状态持续性；不能把本阶段空间调用的重新编码改名为时间演化。
2. 固定结构，逐项增加速度/占有率、真实缺失记录、多报告集合或新的道路资料。每项明确 available/requested/enabled/missing_reason；缺失时保留基础任务，不虚构信息。
3. 如获得物理量纲和更可靠道路连接，开展局部观测响应验证，检验瓶颈形成、积累及传播。不能用局部验证替代全网物理认证。

若 B2 与 B3 均有收益但接近，优先保留更简单的有效方案，并收紧受限结构的贡献主张；若 B3 只在 B2 之上、仍不及 B0，当前还不能称为 IGSTGNN 改进成功。

## 12. 思想来源与复用边界

| 来源 | 迁移的思想 | 本方案的具体落点 | 不继承的结论 |
|---|---|---|---|
| [Knowing When to Look，CVPR 2017 作者稿](https://arxiv.org/abs/1612.01887) | 外部信息不必始终采用 | B1 强度参照与报告状态更新门 | 不照搬视觉模块，不宣称单个 sigmoid 新颖 |

| [Daganzo，The Cell Transmission Model: Network Traffic，1994 报告](https://escholarship.org/content/qt9pz309w7/qt9pz309w7.pdf) | 网络发送、接收及路口分配须共同约束 | 内/外边共享预算和同一边交换量 | 未知转向比不虚构；本方案的比例缩放不是完整 CTM/FIFO |
