## 3. 核心量与可以被反证的解释

在同一有效候选 H1–H6 单元上，先将原始流量单位的 A、P、Y 转为 float64，再定义：

\[
r=Y-A,\qquad d=P-A,\qquad g=|r|-|r-d|.
\]

`g > 0` 表示 P 优于 A。先在全部预定候选位置产生预测，再用原 `y_valid` 评价；
不能让未来 Y、残差符号或以下类别决定是否发出修正。
这些量是事后诊断量，不是可部署特征。

定义**最终预测空间**中的统一缩放：

\[
G(\lambda)=\operatorname{MAE}(A)-\operatorname{MAE}(A+\lambda d),\quad \lambda\ge0.
\]

本轮只计算原端点 `G(1)` 和零点右导数 `S`，不扫描或选择 λ。逐单元导数为：

\[
s=\begin{cases}\operatorname{sign}(r)d,&r\ne0,\\-|d|,&r=0.\end{cases}
\qquad S=\operatorname{weighted\ mean}(s).
\]

固定非负评价权重下，G 是凹函数，`G(0)=0`，故 `G(λ) ≤ λS`。
另计算越过真值所带来的损失项：

\[
O=2\operatorname{weighted\ mean}
  \left[\mathbf1_{r,d\text{ 同号且非零}}(|d|-|r|)_+\right],
\qquad G(1)=S-O.
\]

O 包含“越过真值但仍优于 A”的单元，不等于有害过冲单元的损害总和。
这两种核算必须分开命名。

| 当前固定样本上的模式 | 能说什么 | 不能说什么 |
| --- | --- | --- |
| S < 0 | 该固定最终修正方向经任意正统一缩放仍有负经验收益 | 所有模型、逐节点门控、负缩放或未来数据都无效 |
| S = 0 | 任意正统一缩放不能取得严格正经验收益，可能保持零收益 | 任意缩放都必然严格变差 |
| S > 0 且 G(1) < 0 | 存在足够小的正统一缩放，使当前有限样本收益为正 | 已找到实用缩放值、每个窗口都幅度过大，或收益能够跨期迁移 |
| S 近零、支持不足或两种权重结论不同 | 逐项保留边界或口径差异 | 用有利口径覆盖原 pooled 主结果 |

这里只判断固定预测差 `d`，不判断缩小网络内部向量注入、正则化或重新训练的效果。
即便 S 为正，可改善的 λ 范围与收益也可能极小。本轮不计算最优 λ、oracle 最优收益或新模型成绩。

## 4. 精确贡献分解与分母

按下表顺序，将每个有效单元归入一个且仅一个类别；方向用非零值的符号比较，避免相乘溢出。
不把小残差或小修正截成零，也不按 audit 结果调整类别边界。

| 类别 | 定义 | 单元收益 |
| --- | --- | --- |
| no_change | d = 0，包括 r = d = 0 | 0 |
| r_zero | d ≠ 0，r = 0 | −\|d\| |
| wrong_direction | r、d 非零且异号 | −\|d\| |
| same_direction_beneficial | 同号且 0 < \|d\| < 2\|r\| | 正；允许越过真值后仍改善 |
| neutral_at_2r | 同号且 \|d\| = 2\|r\| | 0 |
| harmful_overshoot | 同号且 \|d\| > 2\|r\| | 2\|r\| − \|d\| < 0 |

窗口 i 有 nᵢ 个有效单元，M 为 nᵢ>0 的窗口数，N=Σnᵢ。
pooled 对所有 g/s/o 求和后除以 N；等窗口先在窗口内除以 nᵢ，再对 M 个窗口平均。
每类贡献也必须使用这两个**完整评价分母**。类别内部均值另列，不能将其直接相加。

每个端点/阶段/cohort 必报：A/P MAE、G(1)、S、O、六类单元数和占比、
六类对 G/S/O 的贡献、有效单元数、可评估窗口数及缺失量。
验证类别计数完整、类别贡献分别重构 G/S/O、`G=S−O`、`O≥0`。
以误差贡献为解释依据，不能只用“方向正确单元比例”决定机制。
原 counts=0 的窗口保留但均值记为 null，零分母不写零收益。

## 5. 匹配事故与常规对照的辅助差值

仅在 selection/audit 使用原共同三元组，按 NPZ 的 `ids` 对齐；该字段是正样本预测窗口 ID。
`source_indices` 是各 cohort 自己的数据行号，不能跨 cohort 当作配对键。
从已认证 manifest 连接事故 ID、事故 t0、两对照 candidate_t0 及完整支持起止时间。
输出唯一事故数用于描述，仍以原预测窗口为估计单位。

主辅助差值固定为 `D = G_I − (G_C1 + G_C2)/2`，同时并列两个单对照差。
只对 G(1) 作此对照，不增加一组基于 S 的筛选规则。

- pooled：先分别计算三个 cohort 的总误差收益 / 各自总有效单元数，再相减。
- equal-triad：只在三方都有候选早期有效支持的共同三元组集合上，逐组三方窗口收益作差后平均。
  该集合由原目标有效性决定；报告排除组数、各方保留有效单元及占完整 cohort 的质量。
- 并列全 cohort 等窗口均值，但不得将“分别可评估窗口集合的均值差”冒称 equal-triad。

相同候选 mask 或相同有效计数不代表三方逐单元有效位置相同。
本轮不新建三方目标交集指标，避免改变原评价对象；缺失差异限制写进解释。
D 为负只说明修正在这些匹配事故上的收益相对较差，不等于事故因果效应；
D 为正也不能挽救完整事故负收益。

## 6. 不确定性与有限的时间检查

复用原各阶段连续 ISO 周网格，含空周；全部端点、cohort 和 G/S/O 使用同一组抽样。
沿用 2,000 次抽样、95% 逐项百分位区间、至少 95% 有效抽样；普通周 seed=12028，
四周循环块 seed=12029。四周区间与普通周敏感性并列，原始抽样矩阵需对账保存。
主表包括每个端点 pooled 与等窗口的 G/S/O 及区间；不为每个小类别新增显著性标签。

对 D 必须在每次共同抽样内重新算三方统计量并相减，不能相减边际区间端点。
三元组整体按所配事故周抽样，保留配对；这不完全涵盖对照发生在其他周时的交通依赖。
只预定一项辅助敏感性：逐个日历周删除**任一成员原完整支持区间触及该周**的整组三元组，
重算 D，报告删除的三元组与单元质量。支持区间按 `[start,end)` 判断；用整数日历周网格，
不把 end 恰在下周起点误计为触及下一周。无剩余支持时报告 undefined，不改删周规则。
这项结果无新增区间、不用作筛周或新 gate；不再开展 matched/补集扫描或粗状态分箱。

数学上的固定样本结论与统计区间分开：S 的区间描述周变化，不把两个逐项区间条件合称
联合 95% 机制确认。audit 只有九周且反复用于研究；两架构三种子的区间也不独立。
跨阶段只报同端点的点值变化，不构造跨阶段配对区间。
原 A/scaler 使用更广 train、A 曾由旧 val 选出的依赖仍存在。

数学定理针对本次固定预测值；即使通过 MAE 对账，S 对近零残差的敏感性仍须保留，
不能把浮点结果包装成关于潜在精确实数网络或未来样本的证明。
若回放显示 G(1) 非负而原主结果为负，也停止主解释并核查，不当作新实验成功。

## 9. 决策和收口

一次完成全部六端点后即结束本轮，不根据输出追加种子、轮次、状态分箱或诊断搜索。

1. 来源、支持、回放或恒等式失败：标记工程失败，只处理可复现性，不作科学归因。
2. 主口径 S 明确为负：记录该端点的固定最终修正不能靠正统一缩放在当前样本改善；
   结束该端点的纯幅度调参解释。若六端点一致，再报告一致性，不能挑其中一个代表全部。
3. S 为正且 G(1) 为负：记录样本内局部方向与原幅度惩罚，不产生“缩小即可成功”的模型结论。
   只有另立方案、仅用既有 fit/selection 固定规则并安排未参与开发的数据确认，才可能比较新的幅度策略。
4. 数值边界、两权重异号或端点混合：报告不能统一归因，停止继续细分寻找有利群体。

所有分支都保留 v12m 主区域负结果，不自动升级模型或开放 test。
如本轮只再次定位到不稳定方向，当前输入与向量修正路线应收口；后续投入应有新的、
报告时可用的信息依据或改变修正方向的独立机制，并先检查信息增量。
不能直接重启已失败的 v9b/v11b 分支，也不能把增加模型容量本身当作新证据。
任何未来独立评价都需重新设计仅使用过去信息的 A/scaler 与选择流程；现有基线不能消除既有信息依赖。
